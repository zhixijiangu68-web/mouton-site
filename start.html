ムートンについて

ムートンは、調べて、試して、書き残している一人だ。専門家ではない。学んだこと、試したこと、公開された情報や研究を読んで分かったことを、このサイトに記録している。

置いているもの

  • セキュリティ：ネットワークの土台から、ログの読み方、認証、脆弱性と事件の読み解き、演習の記録まで。SOC アナリストを目指して勉強している順に置いている。
  • 食・身体・お金・生き方・哲学：よく言われることを、研究と公的な資料で確かめる。判定の表と根拠を置き、結論は読む人に任せる。
  • 暮らし・趣味：装い、部屋、香り、音楽、食べ歩き、おでかけ。調べて分かったことと、選ぶときの手がかりを短くまとめる。

書くときの決まり

  • 事実と数字は、公式の発表や一次資料、研究で確かめ、出典を付ける。確かめられないことは書かない。価格や営業時間などは、確かめた時点のもので、変わることがある。
  • 健康に関わる記事は、医療の助言ではない。「治る」「効く」とは言い切らない。
  • 商品やお店の紹介は、宣伝の言葉で書かない。本などの紹介（アフィリエイト）を含む記事は、リンクに「PR」と表示する。

攻撃の技術を試すときの決まり

  • 試すのは、自分の環境と、試してよいと許可された演習（CTF・学習用の演習）の中だけ。他人のシステムやサービスには、許可なく試さない。日本では、他人の ID とパスワードを無断で使うことや、弱点をついて入り込むことは、不正アクセス禁止法で禁じられている。
  • まだ修正されていない脆弱性の、悪用の手順は書かない。脆弱性は、仕組みと、見つけ方・防ぎ方を中心に書く。
  • 弱点を見つけたときは、勝手に公開せず、作った会社や窓口（日本なら IPA の届出の窓口）に知らせる。
