気になることから選ぶ

生き方について考えたいキルケゴール、ニーチェ、ストア派、カミュ、サルトル。連載「哲学者に聞く」 → 見た目の清潔感を整えたい第一印象、匂い、口臭、日焼け。連載「清潔感を、確かめる」 → 仕事やお金で迷っている辞めたい、転職、年収、お金の本。連載「転職を考える」 → 健康の「本当？」を知りたいコーヒー、ダークチョコ、オリーブ油。連載「その健康法、本当？」 → よく眠りたい昼寝、寝だめ、朝型と夜型、寝室。連載「眠りを確かめる」 → 変わりたい、続けたいセルフイメージ、目標と仕組み、恐怖。連載「自分を変える仕組み」 →
