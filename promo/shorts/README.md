# YouTube ショート

○×クイズを15秒の縦動画にしたもの。上に問題、下に「玉が釘に当たって落ち、山の形にたまる」動き（ゴルトンボード。ブラウザで描いた自作の映像なので、著作権の心配はない）。

- 作り方：`cd scripts/og && node x-video.mjs <slug> [n] --shorts` → `promo/shorts/<slug>-<n>.mp4`
- 流れ：0〜7秒 問題 → 7〜10秒 3・2・1 → 10秒〜 答え → 最後の0.5秒で問題に戻る（ループで2周目に入りやすくする）
- 音は入っていない。アップロードするときに、YouTube の「サウンド」から音源ライブラリの曲を付ける（YouTube 内の曲なら権利の心配がない）
- ショートの説明欄のURLは押せないことが多い。記事への入口はチャンネルページのリンク（サイトのトップ）にしておく
- 投稿するのはオーナー（AI は投稿しない）
- 大量に同じ型を並べると「量産コンテンツ」と見られやすい。1日1本までにして、毎回ちがう問題にする
