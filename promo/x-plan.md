# X の設計図（@kodoku__alone）

最終更新：2026-10-08。迷ったらこの1枚に戻る。細かいルールは `.claude/skills/x-staff/rules.md`、投稿文と順番表は `promo/x-posts.md`。

## 1. 目的と流れ

- 10月の目的：**最初の1件が売れる**、そして**どの記事から売れたか分かる**
- 流れ：**X（見つけてもらう）→ 記事（読む）→ 選び方の商品カード（Amazon・楽天）**
- 役割分担：**哲学の投稿＝フォローを増やす**／**選び方の投稿＝売上につなげる**／**リプライ＝見つけてもらう**

## 3. 毎日やること（オーナー）

| 時間 | やること | 中身 |
|---|---|---|
| 朝 7〜8時 | 投稿1本 | 順番表の「朝」（選び方・読み物） |
| 昼 12〜13時 | 投稿1本 | 順番表の「昼」（哲学の厳選30本を上から） |
| 夜 21〜22時 | 投稿1本 | 順番表の「夜」（選び方・読み物・投票） |
| すきま時間 | リプライ10件 | `promo/x-replies-out.md` の型と一言で。リンクは貼らない |
| 投稿したら | ✓ を付ける | 順番表の「投稿」欄。リプリンクの投稿は、すぐ自分で返信して記事の URL を貼る |

毎朝「今日の3本」と言えば、X担当（AI）がその日の3本をコピーできる形で出す。

## 4. 投稿の中身と比率

| 枠 | 中身 | 比率 |
|---|---|---|
| 朝・夜 | 選び方の記事（クイズ、意外な数字、常識の否定、比較、投票） | 朝・夜の7割 |
| 朝・夜 | 読み物の記事 | 朝・夜の3割 |
| 昼 | 哲学（「哲学投稿のフォーム」の5つの条件を満たすものだけ） | 毎日1本 |

どの投稿も、1行目で止める。嘘・誇張・あおり・他人の批判はしない。数字は記事で確かめたものだけ。

## 5. 決めたこと（10/8）

- **サルトル100本**：10月は出さない。11月から昼の枠で「サルトル100」として毎日1本（リンクは5本に1本）。10月の昼は、形を確かめた厳選30本を優先する
- **哲学100本・オーナーの言葉から・ナルシシズム**：予備。2週間の数字で勝った型に書き直して、11月以降の昼の枠で使う
- **英語の投稿**：保留（アカウントが決まるまで出さない）
- **リンクの型**：リプリンクと本文リンクを、2週間比べてから決める

## 6. 仕組み（2026-10-08 から）

| 何を | どうやって | 誰が |
|---|---|---|
| その日の3本を出す | `npm run x:today`（日付を指定するなら `node scripts/x-today.mjs 2026-10-12`）。本文・リプライの1行・投票の選択肢・画像の場所を、コピーできる形で出す | X担当（AI）が毎朝「今日の3本」で実行 |
| 投稿に付ける画像を作る | `cd scripts/og && node x-cards.mjs 2026-10-09` で、順番表のその日以降の投稿の画像を `promo/x-images/<ID>.jpg`（1080×1350）に作る。投稿の1行目（フック）を大きく、○×の問題には「○か×か？」 | X担当が、順番表を変えたら作り直す |
| 画像を付けない投稿 | 投票（X の投票には画像を付けられない）、答え合わせ（投票を引用する）、本文リンク（画像を付けると記事のリンクカードが消える。記事のシェア画像がクイズのカードなので、そちらを使う） | — |

**画像の効果**：会社の分析では、画像つきの投稿は反応率が少し高く、文字だけの投稿は表示回数が多い、という結果もあり、はっきりしない（`promo/x-research/2026-10-08.md` の後の調べ）。10/9〜10/22 は**画像つき（リプリンクの投稿）と、画像なし（本文リンクの投稿）**を比べ、効いた方に寄せる。

**動画**（10/9 から）：`cd scripts/og && node x-video.mjs <記事> [番号]` で、○×クイズから縦長の8秒動画（問題 → 3・2・1 → ○か×と答え → 「理由はリプライの記事で」）を `promo/x-videos/` に作る。1本約17秒で作れる。投稿文は `promo/x-posts.md` の「動画クイズ」。画像の投稿と入れ替えて、表示回数とリンクのクリックを比べる。

## 7. 毎週の振り返り（月曜）

オーナーが X のアナリティクスと GA4 の画面（またはCSV）を渡す → X担当が `promo/x-analysis/<週>.md` に次の表を作り、翌週の順番を直す。

| 見る数字 | どこで見るか |
|---|---|
| フォロワー数（週の増減） | X のプロフィール |
| 投稿ごとのインプレッション・リンクのクリック・プロフィールへのアクセス | X のアナリティクス |
| X から記事への訪問 | GA4（ソース / メディア が `x / social`） |
| 商品リンクのクリック | GA4 の `affiliate_click` |
| 売上 | Amazon アソシエイト・楽天のレポート |

フォロワーの目標は、10/22（2週間後）の伸びを見て決める。
