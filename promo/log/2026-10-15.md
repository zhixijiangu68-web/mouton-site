## パズルゲーム「MOUTON BLOCKS」を作った（puzzle.html）

- 依頼：ゲームを作りたい。パズルゲーム。シンプルで、個人ゲーム。スコアやランキングが出る。広告を見るとアイテムがもらえる
- やったこと：
  - `src/puzzle.njk` → `puzzle.html`：8×8のマスにブロックを置き、縦か横の列をそろえて消すパズル。サイトのアイコン（紺の夜空・金の月・白い羊毛）の色で作った
  - `puzzle-core.js`：ルール（ブロック13種類・置く・列を消す・点数・コンボ・全消し・詰み判定・アイテム・保存と再開）。画面から切り離して、`tests/puzzle-core.test.mjs`（12件）で確かめる。`npm test` に組み込んだ
  - `puzzle.js` / `puzzle.css`：盤面の表示、ドラッグ（スマホは指の上にブロックが浮く）、タップで選んで置く、キーボード（1〜3で選ぶ・矢印・Enter）、消えるときの演出、点数の表示
  - 点数：1マス1点。列は1列10点・2列30点・3列60点・4列100点で、続けて消すとコンボで倍になる。盤面が空になると+300点
  - アイテム3つ（1ゲームに1つずつ）：もどす（1手戻す）・引き直し（ブロックを3つ入れ替える）・流れ星（3×3を消す。点は入らない）
  - ランキング：この端末のベスト10（スコア・消した列・日付）をブラウザに保存。ゲームオーバーで順位と自己ベストを出し、「Xでシェア」でスコアを投稿できる。途中の盤面も保存し、ページを開き直しても続きから遊べる
  - 広告でアイテム：AdSense の「H5 ゲーム広告」（Ad Placement API のリワード広告）を組み込んだ。使い切ったアイテムのボタンが「広告で+1」になり、押すと確認の画面→広告→最後まで見たときだけ1つもらえる（1ゲーム3回まで、`site.js` の `game.adRewardsPerGame`）
  - `src/_data/site.js` に `game`（`rewardedAds: false`）。`base.njk` は、このページだけ AdSense のスクリプトを読み込まない（`ownAdScript`）
  - 制作ページに PROJECT 004 として追加（`projects.json`・`makingLog.json`、`making-blocks.html` が自動で生成）。カードと詳しいページに「遊ぶ」ボタン。画像 `images/making/blocks.jpg`（盤面と点数はデモ）
  - フッターの「このサイト」に「パズルゲーム」、`sitemap.xml` に `puzzle.html`
  - シェア用の画像 `images/og/puzzle.jpg`（記事と同じ型。`scripts/og/make.mjs` にも足した）
  - プライバシーポリシー：ローカルストレージに保存するもの（途中の盤面・ランキング）を追記。リワード広告の説明は `rewardedAds` を true にしたときだけ出る。最終改定日 2026.10.15 を表示（`site.js` の `policyUpdated`）
  - GA4 のイベント：`puzzle_start`・`puzzle_over`（スコア・列・手数）・`puzzle_share`・`puzzle_reward`。DESIGN.md・REQUIREMENTS.md の表に追記
- 判断：
  - ゲームの種類は、スマホで指1本で遊べて、1回が数分で終わり、アイテムが自然に効く「ブロックを置いて列を消す」型にした
  - **広告でアイテムは、AdSense の正式なリワード広告（H5 ゲーム広告）だけを使う。** 通常の広告を「見たら・押したらアイテム」にするのは AdSense のポリシー違反（広告の閲覧やクリックに報酬を出すこと）になり、アカウントが止まるおそれがある。H5 ゲーム広告は Google の審査（ベータ）で承認されたサイトだけが使えるため、承認までは `rewardedAds: false` で止めてある。止めている間は「広告で+1」は出ず、広告のスクリプトも読み込まない
  - アイテムはゲームの中だけのもので、お金や物とは交換できない（リワード広告のポリシーに合わせた）。広告は自分で選んだときだけ流れ、途中で閉じたらもらえない
  - このページでは自動広告も出ない。盤面やブロックのそばに広告が差し込まれると、ドラッグ中の誤クリック（無効なクリック）の原因になるため
  - **ランキングは「この端末」だけにした。** ほかの人と競える全体のランキングは、スコアを受け取るサーバー（Cloudflare Worker など）、スコアの改ざん対策、名前の不適切な言葉の対策、プライバシーポリシーの改定が要る。まだ動いていない納品の Worker（`fulfillment-worker/`）と同じく、オーナーのアカウントでの準備が要るので、今回は入れなかった。代わりに X でスコアをシェアできるようにした（X → サイトの流れにも合う）。ゲームは乱数の種から同じ展開を再現できる作りにしてあり、全体のランキングを作るときに「サーバーで同じ手を再生してスコアを確かめる」形にできる
  - トップはシンプルに保つ方針なので、トップには入口を置かず、制作ページ・フッター・メニューの「制作」から入れるようにした
