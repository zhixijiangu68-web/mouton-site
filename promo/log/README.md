# 作業ログ

AI（Claude）がした仕事を、日付ごとに詳しく残す場所。`promo/status.md` は「いまどこか」の要約、ここは「何を・なぜ・どう確かめたか」の記録。

## 書き方

- 1日1ファイル：`promo/log/YYYY-MM-DD.md`（日本時間の日付）。同じ日の仕事は同じファイルの末尾に足す
- 仕事を1つ終えるたびに1項目書き、その仕事のコミットに含める（ログだけ後回しにしない）
- 1項目の形：

```
## <見出し：何をしたか>

- 依頼：オーナーの言葉（短く）
- やったこと：変えたファイル・作ったもの
- 判断：なぜそうしたか。選ばなかった案と理由
- 確かめたこと：npm test、スマホ幅の確認、出典の照合など。結果も書く
- 見つけた問題：途中で見つけて直したこと、直していないこと
- 残り・承認待ち：オーナーの判断が要ること、次にやること
- リンク：PR、コミット、ファイル
```

- 数字・事実は確かめたものだけ書く。分からないことは「不明」と書く
- 書かないもの：パスワード・APIキー・個人のメールアドレスなど、公開リポジトリに置けない情報
