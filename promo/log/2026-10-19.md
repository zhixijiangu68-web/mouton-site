# 2026-10-19 作業ログ

## サイトの記事を100本足す（note と同じ記事は作らない・コピー第一・次のコンテンツへつなぐ）

- **依頼**：「サイトの記事が100個ほど欲しい。けれど、noteと全く同じ記事は絶対に作成しないことを守ってください。コピーライティング第一で、次のコンテンツにつなげてください。」（オーナー、10/18 夜）
- **やったこと**：
  - 原典の置き場をつくった：この環境からは青空文庫・グーテンベルクなどのサイトを開けないので、GitHub にある公開の写しから、英訳39冊（GITenberg）と青空文庫の25人・2,190作品（aozorahack/aozorabunko_text）を手元（`/home/user/corpus/`、リポジトリの外）に集め、UTF-8 にして索引を作った。記事の引用は、すべてここで原文を grep して確かめた
  - 企画：原典を7つに分けて7人の企画担当が126本を出し、グループごとに3人（note・サイトとの重なり／コピー／原文）が反証のつもりで確かめた。note と同じ話の5本を落とし、近すぎる57本は場面・一節・切り口の直し方を付けた。そこから100本を選び、悩みごとの20の連なり（決められない32本・人の目34本・続かない34本）に並べた。全体の点検で見つかった重なり10件を直してから書いた
  - 執筆：連なりごとに site-writer が順に書き（原文を前後まで読んで確かめる）、site-checker が コピー → 原文と出典 → note との重なり → 言い方 → 形 の順に確かめて直した。結果は 直して通った62本・そのまま通った17本・オーナーの判断が残る21本・出せない0本
  - 組み込み：100本を `src/_data/currentArticles.js` に連なりごとのコメントつきで登録（いまの記事は11本→111本）。シェア用の画像100枚（`images/og/<slug>.jpg`。作り直しで変わった既存の6枚は元に戻した）。生成物（直下の HTML・`picks.json`・`feed.xml`・`sitemap.xml` など）
- **判断**：
  - 「次のコンテンツにつなげる」は、各記事の最後を「問いを一つ → この記事で片づかなかった問いを一つ渡して、次の記事へリンク」にし、`related` の先頭を次の記事に、有料への案内（`paid-cta`）を連なりの悩みの有料記事にした。どの連なりも最後の記事は入門の無料記事（kierkegaard／nietzsche／spinoza）につなぎ、そこから有料の3本へ進む
  - 連載（`series.js`）には登録していない。10/16 にオーナーが連載を「哲学者に聞く」だけにしたため。記事の中のつなぎと「次に読む」で読む順が分かる
  - 100本を「いまの記事」に登録した。10/17 の「記事は必要なものだけ残す」から変わるが、新しい記事をアーカイブ扱いで出すと上に「アーカイブ」の注記が出てしまうため。戻すなら `currentArticles.js` の追加分を消すだけ
  - note と同じ記事にしないため：note の全80本（main と note のブランチ。有料の無料部分を含む）を企画の段階で除外の基準にし、書いたあとも機械で照らした。20字以上の一致は、note の「はじめての方へ」がサイトの「ムートンについて」を写している文と、記事の題・書名だけだった。「ムートンについて」の文を長くそのまま使っていた3本は言い直した
  - ムートンの経験として書けるのは、「ムートンについて」と残す記事に書いてあることだけにした。新しい出来事は作らず、全段落の前に `<!-- 本人の確認：僕の経験 -->` を入れた（表示されない）。冒頭の場面が一人称の過去形でムートン本人の経歴に読めた2本は「たとえば〜とする」にした
  - 英訳から訳した引用は「（英訳から僕の訳）」とし、参考文献に原典の巻・章と英訳（訳者・Project Gutenberg の番号）、青空文庫は底本の行をそのまま書いた。確かめられない年・伝記は書いていない
- **確かめたこと**：`npm run build` → `npm test`（304ページ、問題なし。いまの記事 111本・アーカイブ 97本）。`npm run lint:writing`（100本で警告1件。漱石の原文の引用の中なので直さない）。形の機械チェック（100本とも h1 が1つ、出典の番号と参考文献が一致、次の記事へのリンク、有料への案内、styles、日付、description の長さ、リンク切れなし）。スモークテスト18件成功。390px で100本とも横にはみ出しなし
- **見つけた問題**：作業の途中で利用枠の上限に一度当たり、9つの連なりの確かめが止まった。上限が解けてから再開し、書いた記事はそのまま、確かめだけをやり直した。Aristotle の英訳（PG #8438）と Pascal の英訳（PG #18269）はファイルに訳者名がなく、参考文献には書いていない
- **残り・承認待ち**：PR 本文の「オーナーに確かめてほしいこと」（僕の経験の段落が実感と合うか、題を企画から変えた記事など）。英語版・連載への登録はしていない
