## 0. 先に読んでほしい：調べ方の制約と確かさ

- **このセッションでは WebFetch がほぼ全部止められていた。** togetter.com / note.com / x.com / nlab.itmedia.co.jp / j-cast.com / diamond.jp / hashout.jp / buzzweet.com はどれも名前解決できなかった（ネットワークの許可リスト外）。**使えたのは WebSearch だけ**。
- そのため本文は次の2つの経路からだけ写した。
  1. **X の投稿ページのタイトル**（検索結果に出る「◯◯ on X: "本文" / X」）。これは投稿本文そのものだが、**改行が空白に置き換わり、長い投稿は途中で切れている**。下の引用は空白も含めてタイトルのまま写した（空白はたぶん元の改行）。切れているものは「（以下未確認）」と書いた。
  2. **記事・まとめ・X のトレンド要約に引用された一部**。その場合は「一部」と書いた。
- **いいね数は、報道（ABEMA TIMES・LASISA など）と X 自身のトレンド要約（x.com/i/trending）に書かれたものだけ**を載せた。それ以外は「不明」。投稿日は、X の投稿 ID（スノーフレーク）から計算した日付（UTC）を基本にした。
- 確かさの目安
  - **A**：いいね数が出典に書いてある（ただし出典ページ本体は開けず、検索結果の抜粋で確認）
  - **B**：本文は X のページタイトルで確認。いいね数は不明だが、まとめ・報道・閲覧数など拡散の根拠がある、または発信者が大規模（数十万〜）
  - **B−**：本文は確認、いいね数不明、拡散の根拠は発信者の規模だけ
- **いいね1万以上を数字で確かめられたのは9件**（A1〜A9。A9 は約1.5万）。残りは数字が取れなかった。ネットワークの許可（とくに x.com・togetter.com）があれば、いいね数をまとめて確かめ直せる。
- 存在を確かめられない投稿・数字は書いていない。

## 4. ムートンの書き直しに使えそうなこと（材料として）

- **いちばん合う型は「逆説 → 言い切り → 指示しないで終わる」**（認識の転換型、10件）。押しつけず、約束せず、それでも止まる。例の骨組み：「〜な人は、〜なのではなく、〜なだけかもしれない。」ではなく、ぼかしを減らして「〜なのではなく、〜なだけ。」まで言い切る（ぼかしは26件中4件しかない）
- **1行目で名指しする**：「眠れない夜に考えごとが止まらない人へ」「〜を続けられない人は」。お坊さん・Tomy・ぱやぱやくんの共通点
- **立場の前置きは事実の範囲で**：ムートンは先生ではないので「医師なので」は使えない。使えるとすれば「〜を3年試した記録として」など、自分の経験の立場
- **問いはXの締めには置かず、サイトへの導線に回す**：伸びた実例に「問いで終わる」はほぼない
- **数字は出典のあるものだけ**：避けたほうがいい型の多くは「出典のない数字」と「〜するだけで」
- **120〜140字いっぱいに具体を詰める型**（11件）と **40字前後の一文**（3件）の両方がある。中途半端な長さより、どちらかに寄せる
