## 固定ポスト（どちらか1本）

140字以内（URL を除く）。X の重み付きの文字数（日本語1字＝2、URL＝23）でも280以内。特定の商品を名指ししないので【PR】は付けていない。

### P-1 選び方の一覧
```
買う前に、何を見ればいいのか。

オリーブオイル、ダークチョコ、コーヒー、プロテイン、口臭ケア、制汗剤、耳栓。研究と公的機関の情報をもとに、選ぶときに見るところを記事にまとめている。

特定の銘柄をすすめるより、自分で選べるように。

https://moutonarchive.com/guides.html?utm_source=x&utm_medium=social&utm_campaign=pinned
```

### P-2 ラベルの言葉だけでは分からない
```
「エキストラバージン」の表示。カカオ分の数字。「カフェインレス」の基準。

ラベルの言葉だけでは、分からないことが多い。

研究と公的機関の情報をもとに、買う前に見るところを「選び方」の記事にまとめている。

https://moutonarchive.com/guides.html?utm_source=x&utm_medium=social&utm_campaign=pinned
```

## プロフィール文（どちらか1本）

160字以内。末尾にアフィリエイトの表示を入れている（ステマ規制）。

### PF-1
```
買う前に、何を見ればいいのか。食べ物・体のケア・本の「選び方」を、研究と公的機関の情報をもとに書いています。言い切らず、出典を付けて。ときどき哲学と生き方の話も。個人サイト「ムートン」。※記事内の商品リンクにはアフィリエイトを含みます
```

### PF-2
```
研究と公的機関の情報で、買う前に見るところをまとめる「ムートン」。オリーブオイル、プロテイン、口臭ケア、耳栓…選び方の記事を毎日紹介しています。ときどき哲学と生き方の話も。※リンク先の記事にはアフィリエイトリンクを含みます
```
