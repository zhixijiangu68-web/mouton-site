# 04-review：one-case-vs-trend

判定：**修正すれば公開可**（修正は article.md に反映済み。人の公開前確認が数点あり）

## 確認結果

- 事実・出典：外部資料は未確認（ネットワーク制限）。本文に数字・論文名・参考文献・公的機関の名指しはなし（01-research.md の方針どおり）。確認できない一般論は「僕の見立て」と断っている。
- 医療：「病気の治療は、体験談で決めないでください。」の一文あり。末尾に「個別の診断や治療を目的とするものではありません」の注記あり。「治る」「効く」の言い切りなし（見出し「何が効いたか」は問いの表現で、効果の断定ではない）。
- 広告：サイト・商品リンクなし。PR 表記は不要。
- 文体：敬体で統一、一人称「僕」。1〜2文ごとの空行を維持。
- タイトル：03-titles.md の本命を採用。誇張・煽りなし。本文と一致。
- 想定の例：冒頭の場面は想定と明記し、「以下のたとえも同じく想定」と追記。体験談に見える記述（知人・本人の経験）はなし。

## 直したところ

1. 先頭の仮タイトルのコメントを、先行記事（smoking-long-lived/note.md）と同じ形式のコメント（本命タイトル1行入り）に差し替え。
2. 「口コミを書くのは、買った人だけ」を「多くは買った人だと思います」に弱めた（買っていない人の投稿もありうるため、断定を避けた）。「並びにくいはず」も同様。
3. 「合格体験記には、受かった人の話しか載っていません」を「中心になりがち」「ほとんどない」に弱めた（未確認の断定を避ける）。
4. SNSの「広がります」を「広がりやすいと僕は感じています」に変え、「僕の見立てで、確かめたものではない」と明記。
5. ニュースの「天気（雷）のたとえ」を「駅の掲示板」のたとえに差し替え。drinking-long-lived の「天気予報」のたとえとの重複を避けるため。
6. 「3つの場面に共通して…5つにまとめます」の「まとめ」を言い換え、「全部に答えが出なくても大丈夫」を追加（まとめ色を弱める）。5つは小見出しのままで、箇条書きにしていない。
7. 末尾の公的情報の節に、「一次資料を開いて確かめられていない」ことを明記（他の先行記事と揃えた）。
8. 「場面を3つ見ていきます」の表現を、「ずれが起きやすい場面を3つ」に整えた。

## 先行記事との重複確認

- smoking-long-lived：生存者バイアスの用語・シートベルト・くじ引きは不使用。重複なし。
- drinking-long-lived：天気予報のたとえは差し替え済み。用語の「生存者バイアス」は使っていない。
- testimonial-bias：「語る人は選ばれる」「比べる相手」「効かなかった人の話」「見せる側」の考え方が一部重なる。ただし本記事は口コミ・SNS・ニュースの3場面と「ありえる／ありそう」の対比が軸で、重なるのは確かめ方の2項目程度。別記事として成立すると判断した。
- before-you-buy：クイズ形式・サイトリンク中心で、内容の重複なし。

## 人が確認すべきこと

- 「5つの確かめ方」のうち「比べる相手」「うまくいかなかった人」は testimonial-bias とやや近い。連続で投稿する場合は、間隔を空けるか、見せ方を変えるか判断してほしい。
- 口コミ・SNS・ニュースの偏りは、すべて「僕の見立て」としている。この表現でよいか、投稿者として確認してほしい。
- 事業部長の方針により、Hu らの論文（口コミの自己選択バイアス）や消費者庁の体験談の調査、ステルスマーケティング規制は載せていない。原典を人が開いて確認できれば、補足として足せる。未確認のため現状は不使用。
- 【要確認】タグの残りはなし。
- note への貼り付けと投稿は人が行う（AI は投稿しない）。
