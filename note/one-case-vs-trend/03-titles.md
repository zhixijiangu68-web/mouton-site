# タイトル案（one-case-vs-trend）

本文の仮タイトル（HTMLコメント）：星4.5の商品に「期待外れ」の1件。どちらを信じる？
先行記事との型の調整：smoking-long-lived は「結論先出し」「と言われたら」「くじ・シートベルトの比喩」、drinking-long-lived は「祖父の問いかけ」「言葉の中身」「天気予報の比喩」、testimonial-bias は「数字（4つ）」「体験談の問い」が中心。この記事は「口コミの場面」「言葉の対比（ありえる／ありそう）」「3つの場面」「道具（ものさし）」を軸にした。

## 2. おすすめ 3 案と理由

- **案1**：本文の核（ありえる／ありそう）がそのまま入り、約束とずれない。言葉の対比は先行3本に使われていない型。「星1つの口コミ」で買い物の場面だと一目で分かり、手が止まりやすい。
- **案4**：「口コミを書くのは買った人だけ」という、言われてみれば当たり前の事実で足を止める。本文の場面1と一致し、煽りがない。
- **案9**：本文の「5つの確かめ方」に対応し、持ち帰れるものがあると伝わる。ただし testimonial-bias の「数字」型と近いため、本命にはしなかった。

## 3. 最終案（本命）

**「ありえる」と「ありそう」は違う。星1つの口コミを読むとき**（全角 29 文字）

- 数字は本文にある「星1つ」のみ。「絶対」「損」などの煽り・言い切りはなく、特定の商品や病気にも触れない。
- 先行3本（結論先出し・と言われたら・祖父の問いかけ・天気予報・数字）と型が重ならない。

## 4. 見出し画像に載せる文言（10〜15 文字）

1. 星1つの口コミの読み方（11 文字）
2. 「ありえる」と「ありそう」（12 文字）
3. 1人の例と集団の傾向（10 文字）

おすすめは 2。最終案と呼応し、静かで、サムネイルでも読みやすい。

## 6. 記事の説明（概要）

星4.5の商品に、星1つの「期待外れでした」が付いていたら、どちらを信じればいいのでしょうか。「1人の例」と「集団の傾向」が答える問いの違いを、口コミ・SNS・ニュースの3つの場面で、僕なりに整理しました。

- 本文先頭の HTML コメント（仮タイトル「星4.5の商品に『期待外れ』の1件。どちらを信じる？」）は、本命の「『ありえる』と『ありそう』は違う。星1つの口コミを読むとき」に差し替える対象。旧タイトルを残さないこと。
