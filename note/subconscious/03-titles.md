# タイトル案：subconscious（本文の仮題：サブリミナル音源のラベルを入れ替えても、聞いた人はラベルの通りに「効いた気がした」）

読者：20〜40代。寝る前のアファメーション・聞き流す音源・理想を思い描く方法のどれかを、一度は試したか、いま気になっている一人。
決め方：タイムラインで止まるか・具体か・本文の約束と一致するか（`docs/content-quality.md` の 0）。静かさ・きれいさでは決めない。
守ったこと：命令・断定・結果の約束・あおり（今すぐ・手遅れ・損・絶対）を使わない。健康の効果を言い切らない。書名・人名で権威づけしない（ザルトマンの名は題・画像・説明に出さない）。有料記事・値段に触れない。本文に書いていないことは入れない。サイトの題「『潜在意識を書き換える』方法を調べると、大規模な追試に残ったものはほとんどなかった。」と同じにしない（近い案は案10だけ）。「潜在意識の方法は全部うそ」と読める題・画像・タグにしない（本文は「寝る前に唱える」を、効かないと示されたわけではない、としている）。

## 2. 推す案と理由

**案1「サブリミナル音源、ラベルを入れ替えても「ラベルの方」が効いた気がした」**

理由：「ラベルを入れ替えた」という実験の仕掛けが一文で分かり、効いた気がした人を責めずに「効いた気がする」の正体を見せていて、本文の1行目と最初の段落（二重盲検・237人・1か月）でそのまま回収される。

弱み：34字で目安の32字を少し超える。「3分の1以上」「237人」「1か月」は題に入らないので、記事の説明（6）と見出し画像（4）で補う。短くするなら案3（32字）。

### 採らなかった主な理由

- 案2：本文の1行目そのもので、数字があるぶん強いが、42字で一覧では後半が切れる。切れると「ラベルの方」が消えて意味が変わる
- 案3：32字に収まり、反転は伝わる。ただし「ラベルを入れ替えた」がないので、市販の音源の宣伝文句の話に読める人がいる。案1の短い代わり
- 案4：数字の出どころを疑う題として強いが、「95%」の話は本文の一節で、主役ではない。X の1行目の材料にはなる（SNS担当へ）
- 案5：数字は具体だが、「教授を思い浮かべる実験」を知らない人には何の話か一瞬で伝わらず、読者の「寝る前に唱える」「聞き流す」とは離れている
- 案6：短く、常識の反対だが、本文では一つの研究グループの結果で確かさは「低」。題にすると本文より強く言うことになる。また「思い描くこと自体が悪い」と読まれる
- 案7：読者の方法に直接当たるが、「研究がなかった」は「効かない」と読まれやすく、本文の「効かないと示されたわけでもない」と齟齬が出る
- 案8：数字が二つあり止まる力はあるが、習慣の話は本文の最後の節で、別の記事（habit-design）にも近い
- 案9：読者の場面には当たるが、驚きがなく、答えが題にない。一覧で素通りされやすい
- 案10：サイトの題に近い。「自動化」は本文を読む前には抽象で、止まらない

### 題に使わなかった材料

- 「潜在意識は想像と現実を区別できない」の否定：本文は「半分だけ本当の部分がある」としていて、題で切ると本文より強くなる
- 「私は愛される人間だ」と唱えて自己評価が下がった研究：追試で再現されておらず、本文も「逆効果とも無害とも言い切れない」と書いている。題にすると逆効果の約束に読める
- 「お金の連想、事前登録すると g=0.01」：具体だが、本文での扱いは一段落。「教授」の追試より分かりにくい
- 「就活の内定が少なかった」：観察研究で、本文も因果を言わないとしている

## 3. 最終案

**サブリミナル音源、ラベルを入れ替えても「ラベルの方」が効いた気がした**（34字）

短くするなら案3「サブリミナル音源は、中身ではなくラベルの通りに「効いた気」がした」（32字）。

## 4. 見出し画像の文言

スマホの一覧では見出し画像が小さく出るので、2行に分けて大きく置ける長さにした。

1. **効いた気がしたのは、ラベルの方**（15字）← 推す
   - 2行なら：効いた気がしたのは／ラベルの方
   - 題（案1）と組むと、画像が結果、題が仕掛け（ラベルの入れ替え）になる。X に URL を貼ったときのカードで題が小さくても、「中身ではなくラベル」の反転は画像だけで伝わる
2. **「95%」に、測った研究はない**（15字）
   - 2行なら：「95%」に、／測った研究はない
   - 通説の数字で止める案。本文の2つ目の節と一致する。案4を題にするなら、こちらではなく1と組む（同じ話を二度言わない）
3. **書き換えより、自動化が残った**（14字）
   - 2行なら：書き換えより、／自動化が残った
   - 本文の結論の側。題が「効いた気がした」の話なので、残りの半分（何が残ったか）を画像で見せる組み合わせ

画像に入れないもの：「うそ」「だまされた」「効かない」（本文は、聞いた人がだまされやすかったという話ではない、と書いている）。「潜在意識は存在しない」のように、意識にのぼらない処理そのものを否定する文（本文は「そこまでは確か」としている）。

## 5. ハッシュタグ

#潜在意識　#心理学　#自己啓発　#アファメーション　#サブリミナル　#習慣化　#エビデンス

（大きいタグ：#心理学 #自己啓発 ／ 中くらい：#潜在意識 #習慣化 ／ 小さいタグ：#アファメーション #サブリミナル #エビデンス。大小は目安で、note のタグのページの記事数は確かめていない）

- 付けないタグ：#引き寄せ #引き寄せの法則 #ビジョンボード #スピリチュアル。本文で扱っていない（引き寄せ・ビジョンボードは【本人が書く】の欄の例にあるだけ）。信じている人の一覧に、否定の記事として並ぶことになる
- #潜在意識 は「書き換え方」を勧める記事が多いタグ。本文の判定と逆の文脈に並ぶが、読者が探す言葉なので外さない

## 6. 記事の説明（note の「記事の説明」欄）

自己肯定感用と記憶力用のサブリミナル音源のラベルを入れ替え、237人に1か月使ってもらうと、3分の1以上が中身ではなくラベルの方の力が上がった気がしていた。「行動の95%」「寝る前に唱える」「21日で定着」も原典で確かめ、追試に残った方法だけを書いた。（119字）

題に入らなかった数字（237人・1か月・3分の1以上）を頭に置き、題にない残りの話（95%・寝る前・21日）を後半に並べた。「追試に残った方法だけを書いた」は本文の最後の節（実行意図・66日）に対応する。効果の約束はしていない。

## 7. 品質チェック担当へ（題を決めるときに気づいたこと）

- 題の「効いた気がした」は、本文1行目の「力が上がった気がしていた」を短くした言い方。研究 [26] は「ラベルに書かれた能力が改善したと本人が報告した」結果なので、意味は変えていない。本文の表記に合わせるなら、題を「ラベルの方の力が上がった気がした」に替えてもよい（4字増えて38字）
- 題・画像・説明には、ムートン本人の体験に頼る言葉を入れていない。【本人が書く】の行を消しても、そのまま使える
- 本文の仮題（1行目）は42字で、note の一覧では後半が切れる。案1に差し替えるか、仮題のまま出すなら「ラベルの通りに」が切れない位置にあるか確かめてほしい
- 案6（活力が下がった）は、本文で確かさ「低」としている研究なので、X の投稿にも単独の一行として使わないほうがよい（SNS担当への申し送り）
