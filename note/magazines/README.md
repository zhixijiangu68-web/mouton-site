# note のマガジン（2026-10-18）

note の「マガジン」は、記事をまとめて並べる棚。1本読んだ人が、同じ棚のほかの記事に進める。記事が12本を超えて、プロフィールの一覧だけでは探しにくくなったので、棚を4つ用意した。**作るのも記事を入れるのもオーナー**（AI は note に投稿しない）。

- 中身：`magazines.json`（名前・説明・いつ作るか・入れる記事・見出し画像の文言）。公開キットの「マガジン」の欄から、名前と説明をコピーし、ヘッダー画像を保存できる。
- ヘッダー画像：`start.jpg`・`series-30.jpg`・`next-30.jpg`・`paid.jpg`（1280×670。スマホでは中央が切り取られるので、文字は中央に置いた）。作り直すときは、見出し画像と同じ `scripts/og/note-cover.html` で作る（文言は `magazines.json` の big・small）。

| 棚 | 作るとき | 入れる記事 |
