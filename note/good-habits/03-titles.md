# タイトル案：good-habits（本文の仮題：毎日の朝食は、確かめると「良い習慣」のリストから外れた）

読者：20〜40代。良い習慣を作りたいが、何を習慣にすればいいか分からない一人。毎日の朝食・1日1万歩・感謝日記・SNS断ちのどれかを、一度は試したことがある。
決め方：タイムラインで止まるか・具体か・本文の約束と一致するか（`docs/content-quality.md` の 0）。静かさ・きれいさでは決めない。
守ったこと：命令・断定・結果の約束・あおり（すべき・必ず・人生が変わる・損）を使わない。健康の効果を言い切らない。「朝食を抜くとよい」と読める題・画像の文言・タグにしない。本文に書いていないことは入れない。サイトの題「『良い習慣』を確かめると、残ったのは地味なものばかりだった。」と同じにしない（近い案は案5だけ）。

## 2. いちばん推す案と理由

**案1「良い習慣とされる毎日の朝食は、9年後の死亡の少なさと結びつかなかった」**

1. **1行目で止まる。** 毎日の朝食は、多くの人が一度は勧められたことのある「良い習慣」の代表で、読者が自分のことだと思える。それが「9年後の死亡の少なさと結びつかなかった」は常識の反対で、「9年後」「死亡の少なさ」という具体がある。
2. **本文の約束と一致する。** 本文の1行目と最初の大見出しの話そのもので、題で引いたことは本文の最初の段落（1965年の米国の成人6,928人、ほかの条件をそろえた比較）ですぐ回収される。題は本文より強く言っていない（「朝食は意味がない」「体に悪い」とは書かない）。
3. **頭の「良い習慣とされる」が二つの役をする。** 一つは、確かめている相手が朝食そのものではなく「良い習慣」という評判だと分かること。「朝食を抜くとよい」とは読みにくくなる。もう一つは、朝食だけの記事ではなく、良い習慣全体の話だと題だけで分かること。検索で拾われやすい「良い習慣」「朝食」も前半に入る。
4. **言い切り・約束・あおりがない。** 過去形の結果（結びつかなかった）で、効果も、読んだあとの変化も約束しない。

弱み：34字で、目安の32字を少し超える。「死亡」は重い語。題は朝食の話だけなので、「上位に残ったのは地味な行動だった」という残りの半分は、記事の説明（6）に任せる。短くしたいときは案2。

### 次点

- **案4「毎日の朝食、感謝日記、SNS断ち。確かめると、根拠は弱かった」**：読者が試したことのある習慣が三つ並び、自分のことだと思う人の数はいちばん多い。本文の3つ目の大見出し（評判の良い習慣の中に、根拠の弱いものがあった）と一致する。案1の下にしたのは、「根拠は弱かった」が「9年後の死亡の少なさ」より抽象で、「確かめると」が何で確かめたかを言っていないから。X の1行目の材料にもなる（SNS担当へ）。
- **案3「『ブレスローの7つの健康習慣』は、9年追うと5つに減った」**：固有名詞と数字でできていて、朝食に触れないぶん誤読の心配がいちばん少ない。外れた2つが何かを知りたくなる。案1の下にしたのは、ブレスローの名を知らない人には一瞬で何の話か伝わらず、いちばん身近な「毎日の朝食」が題から消えるから。

### 採らなかった主な理由

- 案2：短く、止まる力は案1に近い。「良い習慣」の枠がないぶん、朝食だけの記事に見え、「朝食は要らない」と受け取られやすい。案1が長すぎるときの代わり
- 案5：サイトの題に近い案。短く分かりやすいが、数字がなく、「残らなかった」は比喩。サイトの題と並ぶと区別がつきにくい
- 案6（本文の仮題）：「リスト」がどのリストか分からない。日本で知られている7つの一覧には、いまも朝食が入っている（本文 [2]）。食べ方の2項目を外したのはその後のアラメダ郡の解析（本文 [3]）なので、題だけ読むと、一覧そのものが改められたように読める
- 案7：読者の迷いには当たるが、驚きがなく、良い習慣のどの記事にも付けられる題になる
- 案8：本文の最後の問いで、ムートンらしさはいちばん強いが、題だけでは何の記事か分からず、一覧で素通りされやすい。コピー第一で後ろに下げた

### 題に使わなかった材料

- 「朝食をとった群のほうが、体重は0.44kg重かった」：先に出すと「朝食は太る」と読まれる。リサーチの注意どおり、本文の2つ目の一撃にとどめる
- 「6つそろった人は、40歳時点の平均余命が男性で10.3年長い」：観察研究の上限の値で、題にすると長生きの約束に読める
- 「1日1万歩は研究から導かれた数字ではない」：本文では1文の扱いで、リサーチでは研究ノートの推論とされている
- 「間食をしない」が外れたこと：題に入れると「間食してよい」と読まれる。本文もそこまでは言っていない

## 4. 見出し画像の文言

スマホの一覧では見出し画像が小さく出るので、2行に分けて大きく置ける長さにした。

1. **毎日の朝食は「良い習慣」か**（13字）← 推す
   - 2行なら：毎日の朝食は／「良い習慣」か
   - 題（案1）と並ぶと、画像が問い、題が答えになる。X に URL を貼ったときのカードは画像が大きく出て、題は小さいか出ないことがあるので、画像の文言だけで何の話か分かる形にした。問いの形なので、朝食を否定するだけの文には読めない
2. **7つの健康習慣、残ったのは5つ**（15字）
   - 2行なら：7つの健康習慣、／残ったのは5つ
   - 数字で止める案。外れた2つの一つが朝食だと、題と本文で分かる。案3を題にするなら、こちらと組む
3. **良い習慣、確かめたら地味だった**（15字）
   - 2行なら：良い習慣、確かめたら／地味だった
   - サイトの題の結論を短くしたもの。題が朝食の話だけなので、残りの半分を画像で見せる組み合わせ

画像に入れないもの：「死亡」（小さな画像では文脈が抜け、脅しに見える）。「朝食は外れた」「朝食は要らない」のように、朝食を否定するだけに読める文。

## 6. 記事の説明（note の「記事の説明」欄）

米国の6,928人を9年追った研究で、毎日の朝食は死亡の少なさと結びつかなかった。抜くほうが良いという話ではない。寿命や病気で確かめて残った「良い習慣」は、吸わない・歩く・飲みすぎないといった地味な行動だった。（105字）

題と同じ話を繰り返さないよう、頭に研究の範囲（米国・6,928人・9年）を置き、題に入らなかった残りの半分（上位に残った行動）で締めた。「抜くほうが良いという話ではない」は、本文の朝食の節の最後の段落と同じ線。
