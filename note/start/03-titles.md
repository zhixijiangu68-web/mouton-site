# タイトル・見出し画像・ハッシュタグ（はじめての方へ）

MOUTON — PHILOSOPHY OF LIFE。生き方が変われば、行動が変わる。哲学を知識で終わらせず、自分の人生に落とし込むためのブランドです。正しい生き方は押しつけず、考えるための問いと、試すための方法を置いています。

## サイトの本文との違い

本文はサイトのまま。次の4か所だけ、note に合わせて変えた。

- 3人の入門記事へのカード → note の無料記事への案内（`{URL_FREE_*}` に note の URL を入れる）。
- 「変わる順番」の5つの段にあった、サイトの記事へのリンク → 外した。
- 「動画を探し回るより、一冊を読んで、試してみる。」→ 清潔感の科学（サイトで準備中の PDF）を外し、3人の有料記事だけに（`{URL_PAID_*}`）。
- 「お金の出どころを隠さない。」→ 「有料の記事と PDF」を「有料の記事」に。note には PDF の配布をまだしていないので。サイトの販売の状態が変わったら合わせて直す。

## 公開するとき

1. 有料3本と無料の入門3本を先に公開し、URL を控える。
2. `article.md` の `{URL_FREE_*}`・`{URL_PAID_*}` を、その URL に置き換える（置き換え忘れが残っていないか、公開前に検索して確かめる）。
3. `article.md` を note のエディタに貼る。見出し画像・説明・ハッシュタグを設定して公開。
4. プロフィールの最初の記事に置く。
