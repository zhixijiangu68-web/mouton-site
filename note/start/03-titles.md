## サイトの本文との違い

本文はサイトのまま。次の4か所だけ、note に合わせて変えた。

- 3人の入門記事へのカード → note の無料記事への案内（`{URL_FREE_*}` に note の URL を入れる）。
- 「変わる順番」の5つの段にあった、サイトの記事へのリンク → 外した。
- 「動画を探し回るより、一冊を読んで、試してみる。」→ 清潔感の科学（サイトで準備中の PDF）を外し、3人の有料記事だけに（`{URL_PAID_*}`）。
- 「お金の出どころを隠さない。」→ 「有料の記事と PDF」を「有料の記事」に。note には PDF の配布をまだしていないので。サイトの販売の状態が変わったら合わせて直す。

## 公開するとき

無料の20本の1日目（世界観）に出す（`note/series-30/plan.md` の「公開の順番」）。

1. 入門3本と同じ日に出す。本文の `{URL_FREE_*}` を、入門3本の URL に置き換える（公開キット（`note/README.md`）なら URL を入れるだけ）。
2. `article.md` を note のエディタに貼る。見出し画像・説明・ハッシュタグを設定して公開。1日目の最後に公開すると、プロフィールの一番上に来る。
3. 有料3本を出す日に、`paid-section.md` の節を足す（「人の助けと自分の選択」のあと）。いまは有料記事への案内を外してある。
