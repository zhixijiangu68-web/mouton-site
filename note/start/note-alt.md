# はじめての方へ：note 版だけ「気づかせる」に寄せる案（オーナーが決める）

`article.md` は、サイトの「はじめての方へ」と同じ文（`CLAUDE.md` の note の節：入門3本などと同じく、サイトの文を写したもの）。ただ、「変わるには、順番がある」の五つは、やり方の手順と書き込みの指示（「「僕は、〜する人間だ」と書く」「書き出すと」）になっていて、note の無料記事の形（やり方とワークは置かない。`BRAND.md`「気づかせる」）とずれる。「今日から始めてみてほしい」も、読者に行動を頼む言い方になっている。

どちらにするかはオーナーが決める（2026-10-18、Claude の案）。

- **A：このまま**（サイトと同じ文）。はじめての方へは、ブランドの説明の記事なので、ほかの無料記事と形が違ってよい、という考え方。
- **B：note 版だけ、下の2か所を置き換える**。中身（五つの順番）は残し、手順を問いの形にする。サイトの文は変えない。

B にするなら、Claude に「はじめての方へを B に」と言えば、`article.md` を置き換えて、公開キットを作り直す。

## B の置き換え1：「変わるには、順番がある。」の節

```text
## 変わるには、順番がある。

行動から変えようとして、続かなかったことはないだろうか。僕は、変わるには順番があると考えている。あなたがいまどこでつまずいているかで、読むものも変わる。

1. **どんな人間でありたいか**
お金も、評価も、誰かに見られることもなかったら、どんな人間でありたいか。持っているものではなく、在り方の問い。

2. **「僕は、〜する人間だ」と言えるか**
結果（いくら稼ぐ、何キロ痩せる）ではなく、やり方で言えるか。たとえば「自分との約束を守る人間だ」。その一文があると、迷ったときの基準になる。

3. **考えと感情を、道具として見ているか**
自分次第のことと、そうでないことを、分けているか。湧いてきた感情は、いまの自分の役に立っているか。

4. **小さく、引き算で動けているか**
不安が消えるのを、完璧な計画ができるのを、待っていないか。何かを足す前に、邪魔をしているものが一つあるのではないか。

5. **結果は、遅れてやってくる**
行動は今日から変えられる。けれど、結果と自己像は遅れて追いついてくる。何も変わらないように見える冬のような時期を、自分を責めずに過ごせるかどうか。
```

## B の置き換え2：「人の助けと自分の選択」の節の最後

いまの文：

```text
人生は短い。
小さくても、今日から始めてみてほしい。
```

置き換える文：

```text
人生は短い。
何を始めて、何をやめるのか。選ぶのは、いつもあなただ。
```

（冒頭の「何を始めればいいか、だけでなく、何をやめれば、本当に大切なことに向き合えるか。」「どう生きるかを選ぶのは、いつも自分自身だ。」と呼応させた。）
