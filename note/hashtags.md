# note のハッシュタグ

オーナー：「ハッシュタグに一貫性を持たせたい」（2026-10-17）。どの記事も、同じ決まりで5つ付ける。
新しい記事を書くとき（`/note`、`note-titler`）も、この決まりと下の一覧から選ぶ。

## 決まり

1. **#MOUTON**：全部の記事。タグを押すと、ムートンの記事だけが並ぶ。
2. **#哲学**：全部の記事（MOUTON — PHILOSOPHY OF LIFE）。
3. **種類を1つ**：30本と目次は **#30の不安**。入門と有料は、哲学者の名前（#キルケゴール・#ニーチェ・#スピノザ）。はじめての方へは **#自己紹介**。
4. **テーマを2つ**：下の一覧から選ぶ。一覧にない言葉を使いたいときは、先に一覧に足してから使う。同じ意味の言い換えは作らない（#習慣化 → #習慣、#やる気が出ない → #やる気、#人と比べてしまう → #焦り）。
5. **使わないもの**：研究の用語（#実行意図 など）、1本にしか合わない言葉（#休日 など）、答えややり方を思わせる言葉（#最初の一歩・#習慣設計・#書き込みワーク。「気づかせる」形と合わないため）、哲学者以外の人名。

数は5つ。note の公式の上限は確かめられなかった。note の勉強会で「3つくらいでよい」と聞いた、という書き手の記事がある（公式の情報ではない）。

## テーマの一覧

- 動けない・続かない：#先延ばし　#やる気　#習慣　#三日坊主　#意志力　#集中力　#スマホ　#朝活
- 場面：#勉強　#運動　#副業　#仕事
- 決められない・人の目：#決断　#後悔　#不安　#人の目　#人間関係　#緊張　#焦り
- 何のために：#価値観　#生きる意味　#生き方
- 自分を責める：#自己肯定感　#完璧主義　#感情
