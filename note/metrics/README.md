# note の数字の記録（2026-10-18）

何を見て、何を変えるかは `note/next-30/plan.md` の「計測と改善」。ここは、その数字を残す場所。

- **オーナー**：週に1回、note のダッシュボード（記事ごとのビュー・スキ・コメントが見える画面。期間は「週」と「全期間」）のスクリーンショットと、フォロワー数を Claude に渡す。有料が売れたら、売上画面の件数と日時も。
- **Claude**：スクリーンショットから `weekly.csv` に1行ずつ起こし、その週の振り返り（次に変えることを3つまで）を `promo/log/YYYY-MM-DD.md` に書く。
- **売れた件数が最後の物差し**。ビュー・スキ・フォロワーは、売れたことの代わりにしない（`CLAUDE.md`）。

## weekly.csv の列

| 列 | 中身 |
|---|---|
| 記録日 | Claude が起こした日（YYYY-MM-DD） |
| 期間 | 週 / 全期間（スクリーンショットの設定） |
| 記事 | 公開キットのキー（S30_01、N30_31、FREE_SPINOZA、PAID_CHOICE など） |
| 題 | 記事の題 |
| ビュー・スキ・コメント | ダッシュボードの数字 |
| 売れた件数 | 有料記事だけ（売上画面の数字） |
| メモ | 告知した場所、題や画像を変えた日など |

フォロワー数は、記事の列を `フォロワー` にして、ビューの列に数を入れる。
