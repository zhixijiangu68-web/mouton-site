# タイトル案：others-eyes（仮題：帰り道で、あの一言を再生してしまう。ニーチェの「何のための自由か」）

読者：20〜30代。転職・独立・人間関係の岐路にいて、「どう思われるか」で選んでしまう一人。
守ったこと：命令形・結果の約束（気にならなくなる・自由になれる）・あおり（損・手遅れ・知らないと・○割が知らない）・「誰でも」「必ず」を使わない。問いか、ムートンの経験の形。本文に書いていないことは入れない。研究の結果は本文の「〜らしい」「〜かもしれない」より強くしない。有料記事・値段・購入と、有料の目次語には触れない。
重ならないように照らした題：入門記事「その「すべき」は、誰の声なのか。」、有料記事「その選択は、誰の物差しで決めたのか。」、3つの姿勢「「このままで終わりたくない」と思ったら。」、先週の note「決められない夜に、「もっと調べる」をやめてみた。キルケゴールの一行」。もう一つ、連載のストア派「あの一言が、一日じゅう頭から離れない。エピクテトスが引いた一本の線」が仮題の「あの一言」と同じ言葉で、リードにも「頭の中で何度も再生してしまう」とある。そのため題には「あの一言」を使わない。「誰の声」「物差し」と、3つの姿勢の中央の一文「思っているほど、見られていない。」（X の順番表でも使っている）も、題と画像の文言に入れない。
文字数：全角・半角を問わず1字と数えた（「1883年」は5字）。

## 2. おすすめ 3 案と理由

1. **案1「人の目から、自由になりたかった。ニーチェの「何のための自由か」」**
   本文の折り返し（「人の目から自由になりたい。僕は長いあいだ、それを目標のように持っていた。けれど、この段に照らすと、それは「何からの自由」のほうだった」）を、題の前半と後半に分けて置いた。前半だけ読むと「人の目から自由になる」話に見え、後半の「何のための自由か」で向きが変わる。この動きは本文と同じで、題が本文より先に何かを約束することはない（「なりたかった」の先は書いておらず、本文も答えを書かずに問いで終わる）。読者がいま持っている言葉「人の目」が入るので、何の話かは一目で分かる。形はサイトの残す記事（「決められないのは、弱いからだろうか。キルケゴールの「自由のめまい」」）や先週の note とそろうが、言葉は重ならない。「何のための自由か」も「創造者の道」も、サイトのどこにもまだない、この note だけの言葉。弱みは、帰り道・冗談という場面が題にないこと。見出し画像の文言（4. の1）で補う。

2. **案2「帰り道で、自分の冗談を再生してしまう。ニーチェの「何のための自由か」」**
   仮題の形を残し、「あの一言」だけを「自分の冗談」に替えた（本文：「場を和ませようとして言った冗談だった」）。冒頭の場面そのままで、いま帰り道で再生している一人にいちばん近い。弱みは、前半（再生）と後半（自由）がどうつながるのか、題だけでは見えにくいこと。「人の目」という言葉も入らない。ストア派の記事も、一言が頭の中で繰り返される場面から入る（向こうは人に言われた一言、こちらは自分が言った冗談）ので、サイトから来た人には近く見えるかもしれない。

3. **案5「人の目から取り戻したいその自由を、何に使いたいのだろう」**
   本文の最後の問いから「あなたは、」を外した。「人の目」と「自由」が入るので、問いだけでも何の話か伝わる。27字で短く、答えではなく問いを渡す形にいちばん近い。弱みは、最後の問いを先に見せるので、読み終えたときの問いの重みが少し減ること。哲学者の名前もない。哲学者の名前が重く感じられるときの代わりに。

採らなかった主な理由：案3は本文の中央の一文で、いちばんムートンの声に近い。ただ、すぐあとに【本人が書く：いま「何のための自由か」と聞かれたら、言えること・言えないこと】が続く、本人の実感にかかった文で、本人が書いたあとで食い違えば題も直すことになる。「人の目」がないので、何からの自由かも題だけでは分からない（本人が確かめたあと、X の1行目などに向く）。案4は研究の結果を題に出すと、本文が添えている条件（米国の大学生や実験室の場面が中心、立場が上の人が弱みを見せた実験では逆、いつ誰にでも言えることではない）が落ちて、本文の「らしい」より強く読まれやすい。「思う（っている）ほど〜ない」の形も、3つの姿勢の中央の一文に近い。案6は研究の側の問いで、題にすると「相手は厳しく見ていなかった」という答えへ寄せる形になり、本文の中心（それでも止まらなかった、何のための自由か）から離れる。「あの〜を、」の書き出しもストア派の題に近い。案7は読者の姿を言い当てる形で、ムートンの経験にも問いにもなっていない。有料の販売ページの文（「何を選ぶにも先に「どう思われるか」を考えてしまって」）にも近い。案8は年の数字に引く力が弱く、解説の記事に見える。案9は、本文が「原文が二つの目を並べているわけではない」と断っているムートンの読み方で、題に出すと原文の対比のように読まれやすい。「君の目」だけでは何の話かも分からない。案10は本文の読み方の芯だが抽象的で、題だけでは場面が浮かばない。
