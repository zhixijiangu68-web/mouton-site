# タイトル案：french-roundness（外から来たものは、フランスで丸くなった（仮））

読者：フランスのもの（パン・言葉・家具）になんとなく惹かれていて、その「なんとなく」を言葉にしたい一人。
守ったこと：命令形・結果の約束・あおり・「絶対」「必ず」を使わない。問いか、ムートンの経験の形。テーマの一文（「フランス人の手にかかると、すべてのものが柔らかく丸みを帯び始める」）は出典が見つかっていないので、名言・ことわざに見える形にせず、「僕がそう思っていた」見方として扱う。本文の【要確認】の段落（ル・ノートルの庭、ル・クルーゼの創業者、マカロンの今の形）と、それに頼る言い方（ヴェルサイユ、「多くの国の手」）は使わない。本文に書いていないことは入れない。

## 2. おすすめ 3 案と理由

1. **案1「クロワッサンも英語も、フランスで丸くなったと思っていた。半分は外れた」**
   いちばん強い具体の名詞（クロワッサン）と、意外な組み合わせ（英語が丸くなる？）が頭に来るので、一覧で目が止まる。「〜と思っていた」でテーマの一文が僕の見方だと分かり、名言のようには見えない。「半分は外れた」は過去形の経験で、約束にならず、「どっちの半分が？」という読む理由になる。本文とのずれもない。英語は見出し「英語の言葉は、フランスの口で角が取れた」、クロワッサンは「形は外から来て、中身がフランスで変わった」「『丸くした』というより…作り直した」、外れた半分は「まっすぐなフランスもある」「形を変えた手の多くは、フランス人ではなかった」（ツァングはオーストリア人）。弱みは34字で目安の32字を少し超えることと、「英語も丸くなった」が一瞬分かりにくいこと（ただ、その引っかかりが止まる理由にもなる）。

2. **案2「フランスに来たものは丸くなる、と思っていた。確かめたら半分外れた」**
   本文の仮タイトル（外から来たものは、フランスで丸くなった）と冒頭の「確かめると、半分は当たっていた」をそのまま題にした形。32字に収まり、何の話かがいちばん素直に伝わる。弱みは固有名詞がなく、具体さで案1に負けること。案1の「英語も」が分かりにくいと判断されたときの代わりに。

3. **案5「クロワッサンは、フランスで『丸く』なったのだろうか」**
   25字と短く、問いの形。本文の答え（形はオーストリアから来て、生地はフランスで折り込みの生地に変わった。丸くしたというより作り直した）とまっすぐつながる。弱みは、題だけ見るとパンの記事に見え、英語の言葉・ソファ・国民性の研究まで広がる本文の幅が伝わらないこと。

採らなかった主な理由：案3はオーナーの言葉にいちばん近いが、具体の名詞がなく、「ものは丸くなる」が一般論の断定にも読める。案4は事実として面白いが、英字が多く一覧で読みにくく、何の記事か（フランスの丸み）が見えない。案6はソファの節だけの話で、本文の中心とずれる。案7の「r = .04」は本文を読む前の人には意味が伝わらない。案8は「すべてのもの」が何を指すかが題だけでは分からない（「まっすぐなフランス」の例は、ル・ノートルの段落が外れるとオスマンの十字だけになるので、題に出すのは控えた）。案9は共感の入り口としてよいが、「辞書と資料で確かめた」が抽象的で止まりにくい。案10は本文の結論だが抽象的で、止まる力が弱い。

## 3. 最終案

**クロワッサンも英語も、フランスで丸くなったと思っていた。半分は外れた**（全角 34 文字）

（32字に収めたいときは案2「フランスに来たものは丸くなる、と思っていた。確かめたら半分外れた」（32字））

## 6. 記事の説明（概要）

クロワッサンの元はオーストリアの三日月パンで、客船を指す paquebot は英語の packet-boat だった。「フランス人の手にかかると、ものは丸くなる」という僕の見方を辞書と公式の資料で確かめたら、半分は当たり、半分は外れた。
