### 2. 言葉と音：つなげて、ならして話す

- 2-1. リエゾン：ふだんは発音しない語末の子音（「潜在の」子音）を、次の語が母音で始まるときに発音すること [1]【要約・弱】
- 2-2. アンシェヌマン：もともと発音する語末の子音を、次の語の頭の母音とつなげて、間を切らずに発音すること。リエゾンの子音も、ふつうは次の音節の頭として発音される [2]【要約・弱】
- 2-3. フランス語の強勢は、単語ごとではなく、語のまとまり（groupe rythmique、一息で言うまとまり）の最後の音節に置かれる。文の中では、句の最後の音節に強勢が来る [3]【要約】。最後の音節は少し長くなるが強くはならず、ほかの音節はほぼ同じ長さで並ぶ（isosyllabisme）[2]【要約・弱】
- 2-4. リエゾンが起きるのは、同じ groupe rythmique の中だけ [2]【要約・弱】
- 2-5. 使い方：「音が角ばらずに流れる」の根拠として使えるのはここまで。「フランス語は柔らかい言語だ」と言い切る研究は見つけていない。聞いた印象は聞き手の母語で変わる、と一言添える

### 3. 外から来た言葉を、自分の口に合わせて作り変えた例

- 3-1. **redingote（ルダンゴト、長い上着）**：英語の riding-coat（乗馬用の上着。to ride と coat の合成）から借りた語で、18世紀から [4]【要約】。英語の側では、Merriam-Webster が「英語 riding coat のフランス語での作り変え」とし、英語での初出を 1793年とする [5]【要約】。英語の辞書どうしで初出の年は食い違う（Dictionary.com は 1825〜35年）[5]【要約】
- 3-2. **paquebot（パクボ、客船）**：英語の packet-boat（packet「包み」＋boat「船」）から借りた語で、17世紀から（アカデミー・フランセーズの辞書 第9版）[6]【要約】。Larousse は語の出現を18世紀とし、もとはカレー〜ドーヴァーなどの間で郵便を運ぶ船だったと書く [7]【要約】。年は辞書どうしで食い違う
- 3-3. **boulingrin（ブランガン、刈り込んだ芝生）**：英語の bowling green から。ケベック州のフランス語局（OQLF）は、もとは遊ぶ場所を指し、のちに遊びそのものも指すようになったとする [8]【要約】。アカデミー・フランセーズの辞書（第7版、1878年）は「庭や公園で刈って手入れする芝生」と定義する [9]【要約】
- 3-4. 使い方：packet-boat → paquebot、riding-coat → redingote、bowling green → boulingrin は、子音のかたまりがほどけ、フランス語の音の並びにならされた例として、並べて見せられる。ただし「柔らかくした」は書き手の見立て。辞書が言っているのは「英語から借りて形を変えた」まで

### 8. 「フランス人は〜」とくくる危うさ

- 8-1. 49の文化の 3,989人に「自国の人の典型的な性格」を評価してもらい、その国の人の実際の性格の平均（本人と周りの人による評価）と比べた研究では、典型像の評価はそろっていた（信頼性は高かった）が、実際の性格とは一致しなかった（相関の中央値 r = .04）。著者らは、国民性の認識は根拠のない固定観念で、国としての一体感を保つ働きをしているのかもしれない、と結論した [38]【要約】
- 8-2. この調べで挙げた例のうち、クロワッサンの元はオーストリアのパン（持ち込んだのもオーストリア人）、ル・クルーゼの創業者はベルギー人、DS のデザイナーはイタリア生まれ、ポランの椅子を作ったのはオランダの会社だった。「フランス人の手」は、実際には多くの国の手だった [10][27][34][40][41]（ベルトーニは 6-4 の注意のとおり【要約・弱】）
- 8-3. 使い方：8-1 と 8-2 を合わせて、「国の性格ではなく、ある時代の、ある人たちの選び方」として書く。8-1 は国民性の研究で、デザインの研究ではない点は書き添える

## 記事の切り口の候補

### 案A（推薦）：外から来たものが、フランスで丸くなる

- 芯：packet-boat → paquebot、riding-coat → redingote、bowling green → boulingrin、キプフェル → クロワッサン、maccherone → マカロン。外から来たものを、自分たちの口と手に合わせて作り変える。その結果が、ときに「丸み」に見える
- 流れ：一文（オーナーの言葉、出典なしと明記）→ 音（リエゾン・アンシェヌマン・句の最後の強勢）→ 言葉の作り変え3つ → パンとお菓子 → 部屋（Togo・ル・クルーゼ）→ 反対の例（ル・ノートル・オスマン）と、作り手の多くはフランス人ではなかったこと（8-2）→ 国の性格ではなく選び方、で締める → 色の柔らかさとしてサイトへ
- 推す理由：辞書・博物館・公式の資料で確かめた例がいちばん厚い。「柔らかくする＝自分に合わせて作り変える」と言い直せるので、20〜40代の読者が自分の装い・部屋に引き寄せて読める。暮らし・趣味の棚の書き方（結論から、宣伝しない）にも合う

### 案B：丸いフランスの道具と家具

- Togo、ル・クルーゼ、ギマールの入口、DS、リボン・チェアを年代順に並べ、それぞれの作り手と年を事実で書く。最後に、作り手の国がばらばらなこと（8-2）を明かす
- 弱み：公式の資料で確かめられたのは Togo（年・台数）とル・クルーゼ（1925年）ぐらいで、DS・2CV・ビバンダムは数字が割れる。読み物としては商品紹介に寄りやすい

### 案C：この一文は、どこまで本当か

- 一文を立て、例（音・言葉・パン）と反例（直線の庭・十字の大通り・まっすぐなクロワッサン）と固定観念の研究 [38] で、どこまで言えるかを確かめる
- 弱み：判定表の型に寄り、暮らし・趣味の 2,000〜4,000字の note では重い。オーナーの書きたい一文を崩す方向に読まれるおそれ

→ **案A で進める**。案C の反例（7）と固定観念の研究（8-1）は、案A の後半に一段落ずつ入れる
