## 読者の疑問（5個）

1. 言ったことをやり遂げる人は、誠実な人なのか。「有言実行の人」を信じてよいのか
2. 言ったのにできなかった自分は、不誠実なのか。どこからが「嘘」になるのか
3. 「有言実行」は昔からの美徳なのか。孔子や武士道はどう言っていたのか
4. 約束を守れなかったあと、信頼を左右するのは何か。謝れば戻るのか
5. （サイトへの引き）目標は人に言ったほうがいいのか、言わないほうがいいのか

### (c) 「有言実行」は近代の造語だった

- 不言実行は、日本国語大辞典で1914年の原田棟一郎『紐育』が最も古い用例とされ、漢籍の出典は示されていない [42]
- デジタル大辞泉は有言実行を「「不言実行」からつくられた語」と書く。意味は「発言したことを責任をもって実践すること」。日本国語大辞典は「言ったことは必ず実行すること」に加えて、「格別に言いたてて事を行なうこと」という二つ目の意味を載せている [3]
- 確かめられた最も古い用例は1924年の大阪毎日新聞。**ただし Wiktionary の記載によるもので、元の紙面は見ていない** [4]（調査ノートのみ：記事名は「移民の必要とその理想」、文は「有言実行益々可なりである。」。サイト記事には書いていないので、note に入れるなら「Wiktionary の記載では」と添える）
- 1965年、佐藤栄作首相が衆議院本会議で「有言実行、そこに民主主義のルールがあるのだ」と答弁 [44]
- 1975年、片山甚市議員「不言実行でなく、言葉あり実行する」 [5]
- 1977年に福田赳夫首相は「私は言ったことは必ず実行します」と述べた。1979年に大平正芳首相は、有言実行の趣旨を実行に移し、建前と本音のずれが生じないようにすることが政治の要だ、という趣旨の答弁をした [5]
- 国会会議録には、1947年から1985年末までに「有言実行」を含む発言が49件ある [5]
- 落合博満が起源だという説は、書いた本人が根拠はないと明記している [45]（知恵袋。根拠には使わず、俗説を退ける材料としてだけ使う）
- サイト記事の読み：有言実行は、公の言葉は守られないものだという前提、つまり建前の文化への処方箋として値打ちを得た。誠実を測る物差しが、心という内側から、確かめられる結果という外側へ移っていく近代化の一場面として読める（サイト記事の解釈。事実として書かない）
- 字の成り立ち（関連）：「誠＝言＋成＝言ったことを成す」は字の成り立ちとしては支持されない。『説文解字』は誠を「信也。从言，成聲」とし、成は音を示す部分 [1]。白川静『字通』が成に読み込む意味も「神に誓約し、それをまことにする」で、後で実行することではない [2]。**留保：藤堂明保『漢字源』の記述は未確認**（サイト記事の判定の留保点）。note では使っても1文まで

### (b) 孔子と孟子は「言えば必ず守る」を最上の徳としなかった

- 『論語』子路第十三：子貢が「士」の等級を尋ねた章で、孔子は「言必信，行必果，硜硜然，小人哉，抑亦可以爲次矣」と答えた。言えば必ず守り、やると決めたら必ずやり遂げる者は、融通のきかない小人物だが、それでも三番目には入れてよい、という評価 [39]
- 『孟子』離婁下：「大人者，言不必信，行不必果，惟義所在」（立派な人は、言ったことを必ず守るとは限らず、始めたことを必ずやり遂げるとも限らない。ただ義のあるところに従う） [40]
- 後漢の趙岐はこれに「義或重於信」（義は信より重いことがある）と注した。宋の孫奭は、孔子が蒲の人々と結ばされた誓いの後もなお衛へ向かった話を、信に縛られない行いの例に挙げている [41]
- 『論語』が示す順番は「行いが先、言葉が後」。為政第二「先行其言，而後從之」（まず行い、言葉はそれに従わせる） [6]。里仁第四「君子欲訥於言而敏於行」「古者言之不出，恥躬之不逮也」 [38]
- 押さえておく読み（サイト記事）：昔の人が言わなかったのは、行いが言葉に追いつかないことを恥じたから。この理屈は「口にした以上は実行しなければならない」という前提を含む。孔子は言葉の重さを否定したのではなく、重いからこそ言葉を絞れと説いた。**「孔子は約束を守らなくていいと言った」と読める書き方にしない**
- 限界：朱熹『孟子集注』離婁下の注の原文は未確認（サイト記事に明記）。調査ノートにある「記憶による通行本文」は使わない

### (a) 嘘をつかない人と、やり遂げる人は、別の特性として測られた（中心）

- 16研究（4,855人）をまとめ直した分析で、HEXACO という性格モデルの「正直さ–謙虚さ」は、1段階（1標準偏差）高いごとに、不正をする見込み（オッズ）をほぼ半分にした（オッズ比0.53） [7]
- 日本で「誠実性」と訳される Conscientiousness は、それだけで見ても0.86にとどまり、正直さ–謙虚さをそろえると0.94で、効果がないことを支持する証拠のほうが強かった [7]
- 訳語：Conscientiousness は日本で「誠実性」と訳されることが多いが、日本語版の短い尺度（TIPI-J）は「勤勉性」を採っていて [34]、ほかに良識性・統制性・堅実性などの訳もある [35]。中身は達成への努力・秩序・自制・義務への忠実さで、倫理の誠実よりも、有言実行の「やり遂げる」側に近い（サイト記事）
- 逆に Conscientiousness は、92のメタ分析（参加者110万人超）をまとめた研究で、仕事にかかわる変数の98%と望ましい向きに関係し、仕事の成果を予測する、能力以外で最も強い特性とされた [8]
- 職場での規則を破る行動は両方と関係していた（正直さ–謙虚さはマイナス0.48、Conscientiousness はマイナス0.37〜0.40）。HEXACO 全体で説明できる部分のうち、57%を正直さ–謙虚さが、33%を Conscientiousness が担っていた [77]（note では入れなくてよい。入れるなら「両方とも関係はあった」という公平さのため）
- サイト記事の2×2の表：Conscientiousness が高く正直さ–謙虚さが低い人は「確実に成果を出すが、事実を偽ったり、倫理の近道をとったりしうる」。有言実行の実績だけで人を見ると、この人を見分けられない
- 限界・注意：
  - 不正の測り方は、調査ノートのみの情報で、一回きりの報酬つきのコイン投げ・サイコロの自己申告課題。サイト記事には書いていない。入れるなら数字を足さずに「お金のかかったコイン投げのような課題」程度
  - 「オッズ比0.53」と、(f) の Sheeran の「0.53」を同じ note に並べない
  - 「Conscientiousness の高い人は不正をする」とは言えない。言えるのは「正直さをそろえると、不正をほぼ予測しなかった」まで

### (e) 守れなかったとき、効いたのは謝罪の言葉より応答の誠実さ

- Tomlinson ら（2004）：約束が破られた後、和解しようという気持ちを高めた要因（大学院生45人×48の場面。影響の大きさは標準化係数） [18]
  - 相手の応答が誠実であること 0.343
  - また破られる見込みが低いこと 0.260
  - それまでの関係の質 0.230
  - 謝罪があること 0.073
  - 応答が早いこと 0.065
  - 自分の責任だと認めること 0.033
- サイト記事の表現：「形だけの謝罪の言葉より、応答の誠実さのほうが約5倍の重みを持っていた。誠実さを最も重く見た回答者は51%に上った」 [18]（「約5倍」はサイト記事の言い方。note でもこのまま写す）
- 7回続く信頼ゲーム（262人）：裏切る行いだけで損なわれた信頼は、その後に信頼に足る行いを続ければ戻りうるが、欺きで損なわれた信頼は完全には戻らなかった。約束は最初の回復を早めたが、欺きの後ではその効果が弱まった。著者らは、守れない約束をしないよう気をつけるべきだ、と実務への提言をまとめている [17]
- 疑いが能力にかかわる場合は謝罪のほうが、インテグリティ（誠実さ）にかかわる場合は（本当に無実なら）否定のほうが、見られ方を高めた。能力の場合は謝罪5.32、否定4.27、インテグリティの場合は謝罪2.73、否定4.39。どの応答でも信頼は完全には戻らなかった [16]
- 黙っていることは、米国でもシンガポールでも、最もよい応答に劣った [88]
- 心の契約が破られた後の修復の方法を比べた2つの実験（918人）では、否定以外のすべての方法が信頼を高め、全面的な埋め合わせが最も効果的だった [89]
- 経営大学院の修了者128人を追った調査では、54.8%が入社後2年以内に雇い主との「心の契約」が破られたと答えた [87]（「約束が破れることはありふれている」の材料）
- サイト記事の整理（ずれの六つの形）：話した時点の誠実さに反するのは「不誠実な有言」だけ。心変わり・正当な不履行は、後から否定する・黙る・守ったふりをすると不誠実に変わる。誠実が働く場面は「言う前」と「守れないとき」の二つ。→ note ではこの二つの場面の一文だけを見せ、六つの表はサイトに残す
- 関連する哲学（案B 用、使っても1文）：アクィナスは、約束したことをするつもりで約束したなら、その人は嘘をついていない、後で心変わりして果たさなければ欠けているのは信義のほうだ、と答えた [23]。田中一弘は、実行する意図も能力もない約束は「未来についての嘘」になるとした [26]
- 限界：
  - Tomlinson は大学院生45人が想定の場面を判断した研究（実際の約束破りではない）
  - 文化：日本でも、インテグリティの違反の後の謝罪が逆効果になる Kim らの結果が再現された（大渕ら、科研費の報告） [98]。一方、日本人はインテグリティの違反の後に謝った人に、より多くの責任を任せた（Maddux ら、米国との比較） [97]。サイト記事は、比べているものが違うので両立しうる、とする
  - 「謝っても意味がない」とは書かない。謝罪の係数は小さいがゼロではなく、Henderson らでは謝罪も信頼を高めた [89]

### (d) サイトへの引き用（note では1〜2文。ここは正確に写しておく）

- Gollwitzer ら（2009）：「法律家になる」「臨床心理士になる」といった自分のあり方にかかわる意図を人に認められた人は、その後の努力が減った（4つの研究） [9]。**限界：参加者は合わせて約160人と少なく、効果は大きすぎ（差の大きさは最大1.10）、片側だけの検定も含む。そのまま繰り返した追試は見つからなかった**
- 事前登録を含む4つの追跡研究（1,035人）では、目標を人に話すよう指示すると、受ける支えと努力が平均で0.20ほど増えた [10]
- 自分より立場が上の相手に目標を伝えると、目標へのこだわりと成績が上がり、立場が下の相手に伝えても、誰にも伝えない場合と変わらなかった（Klein ら 2020） [11]
- インドの村の実地実験では、村人を貯金の目標の「見届け役」にくじで割り当てると、貯金が平均36%増え、村の人間関係の中心にいる見届け役ほど効果が大きかった（Breza・Chandrasekhar 2019） [12]
- 進み具合の記録を促す介入138研究（1万9951人）では、目標の達成に0.40の効果があり、進み具合を人に報告したり公開したりする場合に効果が大きかった [13]
- **崩れた研究**：「自分で決めた締め切りより、外から決められた等間隔の締め切りのほうが成績がよい」とした Ariely と Wertenbroch の2002年の研究は、追試で同じ結果が出ず [63]、データの改ざんが指摘されて [64]、2026年9月2日に撤回された [65]。書類の冒頭で正直さを誓う署名をさせると不正が減るとした2012年の研究も、事前登録の大規模な追試で再現されなかった [66]
- サイト記事の判定表：「目標は人に言うと、かなわなくなる」は △（確かさ 低）、「確かめてくれる相手に宣言すると、実行しやすい」は ○（確かさ 中）
- 引きの文の案：「では、目標は人に言ったほうがいいのか。この問いは研究でも逆向きに割れていて、分かれ目は『誰に、何を言うか』にあった。続きはサイトに書いた」（約束・断定にならない言い方で）

### (f) 使うなら1文（参考）

- 10本のメタ分析（あわせて422研究）をまとめた Sheeran（2002）では、意図と行動の関係の強さは0.53で、行動のばらつきの約28%しか説明しなかった。やるつもりだった人のうち、実際にやったのは53%だった [19][56]
- 注意：サイト記事の出典 [19] は Sheeran・Webb（2016）のレビュー、[56] は Gollwitzer らの章で、Sheeran（2002）の原典は直接開いていない（調査ノートの Gaps に明記）。note で使うなら「やるつもりだった人のうち、実際にやったのは53%だった」だけにする

- **字の成り立ち**：藤堂明保『漢字源』の記述が未確認。藤堂の説明が「成」の意味を誠に読み込んでいる場合、「俗説」と言い切るのは強すぎる（調査ノート）
- **孟子の注**：朱熹『孟子集注』離婁下の注は原文未確認
- **公言の効果**：「言うと努力が減る」（Gollwitzer ら 2009、約160人、追試なし）と「言うと支えと努力が小さく増える」（Peetz ほか 2025、1,035人）が逆向き。サイト記事は「自分のあり方の目標×認めるだけの聞き手」と「成果の目標×確かめる聞き手」の違いとして、「おそらく矛盾しない」と読む
- **言行一致と信頼の0.78**：測っているものの重なりを含み、研究の多くは一時点の調査 [14]
- **日本のデータ**：日本で言行一致の尺度を使った組織の研究も、目標の公言や約束を守ることを扱った査読つきの実験も見つからなかった（サイト記事）。東アジアの比較研究（Friedman ら 2018）に日本は含まれていない [93]
- **言行一致と道徳の比較**：信頼の予測では言行一致が強く（0.78と0.67、別々のメタ分析の比較）、上司と部下の関係の質ではフィンランドの研究で道徳的なふるまいが最もよく予測した [14][86]。言行一致と道徳を別々に操作して同時に確かめた研究は見つからなかった

## 記事の切り口の候補

### 案A（推薦）：「有言実行の人」が、誠実とは限らなかった

- 1行目の候補：「有言実行は、昔からの教えではなかった。確かめられた最も古い用例は、1924年の新聞だった。」または「言ったことを必ずやり遂げる人を、孔子は三番目にしか置かなかった。」
- 流れ：(c) 1924年の造語 → 問い「言ったことを守る人は、誠実な人なのか」→ (b) 孔子・孟子 → (a) Heck と「誠実性」の訳語 →【本人が書く】→ (e) 守れなかったときに効いたもの → (d) の引き → サイトへ → 最後の問い
- 最後の問いの候補（サイト記事と同じ問いにすると、サイトに入ったときに続いて見える）：「守れなかった約束を思い出したとき、ずれていたのは言葉と心だったのか、言葉と行いだったのか。」
- 推薦の理由：サイト記事の見出しと同じ主張で、note とサイトの約束が一致する（見出しで引いて本文で裏切らない）。意外な事実（造語・孔子・訳語）が3つ続き、段落ごとに読む理由がある。(e) で読者自身の「守れなかった約束」に引き寄せられる。公言の話・六つの形・西洋の約束論・組織の研究はサイトに残るので、続きを読む理由が残る

### 案B：守れなかった約束は、いつ「嘘」になるのか

- 流れ：場面（守れなかった約束を思い出す夜）→ アクィナス [23] と田中一弘「未来についての嘘」[26] → (e) Tomlinson・Schweitzer → 問い
- 良い点：読者の疑問2に最も深く答える。自分を責めている読者に効く
- 弱い点：サイト記事の見出し（誠実≠有言実行）の中心データ (a) が入りにくい。哲学の引用が増え、2,000〜4,000字では薄くなる。六つの形を先に出しすぎると、サイトの続きの中身を食う

### 案C：「目標は人に言うな」は、証拠に比べて強すぎた

- 流れ：よく聞く助言 → Gollwitzer 2009 と限界 → Peetz・Klein・Breza → Ariely の撤回 → 誠実の話へ
- 良い点：自己啓発の常識の反対で、止まる力は強い
- 弱い点：誠実と有言実行の関係というサイト記事の中心から外れ、公言の研究紹介になる。`habit-design.html` の領域と重なる。数字が多く、公平に書くと note の字数に収まりにくい

**推薦：案A**。案B のアクィナスは (e) の段落に1文だけ添えられる。案C は (d) の引きとして最後に1〜2文で使う。

### ムートン本人が書く欄（空けておく）

- いま、言う前に何を確かめているか（読者への手順にしない。自分のことだけ）
