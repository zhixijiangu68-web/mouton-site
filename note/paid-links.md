# 無料の記事から、有料記事への案内（2026-10-18）

オーナー：「無料の記事に有料記事のリンクを貼りたい」。

## 決まり

- **有料記事を note に出して、URL ができてから足す。** 下書きの URL ではリンクにならない。有料記事より先に、特定商取引法の表記の記事を出す（`note/legal/tokushoho.md`）。
- **一つの無料記事に、案内は一つだけ。** 場所は、最後の問い（注意の一文がある記事は、そのあと）と「## 参考」のあいだ。区切り線のあとに置く。本文は変えない（`BRAND.md`「気づかせる」の「無料は問い、有料は答え」）。
- 入門3本・はじめての方へ・目次・習慣設計は、各フォルダの `paid-section.md` の場所と文面。
- 文面は、題と副題と URL だけ（下の「案内の文面」）。値段は note の購入画面に出るので書かない。あおらない。
- **公開キット**：有料記事のカードに URL を入れると、案内先の無料記事の「本文をコピー」に案内が入る。公開ずみの無料記事は、カードの「有料記事への案内をコピー」でコピーし、note で記事を開いて「編集」→ 最後の問いのあとに貼って「更新」。

## 案内の文面

```text

（副題）
（有料記事の URL）
```

題と副題は、有料記事の出品シート（`paid-*/listing.md`）のタイトルを「——」で分けたもの。16 だけは、問いの答えを書いた記事なので「この問いの先を、有料の記事に書いた。」で始まる別の文面（`paid-choice/link-from-16.md`）。
