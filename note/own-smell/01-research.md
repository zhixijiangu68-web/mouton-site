## 読者の疑問（5 個）

1. 自分のニオイは、なぜ自分では分からないのか。本当に分からないものなのか
2. 汗をかいたら臭うのか。汗そのものが臭いのか
3. 体のどこが臭いやすいのか。毎日ちゃんと洗っているのに臭うことはあるのか
4. ニオイは、相手の印象をどれくらい変えるのか（はっきり「臭い」と思われなければ平気なのか）
5. 自分で確かめる方法はあるのか。何から手をつければいいのか（気にしすぎの場合はどうするか）

## 分かっていること

番号は下の「参考文献」。すべて「サイト記事の要約による。原著は未確認」。

### 1. 自分のニオイに気づきにくい理由（嗅覚の順応）

- 人の嗅覚には、同じ匂いを嗅ぎ続けると感じにくくなる「順応」という性質がある [1]
- **ただし、この研究は体臭そのものではなく、嗅覚の順応一般を扱ったもの**（odor-care.html でもこの断りを入れている）。「自分の体臭に気づきにくい可能性がある」までは言えるが、「自分の体臭は自分では分からないと証明された」とは書けない
- 口臭については、口臭外来を受診した 2,000 人のうち「16％は仮性口臭・口臭恐怖と診断された」[11]。つまり**自分の鼻での判断はずれる**。ずれ方は「気づかない」方向だけでなく、「実際は問題ないのに気にしている」方向もある。歯周病の口臭は本人の自覚が乏しいことがある、と halitosis.html は書いている（同記事の出典は e-ヘルスネット等。原著未確認）

### 2. 汗とニオイの関係（汗そのものより「菌の分解物」）

- 脇では、分泌された時点では匂いの弱い前駆物質を、皮膚の細菌が酵素で分解することで匂い成分が生じる [2]
- → 「汗＝臭い」ではない。汗は材料で、ニオイは菌が作る。冒頭の「常識の否定」に使える材料
- 制汗剤はおもに汗そのものを抑え、デオドラントはおもに菌の増殖や匂いを抑える製品が中心 [8]（deodorant-guide.html の冒頭クイズ「制汗剤とデオドラントは同じものである。○か×か」もこの材料）

### 3. 主な発生源その1：脇（遺伝的な個人差）

- ABCC11 という遺伝子の1塩基の違いが、耳垢が湿型か乾型かを決める [3]
- この遺伝子の働きが、脇の典型的な匂い成分の形成に関係している [4]
- 日本人を対象にした研究で、腋臭症と湿型耳垢との間に強い関連が確認された [5]
- odor-care.html の表現：「東アジアでは乾型耳垢の頻度が高いことも知られています」（数字なし、出典番号なし。割合はこのリサーチでも確認できなかった）
- 断定できない点：耳垢が乾いているから絶対に臭わない、湿っているから必ず強く臭う、とは言えない
- → 「きちんと洗っていても体質的に匂いが出やすい人はいる」＝ニオイの強さと清潔かどうかは同じ話ではない

### 4. 主な発生源その2：足（靴の中の環境）

- 足の裏を含む手足は、汗腺の密度が非常に高い部位 [6]（具体的な数値はサイト記事に書かれていない。確認できなかった）
- 足の匂いの原因物質の一つにイソ吉草酸がある。足の微生物が汗などの成分を代謝して匂い成分を作る [7][9]
- 足は靴・靴下に覆われ、汗が蒸発しにくく湿度が上がる → 足そのものだけでなく靴の中の環境を見る必要がある（odor-care.html の説明。この部分に個別の出典番号はない）

### 5. 他人の印象への影響

- 嫌悪は、腐敗物や病原体など害になりうるものを避けるために発達した適応的な仕組みと考えられている [10]
- 意識的には判別できないほど弱い快・不快臭を提示しながら中立的な顔を見せた実験で、顔の好感度評価が変化した [12]（smell.html の表現：「心地よい匂いと組み合わされた顔のほうが、好意的に評価される傾向がありました」「本人は匂いに気づいていない」）
- → **「臭い」とはっきり思われる前から、印象は動いている可能性がある**。冒頭で手を止める材料として最も強い。ただし実験は「顔写真＋弱い匂い」で、体臭そのもので職場の評価が下がると示したものではない。言い過ぎないこと
- 男性の匂いを操作した実験で、本人の自信や自己評価が変わり、女性が動画を見たときの魅力評価に差が出た。写真だけでは差がなかった [13]（smell.html で扱い済み）
- 加齢に伴って増える傾向のある 2-ノネナール（40 歳以上の体臭から検出）[14]。ただし物質が特定されたことと不快と感じるかは別（smell.html の断り）

## まだ分かっていないこと・意見が分かれていること

- **タイトルの「いちばん気づけない」は根拠がない**。「自分が、他人より自分の体臭に気づきにくい」と比べた研究は、サイト記事の文献には含まれていない。順応 [1] は一般論。タイトル担当には「いちばん」を外すか、問いの形にする（例：「自分のニオイに、自分は気づけるのか」）ことを勧める
- 自分の体臭の自己認識を直接調べた研究：Web 検索の一覧には「人は自分の体臭を認識できる／好む」という趣旨の研究（Barnard College の PDF「Smelling themselves」、Discover 誌の記事、Roel Lesur 2023 Biol Psych と思われる PDF）が出てきたが、**開けなかったので内容は未確認**。順応で「感じにくい」ことと「区別はできる」ことは両立しうるが、記事では触れないこと
- 東アジアで乾型耳垢がどれくらいの割合か：数字を確認できなかった
- 足の汗腺密度の具体的な数値：確認できなかった
- 体臭が仕事の評価・採用に影響するかを直接調べた研究：サイト記事の文献にはなく、確認できなかった
- 制汗剤のアルミニウムと乳がん：2023 年の系統的レビューでは結果が一致せず結論は出ていない（deodorant-guide.html で扱い済み）。この note では触れなくてよい

## 記事の切り口の候補

### 案A（推薦）：「臭い」と言われる前に、印象はもう動いている
- 流れ：冒頭「意識できないほど弱い匂いでも、顔の好感度が変わった実験がある」[12] → でも自分の匂いは順応で感じにくい [1] → 汗そのものではなく菌がニオイを作る [2] → 発生源は脇（体質）と足（靴の環境）[3]-[7][9] → 自分で分からないなら、先回りして整える → サイト記事2本へ
- 推薦理由：柱「外見（清潔感）」に直結し、「人と会う前に整える」行動につながる。X →「選び方」記事（deodorant-guide）への流れに最も素直。odor-care.html の結び「自分では分からないからこそ、先回りして整えておく」と矛盾しない
- 注意：体臭の実験ではない点、印象への影響は「可能性」である点を本文で明記する

### 案B：汗は臭くない。臭いを作っているのは菌だ（常識の否定）
- 冒頭で「汗をかく＝臭う」を否定 → 制汗剤とデオドラントは役割が違う → 自分が抑えたいのは汗か匂いか
- 良い点：deodorant-guide.html に直結し、クイズ形式が使える。弱い点：「自分で気づけない」というテーマが薄くなる

### 案C：自分の鼻は、どちら向きにもあてにならない
- 気づかない人（順応）と、気にしすぎる人（口臭外来の 16％）の両方を示し、「自分の鼻ではなく、仕組みで整える」へ
- 良い点：不安をあおらない。読者の「気にしすぎて疲れる」層にも届く。弱い点：16％は口臭のデータで、体臭の話と混ざる

**決定：案A**。案C の「16％」は、案A の終盤で「気にしすぎる必要もない」の補足として1段落だけ使うとよい（口臭のデータだと明記）。
