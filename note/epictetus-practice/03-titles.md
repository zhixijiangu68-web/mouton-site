## 2. 推す案・次点・採らなかった案

**推す案：1「読んでも変わらない夜に、エピクテトスを読む」（21字）**

コピー第一の順で：
1. 止まるか：読んでいる一人の悩みの言葉（「読んでも…変わらない」）が1字目から来る。一覧で「自分のことだ」と思える
2. 具体か：哲学者名（何年たっても検索される言葉）。書名は題に入れず、無料部分の早いところで『提要』と、岩波文庫の國方栄二訳の『要録』を並べた（`titles.md` の 2 の 4）
3. 本文の約束と一致するか：本文は「読んでも変わらない夜に当てて読む」と言い、有料部分はその読み方。答えや結果は約束していない。答えを伏せる題ではない
4. 長さ：目安の 15〜25字に収まる（21字）。止まる言葉も主題の言葉も前の15字に入る（エピクテトスは13字目から）
- 章の番号（52）を題に入れていないので、照合で章の番号が変わっても題は変わらない
- 見出し画像（「読んだ量は、どこに出る？」）とは別の文。題＝主題の言葉＋止まる言葉、画像＝止める一行（`thumbnail.md` の 2 の 5）

**次点：2「読んでも変わらない夜に、エピクテトスの『提要』を読む」（26字）**：書名で検索する人に届く。ただ、いま手に入る邦訳の題は『要録』（岩波文庫）で、『提要』だけだと本屋や検索の名前と合わない。両方を入れる 10 は31字で長い

**採らなかった案**
- 5（前の推す案）：前の15字が「エピクテトス『提要』52」で、講義の目録のように読め、止まる言葉が後ろにある（`titles.md` の 2 の 3）。章の番号は照合の前
- 4：「嘘」だけが目に入ると、正直さ・嘘の記事だと読まれやすい（悩みは「読んでも変わらない」）。本文の1行目で使うので、開いた人にはすぐ届く
- 3：場面は具体だが、スマホに一文を保存する人に読者が狭まる。次の次点
- 6：哲学者名がなく、何の記事か（哲学）が分からない
- 7：「分かっているのに」は強いが、何をか分からない。答えを期待させやすい
- 8：羊は無料部分の章（『提要』46）で、有料部分の中身とずれる。「草を見せない」は、原典の「どれだけ食べたかを見せない」から量の話が抜ける
- 9：見出し画像の文言と同じ問いになる（題と画像で同じ文を繰り返さない）

## 3. 最終案（照合前の仮）

- **読んでも変わらない夜に、エピクテトスを読む**（21字）
- 短くするときの案：今のままで25字以内
- 区切りのダッシュは使っていない（使うときは「——」：`style.md` の 2 の 9）

## 4. 記事の説明（欄があれば）

夜に哲学の本を読み、線を引く。翌朝、同じことに苛立つ。エピクテトスの『提要』（岩波文庫では『要録』）と『語録』から一章ずつを、その夜に当てて読む。有料部分は、二つの章の読み方と、僕の記録と、当てはまらないとき。（105字）

- 1文目は止まる場面で、題を繰り返さない。2〜3文目で、何を読むかと有料部分の中身（目次の言葉まで）を言う（`titles.md` の 4）
- 値段・約束・あおりなし。「原典から読む」は書かない（照らしていない）。「エピクテトスは書いた」と書かない（`style.md` の 4）
- note に記事ごとの説明の欄があるかは未確認（`titles.md` の 4）。なければ、無料部分の最初の1〜2文が説明の役をする
- 「僕の記録」は、有料部分の `【本人が書く】` が埋まってから使える（埋まらないなら、この語を消す）

## 5. ハッシュタグ

#哲学　#エピクテトス　#ストア派　#エンケイリディオン　#読書

- #哲学：本文の分野
- #エピクテトス：主題の哲学者。無料部分の2段落目に名前がある（`hashtags.md` の 2 の 1）
- #ストア派：エピクテトスの学派。無料部分の2段落目に「ストア派の哲学者エピクテトス」とある
- #エンケイリディオン：書名（『提要』の原題）。無料部分に『提要（エンケイリディオン）』とある。「#提要」「#要録」は一般の言葉（要約の意味）と混ざるので付けない
- #読書：悩みが「読んでも変わらない」で、本文は読むことと使うことの順番を扱う
- 付けなかったタグ：#自己啓発（方法を探す人を招き、本文に手順がない）／#名言（本文は一文を集めることを問い直す。出典の分からない名言の文化と混ざる）／#人生を変える（あおり・約束）／#有料記事書いてみた（`hashtags.md` の 2 の 4：付けなくてよい）／#セネカ・#マルクスアウレリウス（本文にない）
- 5つ：社内の決まり（5〜8個）の下限。中身に合うものがこれ以上ない
- タグの記事数は確かめていない（書かない）

## 7. 題・説明・画像に使わなかった材料と理由

- 「53%」（やるつもりの人のうち、実際にやった割合）：読書の話の数字ではなく、意図一般の数字。題や画像に出すと「本を読んだ人の半分は変われない」と誤読される
- 「奴隷」：小さな画像や題では強い語に見え、記事の中身（読むことと使うこと）より目立つ
- 「1,900年前」などの年：生没年を確かめていない（paid/01-research.md の 5）
- 章の番号・有料部分の引用（目次の見出しの言葉を除く）：照合の前。有料部分の中身を先に見せることにもなる
- 「読むだけ無駄」の向きの言い方：本文は読むことを否定していない。題で否定すると、本文の約束とずれる

## 8. 品質チェック担当への申し送り

1. 題・説明・画像は照合前の仮。照合で無料部分の引用（『提要』46・52 の結び）が変わったら、説明と本文の1行目をそろえて直す
2. 記事の説明の「僕の記録」は、有料部分の `【本人が書く】` が埋まってからでないと事実にならない
3. 題の点検（`titles.md` の 6）：止まる／何の話か分かる／25字以内／有料部分と一致し約束なし／答えを伏せない／有料部分の中身を出していない／禁じた言葉なし／健康に関わらない／サイトの記事の題（「あの一言が、一日じゅう頭から離れない。エピクテトスが引いた一本の線」）と区別がつく／題と画像の文言は別の文／「書いた」「原典から」を使っていない
