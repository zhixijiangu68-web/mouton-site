# タイトル案：napoleon-vs-genghis-khan

仮タイトル：「ナポレオンとチンギス・ハン。勝ち続けた男と、負けから始めた男」

仮タイトルについての注意：本文は、テムジンの若いころを「父を失い、一族が苦しい立場に置かれた」と書いていて、「負けた」とは書いていない。若いころの戦いの勝ち負けにも踏み込まないとしている。そのため「負けから始めた」は本文より一歩強い。下の案では「苦しい立場から」「組み直した」と言い換えた。

タイトルに使った事実は、すべて 02-draft.md 末尾の「人が確認すべき事実」の一覧にあるものだけ（勝ち続けて皇帝になった、ワーテルローで敗れた、孤島で亡くなった、父を失った、草原をまとめた、千戸に組み直した、7つの項目で比べた、陸で強く海は思いどおりにならなかった）。数字は本文にある「7つの項目」だけを使った。元寇・十三翼の戦い・百日天下は確認の段階が浅いので、タイトルには使っていない。

   - 型：問いかけ

   - 型：結論先出し

   - 型：対比（物語）

   - 型：逆説（常識の否定）

   - 型：数字

    - 型：共感＋結論先出し（本文の最後の一文から）

## 2. おすすめ 3 案と理由

- **案1「勝ち続けた男と、組み直した男。ナポレオンとチンギス・ハン」**
  仮タイトルの対比の形を残したまま、本文が言っていない「負けから始めた」を外した。「組み直した」が本文の芯（千戸への組み替え、仕組みを作り直す力）にそのまま重なる。有名な2人の名前が後ろに来るので、一覧で目に入りやすい。
- **案4「皇帝は孤島で終わり、父を失った少年は草原をまとめた」**
  「つい見てしまう」に一番近い。誰の話か名前を出さずに、真逆の人生を一行で見せる。本文の冒頭2文をほぼそのまま縮めたもので、書いていないことは約束していない。名前がないぶん検索や一覧での分かりやすさは弱いので、見出し画像に名前を入れて補う前提。
- **案5「負けたあとに必要なのは、『もっと頑張る』ではなかった」**
  常識の否定で手を止めさせる。本文の「今日のワーク」（頑張るだけで終わらせず、仕組みを一つ変える）と合っていて、仕事で負けが続いている読者にまっすぐ届く。歴史に興味のない人も拾える。「ではなかった」は僕の考えとして書かれた結論なので、言い切りすぎにはならない。

## 3. 最終案

**勝ち続けた男と、組み直した男。ナポレオンとチンギス・ハン**（28文字）

理由：仮タイトルの良さ（対比のリズムと2人の名前）を残しつつ、本文に合う言葉に直した。note の一覧で「誰の話か」がすぐ分かり、「組み直した」で「何をしたのか」が気になる。トーンもサイトの「〜なのか」「〜だけだ」のような静かな言い回しに近い。

## 4. 見出し画像の文言（10〜15文字）

2. 負けたあと、何を変えたか（12文字）

画像には小さく「ナポレオン × チンギス・ハン」を添えると、タイトルと合わせて何の話か伝わりやすい。
