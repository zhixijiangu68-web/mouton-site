# タイトル・説明・ハッシュタグ（ntlm）

## タイトル

NTLM は、パスワードがなくてもハッシュで答えられる。Windows は、その答えを外の共有にも自動で送る

サイトの記事の見出しと同じにした（コピーはタイトルにだけ使う決まり。docs/security-renewal-20261104.md の 8）。

## 記事の説明

NTLM は、サーバーのチャレンジに、パスワードの NT ハッシュから作った応答で答える Windows の認証方式。ハッシュがあれば応答が作れること、外の共有への自動の認証で応答が漏れる形、リレーと SMB 署名・EPA・外向きの 445 番、4624 と 4776 を短くまとめた。全文はサイトに。
