## 最初に載せる記事（この順番）

プロフィールの上に、いちばん先に見せる記事を置く。記事を一番上に固定する機能は、note のヘルプでは見つからなかったので、公開の順番で並べる（下の「公開の順番」）。

1. **はじめての方へ**（`note/start/`）：サイトの「はじめての方へ」そのまま。MOUTON の考え方（世界観）と、3人の哲学者への入口。1日目の最後に公開して、プロフィールの一番上に置く。
2. **無料の入門3本**（`note/free-kierkegaard/`・`free-nietzsche/`・`free-spinoza/`）：悩みから入る入口（書き込みの節とやり方は外した）。
3. **30の不安と、30の最初の一歩（目次）**（`note/series-30/00-index/`）：30本の入口。2日目から。
4. **有料記事**：無料の20本のあと。哲学者の3本（`note/paid-kierkegaard/`・`paid-nietzsche/`・`paid-spinoza/`、各 ¥2,980（税込））と、16 の答えの「選べない」（`note/paid-choice/`、note だけ。価格はオーナー、案 ¥980）。冒頭は無料、続きが有料。

  - 自己紹介：上の1案。
