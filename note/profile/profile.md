# note のプロフィール（ムートン）

サイトの世界観（`BRAND.md`）を、そのまま note に置くための設定。**設定・公開はオーナーが行う**（AI は note に投稿しない）。

## 作ったもの

| 項目 | ファイル | 中身 |
|---|---|---|
| ヘッダー画像（1280×670） | `header.jpg` | トップと同じ月桂樹と三日月の絵に、「MOUTON — PHILOSOPHY OF LIFE」「哲学を、読むものから使うものへ。」「決められない。人の目が気になる。続けられない。そんな日々に、自分で考え、試すための道具を。」 |
| アイコン（1024×1024） | `icon.png` | サイトのアイコン（満月の前の羊）。note が円に切り抜くので、四隅は空だけ |

作り直すとき：`cd scripts/og && npm install && node note-profile.mjs`（文言は `scripts/og/note-header.html`）。

## 名前

- **表示名：`ムートン｜MOUTON`**（サイトの運営者名と同じ「ムートン」に、検索で見つけてもらえる英字を足した）。
- **note ID（`note.com/` の後ろ）の候補**：`moutonarchive`（サイトのドメインと同じ。いちばんそろう）／`mouton_philosophy`／`mouton_life`。使われていないものを、note の画面で確かめて選ぶ。決まったら `src/_data/site.js` の `author.note` に入れる（フッター・運営者情報に出る）。

## 最初に載せる記事（この順番）

プロフィールの上に、いちばん先に見せる記事を置く。

1. **はじめての方へ**（`note/start/`）：サイトの「はじめての方へ」そのまま。ブランドの考え方と、3人の哲学者への入口。
2. **無料の入門3本**（`note/free-kierkegaard/`・`free-nietzsche/`・`free-spinoza/`）：悩みから入る入口。サイトの記事と同じ本文。
3. **有料3本**（`note/paid-kierkegaard/`・`paid-nietzsche/`・`paid-spinoza/`）：各 ¥2,980（税込）。冒頭は無料、続きが有料。

## 公開の順番

URL を差し込む必要があるので、次の順に進める。

1. アカウントの設定（名前・ID・自己紹介・アイコン・ヘッダー・リンク）。
2. 有料記事を1本ずつ公開（`listing.md` のとおり。全文はオーナーの手元の原稿）。公開した URL を控える。
3. 無料の入門3本を公開（末尾の `{PAID_URL}` を、手順2の URL に置き換えてから）。
4. 「はじめての方へ」を公開（`{URL_FREE_*}` と `{URL_PAID_*}` を、手順2・3の URL に置き換えてから）。
5. 公開した記事の URL を、無料の入門記事とあわせて X の告知に使う（告知文は、必要になったら `note-sns` に作らせる）。

## 決まったこと（2026-10-17、オーナー）

- **両方で売る。note が先、サイトは後から。** note の有料記事は各 ¥2,980（税込）。出品は、有料3本の `listing.md` に沿って、オーナーが note で行う。
- サイトの販売ページは変えていない（「このサイトでの販売準備中」のまま）。note の URL ができたら、「note で購入」の案内を足す。
- 決まっていないこと：note ID、自己紹介の案（A／B）、3本を同時に出すか順に出すか。
