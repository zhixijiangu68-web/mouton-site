## 最初に載せる記事（この順番）

プロフィールの上に、いちばん先に見せる記事を置く。記事を一番上に固定する機能は、note のヘルプでは見つからなかったので、公開の順番で並べる（下の「公開の順番」）。

1. **はじめての方へ**（`note/start/`）：サイトの「はじめての方へ」そのまま。MOUTON の考え方（世界観）と、3人の哲学者への入口。1日目の最後に公開して、プロフィールの一番上に置く。
2. **無料の入門3本**（`note/free-kierkegaard/`・`free-nietzsche/`・`free-spinoza/`）：悩みから入る入口（書き込みの節とやり方は外した）。
3. **30の不安と、30の最初の一歩（目次）**（`note/series-30/00-index/`）：30本の入口。2日目から。
4. **有料3本**（`note/paid-kierkegaard/`・`paid-nietzsche/`・`paid-spinoza/`）：無料の20本のあと。各 ¥2,980（税込）。冒頭は無料、続きが有料。

## 公開の順番

**無料記事20本で世界観を伝え、信頼を得てから有料3本を出す**（2026-10-17、オーナー）。日ごとの中身は `note/series-30/plan.md` の「公開の順番」。

1. アカウントの設定（名前・ID・自己紹介・アイコン・ヘッダー・リンク）。
2. **1日目「世界観」（4本）**：入門（スピノザ → ニーチェ → キルケゴール）→ はじめての方へ の順に公開する（新しい記事が一覧の上に来るので、見せたい順の逆）。習慣設計はワークが中心なので、いったん外した（出すかどうかはオーナー）。
3. **2〜4日目（16本と目次）**：30本のうち 01〜04 と、ほかの道の最初の3本。「気づかせる」形に書き直してから出す（見本3本はオーナーの確認待ち）。2日目に目次も出し、3日目・4日目は記事を出したあとで目次を貼り直す。
4. **20本のあと**：有料3本（キルケゴール → ニーチェ → スピノザ）。そのとき、はじめての方へ・入門3本・習慣設計・目次に、各フォルダの `paid-section.md` の部分を足す。
5. どの日も、その日に出す記事の下書きを先に作り、「公開時の URL」を控えてから本文を貼る（下書きの「共有用リンク」のページに出て、下書きを直しても変わらない。note のヘルプ「下書きの内容を共有したい」）。公開キット（`note/README.md`）なら、URL を入れるだけで本文のリンクが埋まる。
6. 公開した記事の URL を、X の告知に使う（告知文は、必要になったら `note-sns` に作らせる）。

## 決まったこと

- **両方で売る。note が先、サイトは後から**（2026-10-17、オーナー）。note の有料記事は各 ¥2,980（税込）。出品は、有料3本の `listing.md` に沿って、オーナーが note で行う。
- サイトの販売ページは変えていない（「このサイトでの販売準備中」のまま）。note の URL ができたら、「note で購入」の案内を足す。
- **自己紹介・note ID・出す順番は、Claude が決めた**（オーナー：「決めるのはあなたです」）。
  - 自己紹介：上の1案。
  - note ID：`moutonarchive`。
  - 有料3本は**同時に**出す（キルケゴール → ニーチェ → スピノザの順に公開）。理由：はじめての方へ・入門3本・習慣設計・目次が3本すべてに案内するので、1本だけ出すと案内の足し忘れが残る。どれが先に売れるかの手がかりになる数字もない。売れ方を見て、続きの書き方や価格は見直す。
- **無料の20本が先、有料はそのあと**（2026-10-17、オーナー：「無料記事を20個出して、信頼を獲得してから有料記事を出す。世界観も伝えてからにしたい」）。どの20本にするか、日ごとの順番は Claude が決めた（`note/series-30/plan.md`）。
