## 最初に載せる記事（この順番）

プロフィールの上に、いちばん先に見せる記事を置く。記事を一番上に固定する機能は、note のヘルプでは見つからなかったので、公開の順番で並べる（下の「公開の順番」）。

1. **30の不安と、30の最初の一歩（目次）**（`note/series-30/00-index/`）：無料の30本の入口。「いまいちばん近い不安」から一つだけ読める。プロフィールを見に来た人が、迷わず入れる。
2. **はじめての方へ**（`note/start/`）：サイトの「はじめての方へ」そのまま。ブランドの考え方と、3人の哲学者への入口。
3. **無料の入門3本**（`note/free-kierkegaard/`・`free-nietzsche/`・`free-spinoza/`）：悩みから入る入口。サイトの記事と同じ本文。
4. **有料3本**（`note/paid-kierkegaard/`・`paid-nietzsche/`・`paid-spinoza/`）：各 ¥2,980（税込）。冒頭は無料、続きが有料。

## 公開の順番

記事どうしが URL でつながっているので、次の順に進める（2026-10-17 決定）。

1. アカウントの設定（名前・ID・自己紹介・アイコン・ヘッダー・リンク）。
2. **土台の8本の下書きを作り、それぞれの「公開時の URL」を控える**：有料3本（`listing.md` のとおり。全文はオーナーの手元の原稿）、習慣設計、無料の入門3本、はじめての方へ。公開時の URL は、下書きの「共有用リンク」のページに出て、下書きを直しても変わらない（note のヘルプ「下書きの内容を共有したい」）。
3. 本文の `{PAID_URL}`・`{PAID_URL_*}`・`{URL_FREE_*}`・`{URL_PAID_*}` を、控えた URL に置き換えてから貼る（公開キットなら URL を入れるだけ。`note/README.md`）。
4. 公開：有料3本（キルケゴール → ニーチェ → スピノザ）→ 習慣設計 → 無料の入門3本（スピノザ → ニーチェ → キルケゴール）→ はじめての方へ。新しい記事が一覧の上に来るので、見せたい順の逆に出す。
5. **翌日以降に、30本のうちの第1陣**（10本と目次）を、同じやり方で一斉に出す（`note/series-30/plan.md`）。目次を最後に公開すると、プロフィールの一番上に来る。
6. 公開した記事の URL を、無料の入門記事とあわせて X の告知に使う（告知文は、必要になったら `note-sns` に作らせる）。

## 決まったこと

- **両方で売る。note が先、サイトは後から**（2026-10-17、オーナー）。note の有料記事は各 ¥2,980（税込）。出品は、有料3本の `listing.md` に沿って、オーナーが note で行う。
- サイトの販売ページは変えていない（「このサイトでの販売準備中」のまま）。note の URL ができたら、「note で購入」の案内を足す。
- **自己紹介・note ID・出す順番は、Claude が決めた**（オーナー：「決めるのはあなたです」）。
  - 自己紹介：上の1案。
  - note ID：`moutonarchive`。
  - 出す順番：**有料3本を同時に**（キルケゴール → ニーチェ → スピノザの順に公開）。理由：無料の入門3本と「はじめての方へ」が3本すべてにリンクするので、1本だけ出すと URL の差し込みが残り、あとで直す手間が増える。どれが先に売れるかの手がかりになる数字もない。売れ方を見て、続きの書き方や価格は見直す。
