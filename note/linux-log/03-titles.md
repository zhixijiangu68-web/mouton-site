## 記事の説明

Linux のログは rsyslog のテキストと journald の journal に残り、その機械の管理者なら消せる。syslog の形、sshd と sudo の行、last と auditd、回転と転送、SOC で見る三つの変化を短くまとめた。全文はサイトに。
