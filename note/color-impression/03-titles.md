## 2. おすすめ 3 案と理由

> 朝の記録。下の案1は朝の最終案で、赤いボタンを「証拠なし」としているので使えない（いまは △ 弱い（確かさ 非常に低））。見出し画像も、いまは「「赤い服でモテる」は × 否定」で、下の「画像の文言の1と説明で補う」は当たらない。題・見出し画像・説明は、いちばん上の直しの節が正。

1. **案1「色選びに迷うときに。「赤い服でモテる」は否定、「赤いボタンが売れる」は証拠なし」**（朝の最終案。いまは使えない）
   - 誰に：頭の「色選びに迷うときに」。記事の最後の問い（色に迷うとき、…）と同じ言葉で、状況で書いた。
   - 何が分かるか：2つの話の判定を、本文の印の言葉のまま出した。服の話（赤い服）と、資料・Webの話（赤いボタン）が1つずつ入る。想定読者の場面（服・資料・SNSの画像）の両方に当たる。
   - 「否定」と「証拠なし」が並ぶので、本文の中心にある「× と ― は違う」が、題の形のまま見える。
   - 本文の1行目（「赤い服を着ると、モテる」は、研究まで遡ると「× 否定」だった。）と同じ事実なので、題で引いて本文で裏切らない。
   - 弱み
     - 39字で、上限に近い。
     - 頭が「色選び」で、「服や資料」という場面は題にない。画像の文言の1と説明で補う。
     - 確かさ（中）は題に入らない。説明に入れた。
     - 本文で見せる4行のうち、成績とダークモードの2行は題にない。

2. **案2「服や資料の色に迷うときに。「赤い服でモテる」「赤いボタンが売れる」を確かめた」**（仮題）
   - 誰にがいちばん具体（服や資料）。読む人が聞いたことのある話を2つ並べていて、止まる力がある。
   - 弱み：「確かめた」で止まり、何が分かったかは題から読めない（チェックリスト2）。結果を本文に回すので、引っぱる形に寄る（チェックリスト7）。
   - 使うとき：題で判定を言い切るのを避けたいとき。そのときは、見出し画像に文言の2「「赤い服でモテる」は否定」を載せて、結果を画像で補う。

3. **案3「服や資料の色に迷うときに。印象を決めるのは、何色かより、明るさと場面だった」**
   - 記事の見出しと同じ言葉なので、サイトに行ったときに同じ話の続きだと分かる（事業部長の指定で認められた形）。誰にも具体。
   - 弱み：note で見せるのは、この見方の入口だけ。根拠の研究は名前だけで、結果はサイトにある。本文の中心（4行の判定と、d の縮み）が題にない。題が約束するものの半分しか、note の中で読めない（content-quality 0 の5）。
   - 使うとき：X や、サイトの記事と並べて案内するとき。

**採らなかった理由**

- 案4：本文の見出し2と同じ事実。ただ、頭に誰にがない。赤い服の1つだけになる。X の1行目なら使える。
- 案5：d の説明（0なら差がない、大きいほど差が大きい）がないと、数字の意味が分からない。誰にもない。
- 案6：資料・SNSの人には近い。ただ、本文の1行目（赤い服）と題の話がずれる。ダークモードは、本文では判定だけで根拠がない（根拠はサイト）。
- 案7：本文の「× と ― は違う」をそのまま形にした。ただ、対比の形が先に立ち、分かりやすさよりうまさが前に出る。誰にが後ろに回る。ボタンの話だけになる。
- 案8：場面はいちばん浮かぶ。ただ、「判定した」で止まり、何が分かったかがない（仮題と同じ弱み）。
- 案9：問いの題（copywriting 3. で、題は言い切りが基本、問いは最後に一つ）。答えは本文の1行目にあるので、問いで引っぱる形になる。本文の最後の問いと合わせて、問いが2つになる。
