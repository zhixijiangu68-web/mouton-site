# タイトル・見出し画像・ハッシュタグ（ニーチェ・無料の入門）

サイトの記事「その「すべき」は、誰の声なのか。」を、note に載せる形にしたもの（本文はサイトのまま）。

## タイトル

その「すべき」は、誰の声なのか。

## 見出し画像

- サイトのシェア用の画像をそのまま使う：`images/og/nietzsche.jpg`（1200×630）。note の推奨サイズ（1280×670）より少し小さいだけなので、そのままで足りる。

## 記事の説明（note の「記事の説明」欄）

人の目や評価が気になって、「どう思われるか」で選んでしまう。頭の中の「〜すべき」は、本当に自分の声なのか。ニーチェが『ツァラトゥストラ』に描いた竜「汝なすべし」から、その正体を考える。

## 公開するとき

無料の20本の1日目（世界観）に出す（`note/series-30/plan.md` の「公開の順番」）。

1. `article.md` を note のエディタに貼る（公開キット（`note/README.md`）の「本文をコピー」なら、見出しや太字もそのまま入る）。
2. 見出し画像・ハッシュタグ・記事の説明を、上のとおりに設定して公開。
3. 末尾のサイトへのリンクは、そのまま使う（`utm` つき。GA4 で `utm_source=note` から数える）。
4. 有料記事（`note/paid-nietzsche/listing.md`）を出す日に、`paid-section.md` の部分を末尾の「この悩みの続き」に足す。いまは有料記事への案内を外してある。

## 確認すること

- 本文に商品リンクはない（広告の表記は要らない）。末尾のサイトのリンク先のページ共通のフッターには、サイト全体の広告の注意書きがある。
- 同じ文章がサイトにもある。サイトの記事を直したら、note も直すかどうかを決める（直さない場合は、note のほうが古くなる）。
