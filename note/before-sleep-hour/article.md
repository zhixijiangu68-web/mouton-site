# 布団でスマホを見てしまう夜に。害を大きい順に4つ並べると、画面の光は4番目だった

18〜24歳の167人の試験で、寝る前の1時間にスマホをやめた人も、夜間モードで使った人も、寝つくまでの時間は普通に使った人と変わらなかった[1]。

布団の中でスマホを見てしまう夜のために書いた。スマホをやめた試験と、画面の光を測った実験などを読み、よく言われること3つに判定をつけた。この note に書いたのは二つ。スマホを置いて縮む寝つきは0〜12分ほど。害を大きい順に4つ並べると、画面の光は4番目だった。1〜3番目が何だったかは、サイトの記事の表に載せた。

## スマホをやめても、寝つきは0〜12分しか縮まなかった

寝る前のスマホは、日本の若い世代で、眠りの妨げとして目立つ。平成27年の国民健康・栄養調査では、「就寝前に携帯電話、メール、ゲームなどに熱中すること」が、睡眠を確保する妨げとして20代女性で1位（33.3%）、20代男性（24.6%）と30代男性（19.8%）で3位だった[2]。では、やめれば、寝つきはどれだけ変わるのか。

冒頭の試験は、18〜24歳の167人を、寝る前の1時間「スマホなし」「普通に使う」「夜間モード（Night Shift）で使う」の3群に分け、7夜を活動量計（手首につけて睡眠を推定する機器）で測ったものだ[1]。寝つくまでの時間は、スマホなしが11.45分、普通に使う群が11.91分、夜間モードの群が12.18分。3つの開きは1分未満で、差はなかった。

良い結果が出た試験もある。寝る前に30分以上スマホを使う、睡眠不良の大学生38人の4週間の試験だ。いつもの就寝時刻の30分前からスマホを使わない群は、寝つくまでの時間が対照の群より約12分短くなった。睡眠時間も、試験の前と比べて約18分延びた（同じ群の中での比較）。寝る前の頭と体の興奮も下がった[3]。

ただ、167人の試験とは、参加者と測り方が違う。38人は全員が睡眠不良で、睡眠は活動量計ではなく自己申告で測った。人数も少ない。

別の試験では、デンマークの89家族からスマホとタブレットを2週間預かった。脳波で測った大人の睡眠は変わらなかった[4]。寝る前のスマホ制限をまとめたメタ解析（複数の研究をまとめた分析）も、日本人を対象にした RCT（参加者をくじで群に分ける試験）も見つからなかった。

並べると、期待できるのは寝つきで0〜12分ほどの小さな改善で、それも寝床で長くスマホを使う、睡眠不良の人に集まる。サイトの記事の判定表では、「寝る前にスマホをやめると、寝つきが大きく良くなる」を×（否定）、確かさ「中」にした。確かさは、研究の数・大きさ・質から付けた目安だ。

読み違えやすいところが一つある。×は「主張と逆、または差がない」という意味だ。もともとよく眠れている人で差が出ないのは、良くなる余地がない「床効果」で、スマホが無害だという証拠ではない。

## 最大の明るさのタブレットで測ると、メラトニンの抑制は1時間なら7%、2時間で23%だった

寝る前のスマホが悪い理由として、よく聞くのはブルーライトだ。画面の光が、メラトニン（夜に増えて眠りを促すホルモン）を抑える、という話だ。

光の影響の大きさを、タブレットの明るさを最大にして測った実験がある。それでも1時間なら、メラトニンの抑制は7%で、有意な差はなかった。有意な差がない、というのは、偶然のばらつきと区別できないという意味だ。

2時間では23%に上がった[5]。光が無関係なわけではない。言えるのは、最大の明るさでも1時間なら、メラトニンの抑制は小さかった、というところまでだ。

夜間モードは、画面の光の色を少し変える機能だ。ただ、光の害に限っても、十分には防いでいなかった。iPad の Night Shift は「より暖色」「やや暖色」のどちらの設定でも、2時間でメラトニンを有意に抑えた。調べたのは12人だ。研究者は、色の調整だけでは足りず、画面の明るさも下げる必要があるとしている[6]。

冒頭の167人の試験でも、夜間モードの群の寝つき（12.18分）は、普通に使う群（11.91分）と変わらなかった[1]。判定表では、「夜間モードにすれば、寝る前に見ても大丈夫」を×（否定）、確かさ「低」にした。根拠は、この12人の研究と、167人の試験の夜間モードの群だ。

## 光より大きな害が3つあり、夜間モードはそのどれにも触れない

では、寝る前のスマホは何を通じて眠りを削るのか。サイトの記事では、害の経路を大きさの目安で4つに並べた。違う物差しの研究を並べた僕の整理で、一つの研究が順位を出したわけではない。光によるメラトニンの抑制は、その4番目だった。

いちばん上に置いた経路の根拠の一つは、21の追跡研究、54.8万人をまとめた分析だ[7]。上位の経路の根拠は観察研究が中心で、スマホが原因だとまでは言えない。そのうえで判定表では、「寝る前のスマホの害の本体は、ブルーライト」を×（否定）、確かさ「中」にした。根拠は、1時間なら7%だった実験と、上位の経路の研究だ。

順位は害の大きさの目安で、光の根拠が弱いという意味ではない。寝る前の1時間の行動のなかで、体のしくみとしての根拠がいちばん確かなのは、むしろ光だ。部屋の照明の話は、サイトの記事に書いた。

色を変えるだけの夜間モードは、上の3つの経路には触れない。では、上の3つは何だったのか。それぞれの名前と大きさの目安、打ち手の方向は、サイトの記事の表にまとめた。「スマホをやめても、寝つきは0〜12分しか縮まない」の節にある、「害の順位で、ブルーライトは最下位に近い」の表だ。

## スマホを置いた1時間の「よく言われること」10項目にも、×が3つあった

判定表には、スマホを置いたあとの1時間について、よく言われることも10項目並べた。たとえば、こういうものだ。

「寝る前に本を読むと、よく眠れる」「寝る前に音楽を聴くと、よく眠れる」「消灯の前に翌日の To-Do リストを書くと、早く寝つける」「6分の読書でストレスが68%減る」「ほうじ茶はカフェインが少ない」「寝る直前に湯船につかると、寝つきが良くなる」「眠くなくても、決まった時刻に布団に入るのがよい」。

10項目の判定は、○（支持）が3つ、×（否定）が3つ、△（弱い）が3つ、証拠なしが1つだった。どれがどれかと、その根拠・確かさは、サイトの記事の判定表に載せた。「6分の読書でストレスが68%減る」という数字の出どころも、サイトの記事でたどった。

日本の家には、この1時間の見落とされやすい落とし穴が3つあった。

画面の代わりになる12の活動も、根拠の順に並べた。いちばん確かな等級に届いた活動は、一つもなかった。
