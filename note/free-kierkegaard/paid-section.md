# 有料記事を出したら足す部分

オーナーの方針（2026-10-17）：無料記事20本で世界観を伝え、信頼を得てから有料3本を出す。それまでは有料記事への案内を外してある。2026-10-18、オーナー：「無料の記事に有料記事のリンクを貼りたい」。有料記事を出して URL ができたら足す（どの無料記事からどの有料記事へ案内するかは `note/paid-links.md`。公開キットでは、有料記事のカードに URL を入れると、この部分が本文のコピーに入る）。有料記事を出したら、末尾の「## この悩みの続き」の見出しのすぐ下（「ほかの悩みと、ほかの哲学者は…」の前）に、次の部分を足す。`{PAID_URL}` は、この入門と同じ哲学者の有料記事の URL（公開した記事は、note の「編集」から足して「更新」）。プレースホルダーは有料記事の URL に置き換える。
