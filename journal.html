  • 遠隔操作ツールは、本物のまま攻撃に使われる。だからウイルス対策は、ふつう鳴らない

    RMM は、離れた場所から多くの端末を見守り、操作するための正規のソフトだ。攻撃者は同じソフトを、だまして入れさせる道具や、入り込んだあとの出入り口に使う。使ってよい RMM を決めてほかを止めること、管理する側のアカウントを固めること、見慣れない導入と外への通信をログで見ることを、ファイアウォールと SIEM の記事の続きとしてまとめた。

  • NTLM は、パスワードがなくてもハッシュで答えられる。Windows は、その答えを外の共有にも自動で送る

    NTLM の応答は、パスワードそのものではなく NT ハッシュから作られる。ハッシュを盗まれれば本人として認証でき、外の共有を開かせれば応答が漏れ、そのまま中継されればリレーになる。SMB 署名・EPA・外向きの 445 番の遮断・NTLM の制限と、4624 と 4776 での見つけ方を整理した。

    脆弱性・事件・約12分・2026年11月13日

  • CVSS の 10.0 は、悪用されるかどうかを表さない。直す順番は、KEV と「外から届くか」で決める

    CVSS のベースの値は、起きたときの深刻さで、悪用の起こりやすさではない。実際に悪用が確かめられた脆弱性は CISA の KEV に載る。CVE・CVSS・EPSS・KEV・JVN・月例パッチの読み方と、KEV と外から届く機器を先に直す順番を、カタログの項目と件数とあわせてまとめた。

    脆弱性・事件・約12分・2026年11月13日

  • 確認コードは、偽のサイトにも打ち込める。多要素認証の強さは、鍵がどのサイトに結びつくかで決まる

    パスワードは長さと漏えいの照合で選ばせ、ソルトを付けた遅いハッシュで保存する。ワンタイムパスワードや SMS のコードは偽のサイトに中継されうるが、WebAuthn の鍵はサイトの名前に結びつく。MFA のあとはセッションの Cookie が本人の証明になる。

  • Linux のログは、手元にあるかぎり消せる。だから外へも送っておく

    Linux のログは、syslog の形で出され、rsyslog がテキストのファイルに、journald が journal に書く。sshd と sudo の行、last と lastb、auditd の記録の読み方と、回転で消える仕組み、別の機械へ送る理由、SOC で見る三つの変化をまとめた。

    守る・約12分・2026年11月13日

  • Windows のセキュリティのログには、監査ポリシーで決めたことしか残らない

    Windows のイベントログは、ログの名前とイベント ID で読む。何が残るかは監査ポリシーと Sysmon の設定で決まり、4688 のコマンドラインは既定では残らない。ログオンの種類の読み方、SOC で目を向ける出来事、SIEM への送り方もまとめた。

  • HTTP は、前の要求を覚えていない。だから、Cookie を見せた相手を本人として扱う

    HTTP は一つの要求に一つの応答を返し、要求どうしを覚えていない。前の要求とのつながりは Cookie が運ぶので、Cookie の属性と HTTPS が守りの土台になる。アクセスログの一行から読めることと、SIEM で見る観点もまとめた。

  • 経路を乗っ取っても、本物の鍵がなければ本物にはなれない。TLS が守る三つのこと

    TLS は暗号化・完全性・相手の確認の三つを受け持つ。TLS 1.3 は鍵を決めてから証明書で相手を確かめ、証明書は名前と期限と取り消しまで見る。不正な発行は CT の公開の記録で見つけ、CAA で発行できる認証局をしぼる。

  • DNS の答えは、先に届いた偽物が勝つ。キャッシュポイズニングと、DNSSEC・DoH の役目の違い

    DNS は、届いた応答の正しさを確かめずに、条件の合う最初の応答を受け取る。2008年のキャッシュポイズニングの対策、署名で確かめる DNSSEC、通信路を暗号化する DoT・DoH はそれぞれ守るものが違う。持ち主の側の乗っ取りとログでの見つけ方もまとめた。

  • ICMP を全部止めると、大きな通信だけが止まる。エラーと診断の知らせの読み方

    ICMP は IP の失敗と診断の知らせ。Time Exceeded で途中のルーターが、Packet Too Big で経路の MTU が分かる。全部止めると Path MTU Discovery が壊れ、ping は通るのに大きな通信だけが止まる。

  • 開いているポートの数だけ、外からの入口がある。TCP と UDP とポートの読み方

    IP アドレスが機器を、ポート番号がその中のプログラムを指す。TCP は SYN・SYN-ACK・ACK で接続を作って順番と再送を受け持ち、UDP は接続を作らずに送る。開いているポートは入口になるので、不要なものは閉じ、スキャンと SYN フラッドの見え方を知っておく。

  • ARP は、答えた相手を確かめない。同じネットワークの中で、通信が横取りされる仕組み

    宛先が自分の範囲の中なら相手の、外ならゲートウェイの MAC アドレスへ送る。その MAC アドレスを引く ARP は答えを確かめないので、同じネットワークの者が偽の答えで通信を横取りできる。見つけ方と防ぎ方までまとめた。
