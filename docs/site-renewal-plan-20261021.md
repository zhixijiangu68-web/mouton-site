## 1. なぜ作り直すのか

いまのサイトは、方針が変わるたびに上に積み重ねてきた。

- 10/13 個人ブランド → 10/15 商品先行 → 10/16 哲学の有料3本 → 10/17 点と線・安易に与えない → 10/18 コピーライティング第一。トップ・ナビ・記事の役割に、それぞれの時期の考えが残っている

足し算をやめて、**新しい土台を1つ作り、そこに記事を積む**。今までのものは消さずにアーカイブへ移す。

## 4. 3つの場所の役割

```
X（コピー：1行で止める） → note（一部：要点と続きの入口） → サイト（決定版：全文・無料・出典つき）
```

| 場所 | 役割 | 載せるもの | 載せないもの |
|---|---|---|---|
| サイト | 決定版 | 記事の全文、判定表、出典、更新履歴 | — |
| note | 部分 | 要点、判定表の一部、「続きと出典はサイトに」 | 全文、全出典 |
| X | コピー | 止まる一行と、note へのリンク | 長い説明 |

サイトへのリンクには、これまでどおり `utm_source=note` などを付けて、どこから来たかを分かるようにする。投稿はオーナーが行う（AI は投稿しない）。

## 5. お金の考え方

- **当面は全部無料**。信頼が積み上がる前に売らない
- **有料記事は時間をかけて作る**（オーナー）。無料の決定版で「この人の調べ方は信用できる」と思ってもらえてから出す。哲学の有料3本と納品の仕組み（Worker・Stripe・R2）は消さずに止めておく
- **広告**：AdSense のコードはすでに全ページに入っている（`src/_data/site.js`）。記事の中の広告枠は出していない。審査と自動広告の設定状態は未確認。性の話題は広告が付きにくい可能性がある
- **これまでの主指標（第三者による実決済1件）との関係**：再構築のあいだは、無料の決定版を積むことを優先する。実決済1件は、有料記事を出す段階の指標として残す（**要承認**）

## 7. 危ないことと対策

| 危ないこと | 対策 |
|---|---|
| 原稿の数字の誤り（AI の調査で、原典とずれる） | 公開前にすべての数字を原典で確かめる。開けなかった文献は書かない。デザイン見本を作る段階で、すでに2か所ずれていた（偽薬の約7割は女性の試験の数字／「2.1万人」は原稿で確かめられず外した） |
| 健康の記事の言い過ぎ | `health: true`。「効く」「治る」と言い切らない。医療の助言ではないと明記 |
| 方針がまた変わり、積み重なる | この2つの文書を正にする。変えるときは文書を先に直す |
| 今までの読者や検索からの流入が切れる | ページを消さない。URL を変えない。アーカイブに注記と新しいトップへの案内を付ける |
| 作業の量でオーナーが疲れる | オーナーにしかできないこと（決める・本人の言葉・投稿・マージ）だけを、短い一覧で渡す |
| 性の話題でサイト全体の印象が偏る | 2本目以降は食・身体・お金・生き方に広げる |

## 8. 成功の見方（案・要承認）

数字は測れるものだけを使い、測れないものは「未確認」と書く。

- **作ったか**：原典を確かめて公開した記事の本数
- **読まれたか**：記事ページの閲覧数、最後まで読んだ割合（GA4）
- **流れができたか**：note からサイトへの流入（`utm_source=note`）、X から note への流入
- **覚えられたか**：「ムートン」での検索、記事の再訪
- **お金**：広告の収益（出す場合）。有料記事を出したあとは、第三者による実決済
