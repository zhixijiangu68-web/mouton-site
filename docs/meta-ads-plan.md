# Meta 広告（Facebook・Instagram）を使うときの計画（2026-10-16 オーナー：将来使いたい）

**今は出さない。** 方針（`docs/product-first-strategy-20261015.md`）の順番は「商品の完成 → 販売・決済・納品の準備 → 集客 → 実購入の検証」。購入ボタンがまだ出ていない（納品の E2E と特定商取引法に基づく表記が未完了）ので、広告費を使っても売れない。この文書は、始めるときに迷わないための準備。

## 決まっていること（2026-10-16 オーナー）

- **開始：2026年12月**（下の「始める条件」がそろっていれば。そろっていなければ、そろうまで延ばす）
- **月の上限：20,000円**

20,000円で、1人あたりの上限（約900円）どおりに買ってもらえると、多くて約22件。実際には最初の数週間は「どの悩み・どの一行で、冒頭（無料）まで来てもらえるか」を確かめる期間になるので、件数より「1件あたりいくらかかったか」を記録する。

12月の使い方の案（決まったら書き換える）：
1. 1週目〜2週目：10,000円。1つの商品・1つの悩みで、広告の一行を2つだけ比べる（ほかは変えない）。
2. 3週目〜4週目：10,000円。1件あたりの費用が約900円以内に近い一行に寄せる。遠ければ止めて、販売ページか商品を見直す。
3. 月末：Stripe の購入・GA4 の流れ・Meta の費用を並べて、1月に続けるかを決める。

## 始める条件（すべてそろってから）

1. 哲学の3本または清潔感の科学が、このサイトで**本当に買える**（`fulfillmentReady: true`、`npm test` が通る）。
2. 特定商取引法に基づく表記・プライバシーポリシー・購入者向けのお問い合わせ窓口がある。
3. 広告なしで、知人以外の購入が1件以上ある、または販売ページの「冒頭を読み終える → 購入ボタン」の割合がおおよそ分かっている（GA4 の `paid_sample_read`・`paid_buy_click`）。広告で増やすのは、流れが細くない部分を確かめてから。
4. 月の上限額をオーナーが決めている（20,000円。決定済み）。

## 計測（始めるときに入れる。今は入れない）

- **Meta ピクセル**（必要なら Conversions API も）で「購入」を数える。購入の確定は Stripe の支払いとサイトの Worker で分かるので、Worker から購入イベントを送る形が確実。メールアドレスなどを送る場合は、Meta の仕様どおりハッシュ化し、送る項目を最小にする。
- 入れる前に**プライバシーポリシーに書く**（Meta への送信、Cookie、オプトアウトの方法）。電気通信事業法の外部送信の決まり（2023年6月施行）がこのサイトに当てはまるかも、そのときに確かめる。
- ドメインの認証（Meta ビジネスマネージャ）。
- 広告から来た人は `utm_source=meta` などを付け、GA4 と照らし合わせる。

## 1人あたりの数字

- 1人を獲得する費用は、1人が買ってくれる金額（Stripe 手数料を引いた手取り）の**3分の1まで**（方針文書 2.7）。2,980円の商品なら、目安は約900円まで。
- 最初は少額で、1つの販売ページ・1つの悩みに絞る。変えるのは1回に1か所だけ。

## 広告の中身（ブランドの決まりをそのまま守る）

- 使ってよいもの：販売ページの「最初の一行」（読者の心の声）、見え方の読み替え、無料の冒頭。広告からは**冒頭（無料）を読めるところ**へ案内する。
- **Meta の「個人の特性」の決まりに注意**：広告で、見る人の心身の状態などを決めつけたり、ほのめかしたりできない（例：「あなたは決められない人ですか？」「人の目が怖いあなたへ」は避ける）。一人称の「考えれば考えるほど、決められなくなっていく。」のように、ムートンの言葉・場面の描写として書く。
- 健康・外見（清潔感の科学）の広告は、ビフォーアフターや「必ず変わる」をしない。外見を否定する言い方をしない。
- 使わない：時間のあおり、残りわずか、恐れで動かす言い方、見下す言葉、広告であることを隠す見せ方（`BRAND.md`「目立ち方」「信者をつくらない」）。インフルエンサーに頼む場合は、広告であることを示す（景品表示法のステルスマーケティング規制）。

## オーナーが決めること

- 最初に広告を出す商品（哲学の1本か、清潔感の科学か）。
- Meta のアカウント・ビジネスマネージャ・支払い方法の用意（AI は広告を出さない・アカウントに触らない）。
