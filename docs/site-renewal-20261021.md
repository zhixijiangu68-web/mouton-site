# サイトの作り直し（2026-10-21）

> オーナー「シンプルに続けていきたい」。決めることを最小にして、小さく進める。

## 何をするか

- **サイトは決定版**：全文・無料・出典つき。**note は一部**、**X は止まる一行**（X → note → サイト）
- **扱うこと**：食・身体・お金・生き方で「よく言われていること」を、出典まで遡って確かめる
- **記事の型**：判定表 → 根拠 → 問いを一つ。「僕の結論」は置かない。結論は読む人が考えること（2026-10-22、オーナー）。**長さは本文1万〜2万字**（2026-10-22、オーナー「サイトは決定版だから重厚にして欲しい」「サイトは1万~2万文字にする」）。数えないのは front matter・参考文献・タグ・空白で、`npm test` が数える。note は2,000〜4,000字（一部。続きはサイト）、X は1投稿に収まるぎりぎり（140字まで、120〜140字をめざす）。これからも同じ。完成品はオーナーが読む
- **今までの記事はアーカイブへ**：消さない。URL もそのまま
- **有料記事は急がない**。販売の仕組みは止めたまま残す

## 決まったこと（オーナー）

- **長期の方針（2026-10-22、オーナー）**：2〜3年のプロジェクト。焦らず、奇抜なことをせず、記事をコツコツ積み重ねる
- トップの見出し：君はどういう人間として生きたいのか？／答えられないのなら知識が足りていない。
- 配色：紙・墨・藍。赤（朱）は「×」だけ
- ナビ：ムートンについて／アーカイブ。トップに記事の一覧（新しい順・おすすめ・人気順）と検索だけを置く（10/21、オーナー「それだけのシンプルなサイトでいい」）
  - おすすめ：記事の `pick`（1が先頭）。人気順：`src/_data/popular.json`（過去4週間の閲覧数）。空のあいだは新しい順と同じ
- **理解度テスト**（2026-10-22、オーナー「記事について、どれくらいの理解度があるのかを測るテストも作成したい」）：`test.html`。メニューは 理解度テスト／ムートンについて／アーカイブ
  - 記事とは切り離す：記事にはテストの印もリンクも置かない（入口はメニューだけ）。テストから記事の節（`<記事>.html#s-N`、h2 に上から順に付く id）へリンクする
  - 記事ごとの理解度テスト：4択を8〜10問、1問ずつ答える → ○ 正解／× 不正解・解説・「記事のこの節を読む」→ 最後に「理解度 X / N」と間違えた問題。保存・時間制限・演出はしない。JS が無いときは問題と答え（開くと見える）を並べる
  - 問題は `src/_data/understanding/<記事のファイル名>.json`（q・choices・answer 0〜3・why・section＝記事の h2 の文字）。形と節へのリンクは `npm test` が確かめる

3. **公開**：オーナーが見て、よければマージ

## 判定の決まり

| 判定 | 印 | 使うとき |
|---|---|---|
| 支持 | ○（藍） | ヒトの研究で、主張の向きの結果が出ている |
| 否定 | ×（朱） | ヒトの研究で、主張と逆、または差がない |
| 弱い | △（灰） | 研究はあるが、小さい・短い・資金が偏っている |
| 証拠なし | ―（灰） | ヒトで確かめた研究が見つからない |

確かさは 高／中／低／非常に低。研究が一つだけ、動物だけ、観察だけ のときは「中」より上にしない。

## 守ること

- 数字と参考文献は、原典を開いて確かめたものだけ書く
- 健康の記事は `health: true`。「効く」「治る」と言い切らない
- 演出を足さない。スマホ幅（390px）で崩さない。`npm test` を通す
