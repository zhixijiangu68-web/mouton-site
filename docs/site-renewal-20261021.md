# サイトの作り直し（2026-10-21）

> オーナー「シンプルに続けていきたい」。決めることを最小にして、小さく進める。

## 何をするか

- **サイトは決定版**：全文・無料・出典つき。**note は一部**、**X は止まる一行**（X → note → サイト）
- **扱うこと**：食・身体・お金・生き方で「よく言われていること」を、出典まで遡って確かめる
- **記事の型**：判定表 → 根拠 → 僕の結論 → 問いを一つ
- **今までの記事はアーカイブへ**：消さない。URL もそのまま
- **有料記事は急がない**。販売の仕組みは止めたまま残す

## 決まったこと（オーナー）

- トップの見出し：君はどういう人間として生きたいのか？／答えられないのなら知識が足りていない。
- 配色：紙・墨・藍。赤（朱）は「×」だけ
- ナビ：記事／ムートンについて／アーカイブ

## 決まるまでの扱い（AI が仮に決めた。いつでも変えられる）

- ロゴの下の一言：出さない
- 読者の呼び方：呼びかけを使わずに書く
- 広告・成功の見方・英語版：今のまま

## 進め方

1. **土台**：新しいトップと記事の型を、公開しない枝で作る ← いまここ
2. **最初の記事**：「肉を食べても、性欲は上がらない。」を、数字と参考文献をすべて原典で確かめて書く
3. **公開**：オーナーが見て、よければマージ

## オーナーにお願いすること

- 段階3で見て、よければマージ
- 本人の言葉を2〜3文ずつ：最初の記事の「僕の結論」と、トップの「書いている人」

## 判定の決まり

| 判定 | 印 | 使うとき |
|---|---|---|
| 支持 | ○（藍） | ヒトの研究で、主張の向きの結果が出ている |
| 否定 | ×（朱） | ヒトの研究で、主張と逆、または差がない |
| 弱い | △（灰） | 研究はあるが、小さい・短い・資金が偏っている |
| 証拠なし | ―（灰） | ヒトで確かめた研究が見つからない |

確かさは 高／中／低／非常に低。研究が一つだけ、動物だけ、観察だけ のときは「中」より上にしない。

## 守ること

- 数字と参考文献は、原典を開いて確かめたものだけ書く
- 健康の記事は `health: true`。「効く」「治る」と言い切らない
- 演出を足さない。スマホ幅（390px）で崩さない。`npm test` を通す
