- 2026-10-17 時点で、売上は0件。X の投稿も0本。**買ってもらえない一番の理由は、決済よりも、まだ誰にも届いていないこと**。note に移しても、これは自動では解けない。

## 2. note で収益にできるもの

| 手段 | 向き・不向き（いま） |
|---|---|
| 有料記事（有料ライン） | **使える。** 無料の冒頭＋有料の続き。決済・購入者への表示・返金の受付は note が行う |
| 有料記事にファイルを付ける | 記事へのファイル添付は 1ファイル 50MB まで。ヘルプに「動画やファイルを販売する」の項目はあるが、**有料エリアに PDF を置いて売れるかは、本文を開けず未確認** |
| 有料マガジン（買い切り） | 記事が増えてから。いまは1本ずつ |
| 定期購読マガジン・メンバーシップ | **いまはやらない。** 続けて書く約束になり、読者がいない段階で負担が大きい。定期購読マガジンは手数料率も高い |
| サポート（チップ） | 設定は軽いが、読者が増えるまで収益はほぼ出ない |
| 記事内のアフィリエイト | 禁止ではないと解説されているが、note の規約の本文は未確認。広告であることの明示が必要。**note の記事はサイトの記事へのリンクにとどめ、リンク先で扱う**（いまの `note/before-you-buy` の形） |

## 3. 手数料（2,980円の商品が、クレジットカードで売れたとき）

note の公式ヘルプ「コンテンツを販売する際に引かれる手数料」の検索結果から。**ヘルプページ自体はこの環境から開けなかった**ので、公開前にオーナーが公式ページで料率を確かめる。

- 事務手数料（購入者の決済手段で決まる）：カード 5%、携帯キャリア決済 15%、PayPay・Amazon Pay 7%、note ポイント 10%、PayPal 6.5%
- プラットフォーム利用料：（売上 − 事務手数料）の 10%（有料記事・有料マガジン・チップ・メンバーシップ。定期購読マガジンは 20%）
- 振込手数料：1回の振込ごとに 270円

|---|---|---|

## 4. 3つの道

| | A. note は集客だけ（いまの決定） | B. 3本のうち1本だけ note でも売る（並行テスト） | C. 3本とも note で売る（決定を戻す） |
|---|---|---|---|
| 売れる状態になるまで | サイトの納品が通るまで（オーナー作業が多い） | **note に貼って価格を決めれば、その日から** | 同じ |
| リポジトリの変更 | なし | **なし**（サイトの販売ページは「準備中」のまま。note の商品はサイトからリンクしない） | 販売ページ・`site.js`・`check-paid-sales.mjs`（note の購入表記を禁じている）を変える |
| 検証できること | 納品までの通し | 第三者が2,980円を払うか（販売可能の条件を note に任せて） | 同じ |
| 手取り | 約 96% | 約 85% | 約 85% |
| 弱いところ | 10月中に売れる状態になるか分からない | 同じ商品を2か所で売る形になる。どちらが先に売れたかで、流入の学びが分かれる | 10/16 の決定（PDF・自分のサイト・手数料）を取り消す |

### 推薦：B（ただし、オーナーの「はい」が出てから）

- 10月中に「第三者による実決済1件」を確かめるには、購入できる状態にするのがいちばん早い。納品・返金・購入者の表示を note に任せられる。
- 価格は**サイトと同じ 2,980円**にする。別の価格にすると「2,980円を払う人がいるか」の検証が濁る（低い価格は別の仮説）。
- どの1本にするかは、販売ページと入門記事がもっとも整っているものを、オーナーが選ぶ。
- Bをやっても、サイトの販売準備（納品の確認など）は止めない。サイトが通ったら、note の商品は残すか下げるかを、売れた記録を見て決める。
- 公開前に、次の4つはオーナーが確かめる。
  1. note の手数料の料率（公式ページ）
  2. 有料エリアに PDF を置いて売れるか。置けないなら、note 版は記事だけになり、書き込み用ページが付かない。**サイトの PDF と同じ商品ではなくなる**ので、販売ページの表記を変えずに、別の名前（「note 版」）で出す
  3. 販売者としての表示（特定商取引法）の扱い。note の説明は「販売業者に当たらなければ住所・電話番号の掲載は不要」。継続して売る個人が販売業者に当たるかは、消費者庁の通信販売のガイドで確かめる（`docs/philosophy-sales-20261016.md` の手順6と同じ確認）
  4. note の返金の扱い（購入後24時間以内に申請できるという説明を見かけたが、審査があり、公式ページでは未確認）

## 5. 守ること

- 「必ず」「今だけ」「残りわずか」などのあおりを使わない。実在しない口コミは載せない（`docs/product-first-strategy-20261015.md` 2.6）。
- 売れた件数は、note の売上画面や Stripe の記録で確かめたものだけを書く。閲覧数・フォロワー数を成果にしない。
- note の記事から広告のある記事へ案内するときは、冒頭に「広告を含みます」（`CLAUDE.md`）。
- 無料の入門記事とサイトの入門記事を**同じ文で2か所に出さない**。note 版は別の切り口で書く（検索で重なるのを避ける）。
- AI は note にも SNS にも投稿しない。公開はオーナー。

## 6. 役割分担

**AI がすぐできること（オーナーの決定を待たない）**
- `note/before-you-buy`・`note/job-change` の公開前チェックを再点検する。
- 哲学の入門記事（3人）の note 版を、`/note` で作る（重ならない切り口で）。末尾に `?utm_source=note&utm_medium=referral&utm_campaign=<slug>` つきでサイトの販売ページへ。

**オーナーがすること**
- 決める：A / B / C のどれか。Bなら、どの1本か。
- note のユーザー名を教える（`author.note` に入れる）。
- 公開前に、手数料・PDF の添付・特商法・返金の4つを公式ページで確かめる。
- note への貼り付けと公開（有料ラインの位置は、AI が「リスト」として渡す）。

**Bに決まったあと、AI が作るもの**
- 出品シート：タイトル案、無料の冒頭と有料ラインの位置、記事の説明、ハッシュタグ、価格 2,980円、購入者への一言、X・Threads の告知文。
- 全文はリポジトリに入れない。オーナーが持っている note 用の全文を、オーナーが貼る。

## 7. 測るもの

- 主指標：note の売上画面で確かめた、**第三者の購入件数**（`product-first-strategy` の「初回検証」と同じ）。
- 流れの見方：note の記事の閲覧 → 有料の冒頭を読み切った → 購入。note 側の数字は note の画面で見る。サイトへの流入は GA4 の `utm_source=note`。
- 数字が少ないうちは、価格や文章のどこが悪いと決めつけない（`product-first-strategy` 2.7）。

## 8. 確かめられなかったこと

- note ヘルプの本文（手数料・ファイル販売・特商法・返金）：この環境から `help-note.com` を開けず、検索結果の要約だけで確かめた。
  - 2026-10-17（初回の公開の前）に検索し直した結果：手数料は上の3のとおり。**有料エリアにファイル（PDF）を添付して売れる**（1つ50MBまで、ダウンロードは公開後に有効）。返金は、記事ごとに「受け付ける／受け付けない」を選べる（受け付けると、購入から24時間以内の申請を note が審査）。特商法の表示は「販売業者」（利益を目的に、くり返し取引する人）に当たる場合だけ必要。4つの答えと、オーナーが決めること（特商法・返金の設定）は、有料3本の `listing.md` の「公開前の4つの確認」。
- 初めて有料記事が売れるまでの目安：個人の体験談（数か月〜1年以上かかった例、フォロワー125人で7か月かかった例）しか見つからなかった。**再現性は不明**。「note に出せばすぐ売れる」とは言えない。
- Stripe の国内カード料率：一般に 3.6% と案内されているが、Stripe の料金ページで確かめていない。
