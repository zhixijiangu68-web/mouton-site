## 1. 答え：一部。骨組みは良い。足りないのは「最初の2画面」「誰が、どう確かめたか」「読み終えたあとの口」と、自分の数字

結論の題 → 判定表 → 結論の一文の h2 → 出典 → 問いを一つ、という骨組みは残してよい。英語圏で信頼と収益のある所と同じ「判定を先に出す」向きだからだ。Examine は収益の100%が会費（おそらく。月29ドル）で、Wirecutter・Our World in Data も同じ向き。日本語のウェブで、通説を一つずつ判定して確かさを付ける個人は見つからなかった。本の形では、食品を5つに仕分けた『究極の食事』が10万部を超えている。

足りないのは次の3つだ。

1. **結果が最初の2画面にない。** 閲覧時間の74%は最初の2画面に集まる（NN/g 2018）。色気の記事では、判定が見え始めるのが2.8画面目【計測】。
2. **誰が・どう確かめたかが、画面にない。** 17本で「僕」も「あなた」も0回。署名もない。判定の決まりは内部の文書にしかない。日本の検索で強い所は、書き手を記事の上に出している（All About のガイド約900名、Medical DOC の監修医500名以上）。英語圏で稼いでいる個人は、調べた範囲ではみな一人称で書いていた。
3. **読み終えたあとの口がない。** 調べた収益の形は、どれも名簿から始まっていた。無料から有料への転換は、中央値で3%前後（0.62%という報告もある）。

さらに、どの記事がどこまで読まれたかを誰も測っていない。「調査と実行が足りない」は当たっている。いちばん足りないのは、測るという実行だ。なお、どの型を選んでも10月の収益は出ない。

## 2. 推す型：結果を先に、作り方を見せる

骨組みは変えない。足すのは次の3つ。

- 結果の3行（最初の2画面に入れる）
- 誰が・どう確かめたか（署名の行、判定の決まりの公開、作り方の段落、本人だけが書く欄）
- 読み終えたあとの口（X と RSS）

画面で増えるのは、署名の行・結果の3行・続きの口の3つ。代わりに、表の前の注2段落が1行に減る。オーナーの「余計なものはいらない」「1だけ」に合わせ、3つの案のうち、数字か信頼の理由のある部品だけを残した。

### 2-1 2人の採点の食い違いを、どう決めたか

伸びの採点は「人と物語の型」を1位（10点中6.4点）、信頼の採点は「結果が先の型」を1位（10点中7.5点）にした。2人とも組み合わせた型を出しており、部品の多くは重なっている。食い違った点は、次のように決めた。

| 点 | 伸びの採点 | 信頼の採点 | 推す型 | 理由 |
|---|---|---|---|---|
| 土台 | 人と物語 | 結果が先 | 並びは結果が先。人と物語の型からは、本人だけの欄・npm test・lint・続きの口を取る | 数字で支えられているのは「最初の2画面に届く」ことだけ。続きの口は2人とも入れている |
| 判定の理由の「僕」 | 判定が割れた節だけ「僕は〜にした」 | 「僕」を使わない | 主語を置かずに書く（「この行を△にしたのは〜からだ」）。オーナーが原典を開いた行だけ「僕が原典で確かめた」と書く | 下書きと照合は AI がしている。「迷いながら試している一人」という看板と食い違えば、人で崩れる |
| 変わりやすいところ | 新しい h2 にする | 最後の節の段落にする | 最後の節の段落にする | h2 を足すと節の番号（s-N）がずれる。2万字の上限まで180〜230字しか残っていない記事が3本ある |
| 表の並び | 節の順のまま | 確かさの順 | 1行目は題の主張。あとは節の順 | 表が目次を兼ねる。179行を並べ替える手間がかかる。確かさの順が効くというデータはない |

## 3. 文体の決まり

| 項目 | 決まり | 理由（根拠） |
|---|---|---|
| 文末 | 常体（だ・である）のまま。編集方針の新しい節だけは、そのページに合わせて敬体 | 敬体と常体の差を調べた研究は見つからなかった。常体は判定の落ち着きに合い、`docs/content-quality.md` の決まりとも同じ |
| 一人称 | 「僕」は、オーナーが自分でしたこと・決めたことにだけ使う。体験と気持ち（信じていた・試した・驚いた）は本人だけの欄に書く。判定の理由は主語を置かずに書く。オーナーが原典を開いた行は「僕が原典で確かめた」と書ける | 稼いでいる個人はみな一人称だった（事例。成功した例だけを見ている）。ただ、下書きと照合は AI がしている。看板と食い違えば人で崩れる（DaiGo は2021年の炎上のあと事業ごと揺れた） |
| 呼びかけ | 読む人への問いは、最後の一つだけ。本文の「あなた」は1本に2回まで。命令・勧誘（〜しよう・〜すべき・〜するとよい）は書かない。読む人の体や性の経験を尋ねる文、外見の不安を突く文も書かない | BRAND.md「一人に語りかける」「安易に与えない」（問いは最後に一つだけ）。話しかける文体は、応用に中程度、記憶に小さいプラスの効果があった（Ginns 2013。教材の研究で、逆向きの2024年の研究もある） |
| 文の長さ | 一文の平均は35字前後。80字を超える文は作らない。段落は2〜4文・150字まで。段落の1文目に要点を置く | 色気の記事の書き直しで、一文の平均は44.1字から34.0字に、90字を超える文は13から0になった（作業ログ）。簡潔にした版は使いやすさが58%高かった（NN/g 1997。小さく古い研究） |

| 見出し | h2 は結果の一文のまま。h2 だけを縦に読んで、筋が分かること | 見出しは節の話題の記憶を助ける（Lorch）。見出しを拾って読む人に合う（NN/g 2017） |
| 結果の3行 | 主語は研究。条件（何を・誰で測ったか）を同じ文に入れる。数字は本文にあるものだけ。読む人の行動を書かない。「だから」「つまり」「結論」「おすすめ」「あなた」は使わない | X や AI の要約に1文だけ抜き出されても、条件が落ちないようにする【判断】。「僕の結論」を置かない決まりも守れる |
| 根拠の欄 | 一文で、60字めやす・80字まで。主な人数か数字を一つ入れる。限定の言葉（研究が一つ・写真への印象・動物だけ・観察だけ）は消さない | スマホでは表が行ごとのカードになり、いちばん読まれる場所になる。読まれるのはページの文字の20〜28%（NN/g 2008） |
| 使わない言葉 | 判明・衝撃・驚き・ウソ・ホント・大間違い・警告・断言・科学的に証明・最強・正解。生き方の結論がにじむ「大切だ・大事だ・するとよい・したほうがいい・おすすめ」。性・外見の記事の「モテる・色気が出る・〜すれば」 | あおらない。Google の自己点検「誇張や衝撃的な表現を避けているか」。Discover は性的な刺激に訴える題を避けるよう求める。AdSense は性的な能力の助言を「制限」にしている |
| 性の記事 | 研究と医学の言葉で書く。評価しない・恥をかかせない・正常の幅を示す。露骨な描写をしない | Lehmiller・Nagoski の語り口【一般知識】。note・Discover・AdSense の決まり |

結論の線は三段に引く。lint で点検できるようにする。

1. 研究の判定は言い切る
2. 証拠のまとめは書く
3. 生き方の結論（だからどうするか）は書かず、問いに変える

## 5. 収益の道筋：何を、いつから、どの順で

- 型そのものは稼がない。稼いでいるのは、記事の隣にあるもの（名簿・横断した一覧・保存版・本）だった
- BRAND.md は、会員制・定期購読・休むと失う仕組みをつくらないとしている
- CLAUDE.md の順番は、商品の完成 → 販売の準備 → 集客 → 実購入の確かめ。作り直しの文書は「有料記事は急がない」

**使わない形**

- 会員制・定期購読・サロン：BRAND.md に当たる
- 広告を柱にすること：1PV で0.2〜0.3円。月10万円には33万〜50万PV が要る【試算】。性の記事は「制限」で広告が減る
- アフィリエイト
  - 判定で × や △ が付く物は売れない
  - クリニック・サプリ・精力剤は、医療広告ガイドライン・薬機法・ステマ規制に当たる
  - 本の紹介はできるが小さい（楽天の本は3%で、1,500円の本なら45円【試算】）
- note の有料記事：売れるのは実用ノウハウ（平均1,842円）で、読み物は983円。性の話題は審査が厳しい。note は入口（記事の一部）のまま使う

**主題の配分**

- 性を中心にした7本は、人を集める
- けれど、広告（制限）・note の有料（厳しい）・X の収益分配（対象外）のどれにも乗りにくい
- 稼ぐ役は、お金・食・生き方の柱に持たせる【判断】

## 8. 調べきれなかったこと・確かさの低いところ

1. **ページの中は開いていない。** 6つの調査とも WebFetch が通らず、記事の型は検索結果の題と要約から読んだ。次のものは【一般知識】のまま

   - Examine の見出しの並び
   - ACX と ParentData の構成
2. **規模の数字の多くは、自己申告か推計。** Psychology Today の「月2,000万訪問・年1億ドル超」は、確かめられない推計。「その型だから伸びた」を示す数字は、どこにもない
3. **読まれ方のデータは古く、米国の英語。** 2005〜2016年のもので、日本語の読了率の公開データは popIn 2014（新聞社のサイトで70%。定義は不明）くらいしかない
4. **見つからなかったデータ。** 次の効き目を測った研究は見つからなかった
   - 目次・出典の見せ方・更新日の表示
   - 情報を運ぶ図
   - 敬体と常体の違い
   - 日本語の、問いの題と結論の題の比べ
   - 「結論を置かない」こと
   - 否定の題が続くこと
5. **一人称と物語の効き目の研究は、ウェブの記事の研究ではない。** 教材と健康の伝え方の研究で、逆向きの2024年の研究もある
6. **位置の計測は Chromium のもの。** 390×844 で測った。Safari の見える高さ（約664px）では、画面の数が約1.27倍になる【試算】。推す型を一つにまとめた試作はない。部品は、3つの案が別々に試した
7. **収益で調べていないこと。** Amazon の今の料率表、Amazon と ASP の性的なサイトの審査の原文、クリニックの報酬、科学・健康の note の売れ方、theLetter、講座。英語圏の転換率が、日本語の小さな名簿にそのまま当てはまるかも分からない
8. **ムートン自身の数字がない。** PV・読まれた深さ・X のフォロワー・note の読了率。この提案の弱みの見立ては、外のデータからのもので、ムートンの読者で確かめたものではない
9. **作業時間の見積もりは推測。** 特に、人が原典を確かめる時間は分からない
10. **2人の採点の点数（6.4点・7.5点など）と重みは【判断】。** 2人の結論は、組み合わせた型ではほぼ重なった

## この提案から分かること

1. 骨組み（結論の題 → 判定表 → 結論の h2 → 問い）は、信頼と収益のある所と同じ向きだった。日本語のウェブで個人がやっていない空きにもいる。変えるのは、型の外側だ
2. 数字で強く支えられているのは「最初の2画面は読まれ、最後まで来る人は少ない」ことだけ。だから結果・分かっていないこと・限定の言葉を、上に寄せる
3. 信頼のいちばんの穴は、書いていることと実際の作業のずれにある。原典の確かめ方、広告のコードと収入の文、体験の文が誰のものか。部品を足すより先に、これをそろえる
4. 一人称は、オーナーが書いたことだけなら信頼を足す。AI が書けば、看板を崩す
5. 収益は、型からではなく隣から来る。名簿 → 判定の一覧 → 柱ごとの PDF → 本の順。性の記事は集める役で、稼ぐ役は別の柱に持たせる
6. 次の一歩は、外の調査ではなく自分の数字を取ることだ。GA4 の書き出しと、4週の比べから始める
