# コピーライティングの決まり（2026-10-18）

> **オーナー：「コピーライティングが第一優先」「美しさに勝る」**
> 同日：「冒頭に誰に対しての記事なのか。何を示すのか。何が得られるのか」「文章の美しさよりも具体的で分かりやすいかどうかを重視したい」

- 方針の全文は `BRAND.md`「コピーライティング第一」と `docs/content-quality.md` の 0（同日、オーナー「全てコピーライティングを第一優先にしてください。美しさなんて二の次です」）。この文書は、その方針で使う型・使わない型・チェックリスト・根拠をまとめたもの。ぶつかるときは、方針の全文のほうを先にする
- 対象：note・X・サイトの記事・販売ページの、題・冒頭・見出し・リンクの前の一文・告知・説明文
- 言い方の決まり（`BRAND.md`：押しつけない・命令しない・約束しない・あおらない・見下さない）は、そのまま守る。コピーライティングの型のうち、これとぶつかるものは使わない（下の4）
- 調べた中身と出典の URL は `docs/copywriting-research-20261018.md`。確度：◎＝文言と書誌を検索結果で確かめた／○＝書誌は確かめ、文言は二次資料／△＝二次資料だけ。原典の本文は開けていない

## 1. 書く順番

1. **誰に**：読む人の言葉で、悩みか場面を名指しする（「人の目が気になる」「決められない」「続かない」）。「〜な人」というラベルより、「〜とき」「あなたがいま、こうなら」と状況で書く
2. **何を示すか**：哲学者の名前と原典の言葉、研究で分かったことを、具体的な名詞で書く。「〜について」「〜の見方」「〜の問い」という呼び名で止めない
3. **読んで手元に残るもの**：見方・問い・材料・届くもの。結果（気にならなくなる・変われる・続けられる）は約束しない
4. **そのあとで、言い回しを整える**：比喩・余韻・対句・響きは、分かりやすさを邪魔しない範囲で使う

## 2. 使う型

| 型 | やること | 出典 |
|---|---|---|
| 具体的に書く | 一般論・形容詞より、固有名・一つの場面・原典の章・研究の中身（誰に、何をして、何が分かったか） | Hopkins『Scientific Advertising』1923 ◎ |
| 題で読む人を名指しする | 題の頭で、誰の話かを読む人の言葉で示す | Hopkins 1923 ◎ |
| 題と1行目に時間を使う | 題・説明文・冒頭・見出し画像の文言・X の1行目を、本文と同じくらい練る | Ogilvy『Confessions of an Advertising Man』1963 ◎（題は本文の5倍読まれる。紙の広告の話） |
| うまいより、分かる | 「うまい」と言われる文より、何がどうなのかが分かる文 | Ogilvy『Ogilvy on Advertising』1983 ◎、谷山雅計『広告コピーってこう書くんだ！読本』2007 ○（「なんかいいよね」を禁句に） |
| 新しい事実を前に出す | 研究で分かったこと、原典の一節を、題・1行目・見出しに置く | Caples『Tested Advertising Methods』○ |
| すでにある願いに向ける | 欲しい気持ちはコピーではつくれない。読む人がもう持っている願いに、哲学を道具として向ける | Schwartz『Breakthrough Advertising』1966 ○ |
| 最初の一文は、二文目のため | 1文目は短い場面、2文目は誰に、3〜4文目は手元に残るもの | Sugarman『The Adweek Copywriting Handbook』2006–07 ◎ |
| 平易に、一文一義で | 一文に一つのこと。名詞の前に長い修飾を積まない。漢語・カタカナ語より和語 | 唐木元『新しい文章力の教室』2015 ◎、Oppenheimer 2006 ◎、Shulman ほか 2024 ◎ |
| 悩みの名指しと、親近感 | 悩みを一つ、大きくせずに書く（Problem）。ムートン自身の迷いを冒頭の近くに置く（Affinity。本人が書いた・確かめた経験だけ） | 神田昌典『稼ぐ言葉の法則』2016 ◎（新PASONA） |

研究の裏づけ：読者は平易な見出しを選び、書き手（記者など）にはその好みがなかった（Shulman ほか 2024、Washington Post と Upworthy の A/B テスト3万件超）。難しい言葉は書き手を賢く見せない（Oppenheimer 2006）。「美しさに勝る」は、この2つと同じ向き。

## 3. 形を変えて使う型

- **得を示す見出し**（Ogilvy・Caples）→ 示すのは手元に残るもの（見方・問い・材料）まで。効果の言い切りは、景品表示法の優良誤認・不実証広告にも触れうる
- **特徴より便益**（「ドリルではなく穴」。レビットの言葉ではなく、1940年代の McGivena の言葉）→「哲学が学べる」ではなく「決められない夜を、別の角度から見る」。穴（結果）は約束しない
- **4U**（Useful・Urgent・Unique・Ultra-specific）→ Urgent を外す。Useful を「〜する方法」「3つのステップ」の題で満たさない（安易に与えない）
- **新PASONA の Solution・Offer・Narrowing down・Action** → 解決は見方と問いとして書き、答えは渡しきらない。提案と絞り込みは事実で案内する（価格・届くもの・「あなたがいま、こうなら」）。行動は命令しない
- **問いの題** → 研究で結果が割れる（Lai & Farbrot 2014／Scacco & Muddiman 2016）。題は「誰に＋何を」の言い切りを基本にし、問いは最後に一つ

## 4. 使わない型

- **問題をあぶりたてる**（PASONA の Agitation）：神田氏自身が、恐怖をあおる危険を理由に Affinity へ替えた
- **好奇心だけの題、前方参照**：指すもののない「その」「あの」「これ」「〜の正体」「〜とは？」で引っぱらない（Blom & Hansen 2015）
- **否定的な言葉・恐れでクリックを増やす**（Robertson ほか 2023 はクリックが増えたと報告。MOUTON の物差しはクリックではなく第三者の購入）
- **急がせる**：今すぐ・期間限定・残りわずか（有利誤認のおそれ。消費者庁は2025年にも「期間限定」「今だけ」に措置命令）
- **作った具体**：作った数字・体験談・口コミ。具体的な言葉は本当らしく見えるので（Hansen & Wänke 2010）、確かめた具体だけを書く
- **広告であることを隠す**：頼んだ紹介・アフィリエイトには「PR」（ステマ告示、2023年10月1日施行）

## 5. 形

- **note の題**：「[読む人の言葉の悩み]ときに。[示すもの：研究の中身／哲学者と原典の言葉]」か、「[ムートンの経験]。[示すもの]」。40字以内
- **冒頭（3〜4文）**：場面を1文 → 誰に向けたか → 手元に残るものを中身まで（「研究の見方」で止めず、何が分かったかまで）
- **見出し**：何が分かったか・誰が何を言ったかを文で。名詞の対句にしない。本文より強く言い切らない
- **リンクの前の一文**：リンク先で何が読めるかを具体的に。リンク題の「その〜」が指すものを、前の文に書いておく。リンクは1本に絞る
- **終わり**：答えを書かない問いを一つ
- **X**：1行目に「誰に」か「新しい事実」。1投稿に言いたいことは一つ。研究の条件も同じ投稿に
- **販売ページ**：冒頭の4つ（どんな悩みに／読んで、考えられること／届くもの（PDF）と価格／いま買えるか。`CLAUDE.md`）。価格と条件は事実のまま。「今だけ」は書かない

## 6. チェックリスト（題・冒頭・見出し・リンクの前・告知に当てる）

1. **誰に**：題（X は1行目）に、読む人の言葉で悩みか場面がある。ラベルではなく状況で書いた
2. **何を**：示すものを具体的な名詞で言えている。「〜について」「〜の見方」「〜の問い」で止まっていない
3. **手元に残るもの**：見方・問い・材料・届くものを書いた。結果は約束していない
4. **具体**：固有名、一つの場面、章や年、研究の中身。雰囲気の言葉・比喩・対句・余韻で止まっていない。数字は出典どおり
5. **平易**：一文に一つのこと。長い修飾を積まない。声に出して読み、つかえるところを削った
6. **一つだけ**：1本（1投稿・1見出し・1リンク）で言いたいことは一つ
7. **謎で引っぱらない**：指すもののない「その」「あの」「〜の正体」「〜とは？」がない。気を引くための問いの題にしていない
8. **本文と同じ強さ**：題・説明・画像の文言・告知は、本文より多くを言っていない
9. **書かないこと**：命令・断定・約束、あおり（今すぐ・期間限定・損）、恐れや自己嫌悪を燃料にする言葉、見下し、作った口コミ、隠した広告、ワーク・手順の箇条書き
10. **終わり方**：最後は答えを書かない問いが一つ。リンクの前の一文は事実の案内

## 7. 根拠の限界

- 研究のほとんどは英語のニュース見出しで、測っているのはクリックと印象。購入は測っていない。日本語の note や哲学の文章を調べた研究は見つからなかった
- 問いの題・釣りの題の効果は、研究で結果が割れている（Lai & Farbrot 2014、Scacco & Muddiman 2016、Molyneux & Coddington 2020、Munger ほか 2020）。使わない理由は、研究ではなくブランドの決まりに置く
- 数が少ないうちは、X の数字の差から、どの言い回しが効いたかは言えない。1つずつ変えて、週次で見る
