# 幅広いテーマへ（2026-11-13、オーナー）

`CLAUDE.md` の先頭の節と、`docs/security-renewal-20261104.md` の「セキュリティの個人研究サイト」より優先する。セキュリティの記事の書き方の決まり（攻撃の技術・悪用の手順・出典）は、そのまま使う。

## オーナーの言葉と選んだこと

- 「セキュリティに限らず、幅広いテーマを扱いたい」
- 選んだこと（AskUserQuestion）：
  - テーマ：**暮らし・趣味**と、**以前の柱を戻す**（食・身体・お金・生き方・哲学）。セキュリティの記事21本はそのまま残す（IT 全般・学びと仕事は選ばれていない）
  - トップの見出し：**広い言葉に変える**（言葉の案は AI が出し、オーナーがあとで直す）
  - 書き方の決まり：**テーマごとに変える**

## サイトの形

- トップの見出しは「調べて、試して、書き残す。」（案。オーナーが直すまで）。短い文は「ムートンの個人のノート。セキュリティ、食と身体と生き方、暮らしと趣味。学んだことと確かめたことを、出典つきで置いていく。」
- 名前とアドレスはそのまま（ムートン／moutonarchive.com）
- 棚（front matter の `pillar`）：
  | 棚 | pillar（表示） | 本文の長さ | 書き方 |
  | --- | --- | --- | --- |
  | セキュリティ | `ctf`（演習・CTF）・`vuln`（脆弱性・事件）・`defense`（守る） | 5,000〜6,000字 | `docs/security-renewal-20261104.md` の「書くときの決まり」1〜8 |
  | 食・身体・お金・生き方・哲学 | `food`・`body`・`money`・`life`・`philosophy` | 1万〜2万字 | `docs/site-renewal-20261021.md` の型（判定表 → 根拠 → 問い）と `docs/content-quality.md`。健康の記事は `health: true` |
  | 暮らし・趣味 | `fashion`（装い）・`interior`（部屋）・`scent`（香り）・`music`（音楽）・`gourmet`（食べ歩き）・`outing`（おでかけ） | 2,000〜3,000字 | 下の「暮らし・趣味の書き方」 |
- 長さは `npm test`（`scripts/check-current-pages.mjs`）が棚ごとに数える
- 2026-11-04 にアーカイブへ移した判定表つきの16本（食・身体・生き方）は、いまの記事に戻した（`src/_data/currentArticles.js`、おすすめの順は 22〜37）。それより前の記事（哲学の連載など）はアーカイブのまま。戻すかはオーナーが決める
- 「ムートンについて」（`start.html`）は、置くもの（3つの棚）・書くときの決まり・攻撃の技術を試すときの決まり・これまでの記事、にした

## 暮らし・趣味の書き方

- 本文 2,000〜3,000字。コピーは題だけ、本文は簡潔に結論から、問いかけをしない（`docs/security-renewal-20261104.md` の決まり 8 と同じ）
- 商品・店・場所の事実（価格・営業時間・発売日・住所）は、公式か販売ページで確かめた値だけ書き、確かめた日を書く。確かめられなければ書かない
- 宣伝の言葉で書かない。評価は主観と分かるように書く。アフィリエイトを入れるなら `affiliate: true`（PR の表示が付く）
- 写真は載せない（著作権）。写真のある公式のページへリンクする
- オーナーが毎日受け取っている定期実行（dress・大人の部屋づくり便・香りデイリー・音楽デイリー・中華デイリー・おでかけデイリー）を話題の元にしてよい。オーナー本人の体験の作り話は書かない

## 止めたままのもの

- note の有料記事・X の運用・AI 社員の定期の仕事は止めたまま（2026-11-04）。オーナーが再開を言うまで使わない
