note 公開キット

無料の20本で世界観を伝えてから、有料を出します。公開する順に並べてあり、下書きの URL を入れると、本文の中のリンクが埋まります。

最初の1件の購入までに、残っていること

    「公開」の印と URL から、自動で更新します。

    使い方

    1. その日に出す記事の下書きを作り、URL を入れる。note で記事を新しく作り、タイトルを貼って下書き保存します。「…」のメニューの「共有用リンクをコピー」で開くページに、公開したときの URL が出ます（下書きを直しても変わりません）。それを「公開時の URL」に貼ります。
    2. 「本文をコピー」を押して、note の本文の欄に貼る。見出し・太字・引用・箇条書き・リンクは、貼るだけでそのまま入ります（書式つきの形と Markdown の形を、一度にコピーしています）。見出し画像を保存して載せ、ハッシュタグを入れます。
    3. 番号の順に公開する。新しい記事が一覧の上に来るので、この順に出すと、見せたい順に並びます。公開したら「公開」に印をつけます。

    万一、見出しが「##」のような記号のまま出たら、貼った本文を消して、「書式だけでコピー」で貼り直してください。編集画面のアドレスを貼っても、記事の番号（n で始まる13文字）から URL を作ります。最初の1本で、共有用リンクのページの URL と同じになるか確かめてください。

    はじめに：アカウントの設定

    一度だけ。note の設定とプロフィールの編集で入れます。note ID は記事の URL に入るので、記事を出す前に決めます（決めたら、上の note ID の欄も合わせます）。

    マガジン（記事をまとめる棚）

    note の「マガジン」は、記事をまとめて並べる棚です。1本読んだ人が、同じ棚のほかの記事に進めます。クリエイターページの「マガジン」→「作成」で、名前・説明・ヘッダー画像を入れて作り、記事のページの「記事を保存」（または「…」）からマガジンに追加します。下書きの記事は追加できません。無料のマガジンに有料記事を入れても、続きは購入した人だけが読めます。

    入れた URL と印は、このページに保存されます。Claude があとで読み取って、リポジトリの {URL_...} を埋められます。

    文章のもとは、リポジトリの note/ の各フォルダにあります。
