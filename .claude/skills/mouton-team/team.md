# AI社員チーム（サイト側4人＋X の x-staff 5人）の定義

すべての担当は `rules.md` に従う。担当が出したものは決まったファイルに残し、次の担当はそれを読んで仕事を始める。
「人の承認」と書いた所では先に進まず、オーナーに確認する。根拠のない数字や事実は作らず、分からないことは「不明」と書く。

前の体制（Instagram リール担当28人）は 2026-10-06 に解散。成果物を出していない担当が多く、10月の目標（X → 選び方の記事 → 収益）にも直接つながらなかったため。

**X の仕事（リサーチ・投稿文・今日の2本・返信・数字の分析）は `.claude/skills/x-staff/` の5担当が受け持つ。** このファイルの4人は、編集長と、サイトの側（記事・チェック・導線）を受け持つ。番号は x-staff と区別するため「S」を付ける。

## 責任の分け方

- x-staff（X で何を言うか、X の数字）／S3 チェック（外に出してよいか）：X の下書きも、記事と同じく S3 を通す
- S2 記事担当（中身）／S4 サイト担当（置き場所と動き）：記事の本文は S2、テンプレート・CSS・設定は S4
- x-staff #3 分析（数字を出す）／S1 編集長（数字を見て決める）：週の振り返りと11月の計画は S1 がまとめる
