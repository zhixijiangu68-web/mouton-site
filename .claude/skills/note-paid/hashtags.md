# ハッシュタグ

タグは「この記事は何の分類か」を伝えるもの。人を集めるために足すものではない。

強さの印は `structure.md` の冒頭と同じ。根拠の全体は `analysis.md`（とくに 9）。末尾の「→ 9」などは `analysis.md` の節の番号。

---

## 1. 先に知っておくこと

- **付けられる数の上限も、おすすめの数も、公式には見つからなかった**【未調査】。「note の社員の勉強会で3個くらいでよいと言われた」という個人の伝聞があるだけ（日付不明。下の仕様の変更より前かもしれない）【個人・未確認】。社内の決まり（note-titler）は5〜8個。どちらにも出典はない（→ 9・12-1）
- **2026-09-15 から、一部のハッシュタグを検索すると「キーワードページ」が出る**。note の AI が記事の本文を読んで関連する記事を並べるもので、タグを付けたかどうかでは決まらない、という説明。お題・コンテストのタグと、記事の少ないタグは、これまでどおりのハッシュタグページ【公式・未確認】。これより前の「タグで探してもらう」という解説は古いかもしれない（→ 9・2-10）
- タグの記事数（#人生哲学・#生き方 など）は、いつの数か分からない。いまの数は note で見る
- 「大きいタグと小さいタグを混ぜる」の効果を確かめた資料はない【未調査】。社員の定義（`.claude/agents/note-titler.md`）にはこの言い方があるが、このスキルでは決まりにしない（`SKILL.md` の note-titler への依頼）

## 2. 決まり

1. **先に、本文に主題の言葉をはっきり書く**：哲学者名・書名・悩みの言葉を、無料部分の早いところに。キーワードページは本文の中身で決まる、という説明があるため【公式・未確認】。タグを増やすより先にやる（→ 9）
2. **中身に合うタグだけ**。人の多いタグ・流行りのタグを、中身と関係なく付けない。無関係な画像で PV を稼ぐのはすすめない、という note の考え方【公式・未確認】を、タグにも当てる。【決まり】あおらない（→ 9・10-3）
3. **数**：社内の決まり（5〜8個）の中で出す。中身に合うタグが5つに満たないときは、合わないタグで埋めずに少なく出し、`03-titles.md` に理由を書く（数より中身。この食い違いは `SKILL.md`「オーナーに確かめること」）（→ 9・12-1）
4. **組み合わせ**
   - 分野：#哲学 など（本文の分野）
   - 固有：哲学者名・書名・概念（例の形：#〔哲学者名〕 #〔書名〕）。実例の記事にも、哲学者名と概念のタグが付いていた（「ニーチェ」「ルサンチマン」、「ニーチェ」「力への意志」）【実例・未確認：2件】
   - 悩み・場面：本文がその悩みを扱うときだけ（例の形：#転職 #人間関係）
   - お題・コンテスト：note で本当に出ていて、中身が合うときだけ（ハッシュタグページが残る【公式・未確認】）。お題の決まり（期間・条件）をオーナーが確かめる
   - 有料記事を探す人向けらしいタグ（実例：「読んでほしい有料記事」「#有料記事書いてみた」）【実例・未確認：2件、効果は不明】：付けなくてよい（→ 7-2・9）
5. **付けないタグ**：中身と違う読み方を招くもの（健康の記事で「効く」に読めるタグ、本文が言っていない結論のタグ）、あおり（#人生が変わる など）、関係のない人名・商品名
6. **付け方**（オーナーが公開のときにする）：公開の設定のタグの欄に入れる。公開せずに下書き保存すると、欄に入れたタグは消える、という説明がある【公式・未確認】ので、公開の直前に入れる。本文に「#」で書く方法もある【公式・未確認】が、本文には書かない（本文の文字が増え、読みにくくなる）（→ 9）

## 3. 03-titles.md に書く形

```markdown
## ハッシュタグ

#哲学　#〔哲学者名〕　#〔書名〕　#〔悩みの言葉〕

- #哲学：〔本文のどこと合うか〕
- #〔哲学者名〕：〔…〕
- 付けなかったタグ：#〔…〕（理由：〔…〕）
- 5つに満たない理由（あれば）：〔…〕
```

タグの記事数は、確かめたときだけ日付つきで書く（確かめていない数は書かない）。タグは、本文に書いてあることだけ（有料部分にしか出てこない言葉をタグにすると、有料部分の中身を先に見せることになるので、目次の見出しにある言葉まで）。
