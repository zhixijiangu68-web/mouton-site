# 題・記事の説明のコピー

題は「note の一覧で、読んでいる一人が止まり、何の記事か分かり、開く理由がある」一行。記事の説明はその補い。物差しは `docs/content-quality.md` の 0（止まるか・具体か・本文の約束と一致するか）で、きれいさ・静かさでは決めない（2026-10-18、オーナー「コピーライティング第一」）。

強さの印は `structure.md` の冒頭と同じ。根拠の全体は `analysis.md`。末尾の「→ 8-3」などは `analysis.md` の節の番号。

---

## 1. 先に知っておくこと

- **題の効果（どの型が売れるか・押されるか）を確かめた材料はない**。見出しの研究（数字・問い・好奇心・長さとクリック率）と、PASONA などのコピーの型は、この調査では調べていない【未調査】。「研究では〜」と書かない。記憶で埋めない（→ 8-7）
- 下の 3 の型は、note の哲学の有料記事・会員記事などの題 42本を数えて「よく使われていた」というだけ。42本には無料の記事・note の外の記事が数本入っている。どの題も売れた数は見えていない【実例・未確認】（→ 8-4・8-5）
- 短い概念語・日常の言葉の題（6〜18字）は、本・大学で note の外に読者がいる書き手2人の、メンバーシップ・定期購読マガジンの記事の題だった【実例・未確認】。外の読者が少ないうちは、題だけで「誰の・何の話か」が分かる長さにする（→ 8-3）
- 字数は、かぎかっこ・記号・半角も1字として数える（数え方をそろえないと、比べられない。note のヘルプの例も、かぎかっこを数えるかどうかで5字にも7字にもなる）（→ 1-4・8-1）
- **題を作るのは、有料部分の中心の照合が済んだあと**（`SKILL.md` の手順2の関門）。章の番号・引用を題に入れるのは、照らしたものだけ

## 2. 決まり

1. **題は、主題の言葉と、止まる言葉の両方**。主題の言葉＝哲学者名・書名・悩みの言葉（悩みの言葉も主題の言葉に数える）。止まる言葉＝読んでいる一人が「自分のことだ」と思う場面か、常識の反対か、意外な一言。いちばん強い一文が題に入らなければ、本文の1行目か見出し画像に置く（画像との役割は `thumbnail.md` の 2 の 5）。選ぶ順は 止まるか → 具体か → 本文の約束と一致するか。【決まり】content-quality 0、CLAUDE.md「見出し・1行目は『読む人が止まるか』でだけ決める」（→ 8-7）
2. **長さ**：15〜25字を目安にする（note のヘルプの目安。長いと一覧や X で後ろが「…」になる、という説明【公式・未確認】。X の部分は、X がリンクカードから題を外す前の説明かもしれない）。上限は全角32字前後（note-titler の決まり【決まり】）。ムートンの下書きの題は 26〜34字だった（`note/good-habits/03-titles.md` の34字、`note/cannot-decide/03-titles.md` の33字。未公開で反応のデータはない）（→ 8-1・8-2・8-8）
3. **止まるかを先に見る。前の15字は、止まる力が同じくらいのときの決め手**。25字を超えるときは、主題の言葉（悩みの言葉を含む）を前の15字に入れると、後ろが切れても何の話かが残る。26字以上の題21本のうち17本が、前の15字に主題の言葉を置いていた【実例・未確認（数え直し済み）】。ただし、前に置く言葉が止まらない言葉（書名と章の番号だけ、など）なら、止まる言葉を前にした案を取る（→ 8-3）
4. **何の記事か、と検索される言葉を入れる**（note のヘルプ【公式・未確認】）。哲学なら哲学者名・書名。固有名詞の入った題は42本中21本【実例・未確認】。1年以上たった記事は検索から読まれることが多い、という note 社の調査もある【報道・未確認】ので、流行り言葉より、何年たっても検索される言葉。**書名は、いま手に入る邦訳の題を使うか、並べて書く**（例：『提要』は、岩波文庫の國方栄二訳では『要録』の題：`src/articles/stoicism.html` の参考文献 1）。題に入りきらなければ、無料部分の早いところで並べる（→ 8-1・8-5・2-8）
5. **具体は、場面・年・本の章・事実の数字で**。note のヘルプの例は「先生の言葉」→「卒業式で先生が最後に伝えたかったこと」【公式・未確認】。手順の数（「5つの手順」）は使わない【決まり】安易に与えない（→ 8-1・8-8）
6. **題で約束しない**。「挫折なしに」「未来が変わる」「〇分で読める（分かる・身につく）」（どれも実例の題にあった。反応は見えていない【実例・未確認】）や「〜できるようになる」は書かない。根拠のない効果の保証は不当表示になりうる【公式・未確認】。【決まり】BRAND.md。測った読む時間を事実として書くのは、題ではなく無料部分の目次で（`structure.md` の 3 の ⑩）（→ 8-5・11-2）
7. **有料部分の中身と一致させる**。題で引いたことを無料部分で回収し始め、有料部分で書く。有料部分にないことを題に入れない。**有料記事では、答えを伏せる題（「〜の理由」「〜の正体」）は使わない**（答えが有料部分にあると、題で気を引いて払わせる形になる）。使うなら、答えの入口を無料部分に置くときだけ。【決まり】content-quality 0-5（→ 11-2「題・画像と本文がずれる」）
8. **使わない言葉**：命令形、あおり、強い語（「発狂」「邪悪」「炎上」）、最上級（「最高」「No.1」「唯一の」）、限定・期限・値段、「！」「✨」。【決まり】BRAND.md、`style.md` の 5（→ 11-2）
9. **「有料」の札は題に付けない**。有料であることは、無料部分の目次の前の一文と、X のリンクの行で伝える（`funnel.md` の 6）（→ 11-2「有料であること・広告を隠す」）
10. **サイトの記事の題と同じにしない**。並んだときに区別がつくようにする（同じ題だと、無料の記事と有料の記事を取り違える）
11. **哲学者の言葉の扱い**：弟子の筆記で言葉が残った人（エピクテトス・ソクラテスなど）に「書いた」と書かない（`style.md` の 4）。題・説明に「原典から読む」と書くのは、原典の版と照らしたときだけ
12. **区切りのダッシュは「——」**（`style.md` の 2 の 9）

## 3. 型（よく使われていたもの。効果は分からない）

数は `analysis.md` 8-5（42本。1本に複数の型あり。分類は調査担当の判断）。

| 型 | 42本中の数 | ムートンでの使い方（〔〕は形の見本で、実在の題ではない） |
|---|---|---|
| 固有名詞（哲学者名・書名・学派） | 21 | ほぼ毎回入れる（2 の 4） |
| 区切り（——・～）で「主題＋ひとこと」 | 12 | 〔哲学者〕の〔一節〕——〔ひとこと〕。ひとことは、本文の問いと同じ向き。区切りの前が書名と番号だけだと止まりにくい（2 の 3） |
| 方法・入門・解説・まとめ | 11 | 「方法」は中身が方法のときだけ。ムートンは手順を渡さないので、たいてい使わない。「読む」「読み直す」はよい |
| 連番・前後編 | 8 | 連載のとき。【シリーズ名】は前の字数を使うので短く |
| 読む人・場面 | 8 | 〔転職サイトを開いては閉じる夜に〕のような場面・悩みの言葉。読む人を「〜な人」と決めつけない |
| 言い換え（AはBである、AよりB） | 7 | 常識の反対の一文になりやすい。言い換えが本文の読み方と一致すること |
| 数字（年・時間・冊数など） | 6 | 事実の数字だけ（年・日記の日付・照らした章） |
| 理由・正体（答えを伏せる） | 4 | 有料記事では使わない（2 の 7） |
| 強い語 | 4 | 使わない |
| 経験の形（〜してみた・読んで思ったこと） | 3 | ムートンの記録が有料部分にあり、本当に試したときだけ（例：`note/cannot-decide` の「決められない夜に、『もっと調べる』をやめてみた。キルケゴールの一行」33字） |
| 問いの形 | 3（どれもテーマを問う形） | 問いだけでは何の話か分からないので、主題の言葉を必ず入れる |
| 読者への約束 | 3 | 使わない（2 の 6） |

実例の題そのもの（URL つき）は `analysis.md` 8-4。題を引用して使うときは、note のページで日本語の題を確かめてから（英語の訳題しか見えていない記事がある）。

## 4. 記事の説明

- note に記事ごとの説明の欄があるかは、確かめられていない【未調査】（→ 8-6）。欄があればそこに入れる。なくても、無料部分の最初の1〜2文が説明の役をする（検索結果の説明は主にページの本文から作られる、という Google の説明【公式・未確認】）
- 形：1文目＝止まる一文（題を繰り返さない）、2文目＝この記事で何を読むかと、有料部分に何があるか。80〜120字（サイトの description と同じ目安【決まり】CLAUDE.md）
- 値段・約束・あおりを書かない。有料部分にないことを書かない。有料部分の結論・読み方を書かない（目次の言葉まで）

## 5. 03-titles.md に書くこと

`03-titles.md` はコミットしてよいファイル。使ってよいのは、無料部分の言葉と、目次の見出しの言葉まで。有料部分の引用・読み方・結論は書かない。

1. 題の案 8〜10個の表：題・型・字数・止まる言葉と位置・主題の言葉（哲学者名・書名）の位置・悩みの言葉の位置
2. 推す案と理由（コピー第一の順：止まるか → 具体か → 約束と一致するか → 長さ）、次点、採らなかった案と理由
3. 最終案（字数）。短くするときの案（25字以内）
4. 記事の説明（字数）
5. ハッシュタグ（`hashtags.md` の 3 の形）
6. 見出し画像の文言 3案と、推す案の `thumb.json`（`thumbnail.md` の 3 の形）
7. 題・説明・画像に使わなかった材料と理由（誤読されやすい数字、脅しに見える語など）
8. 品質チェック担当への申し送り

## 6. 点検（題・記事の説明・画像の文言に当てる）

- [ ] 一覧で一度読んで、止まるか。誰の・何の話か分かる
- [ ] 25字を超えるなら、主題の言葉（悩みの言葉を含む）が前の15字にある。全角32字前後まで
- [ ] 書名は、いま手に入る邦訳の題か、並べて書いた（無料部分でもよい）
- [ ] 本文・有料部分の中身と一致し、有料部分にないことを約束していない。答えを伏せる題ではない
- [ ] 有料部分の引用・読み方・結論を出していない
- [ ] 命令・断定・結果の約束・あおり・最上級・強い語・限定・期限・値段・「！」がない
- [ ] 健康の話で「治る」「効く」に読めない
- [ ] サイトの記事の題と区別がつく
- [ ] 題（主題の言葉＋止まる言葉）と画像の文言（止める一行）が、同じ文の繰り返しになっていない（`thumbnail.md` の 2 の 5）
- [ ] 弟子の筆記で残った人に「書いた」と書いていない。照らしていないのに「原典から」と書いていない
