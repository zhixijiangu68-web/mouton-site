# 公開前の点検表

品質チェック（手順6）で使う。点検の順番は **コピー → 事実と出典 → 引用 → 言い方 → 有料記事の正直さ → 告知 → 見た目**（`BRAND.md`「コピーライティング第一」の点検の順番に、有料記事の項目を足した）。見た目の指摘は、言葉を弱める理由にしない。題・無料部分・見出し画像・ハッシュタグ・X の告知文のすべてに同じ基準を当てる（`analysis.md` 11-2 の末尾）。見出しの「→ 11-2」などは `analysis.md` の節の番号。

`<slug>` は記事の slug に置き換える。コマンドはリポジトリの直下で、bash で実行する。grep の言葉は、`[０-９]` のような全角の範囲を使わず「|」で並べている（ロケールが POSIX のシェルでも、UTF-8 のシェルでも同じに動くように）。

**字数**（無料部分・有料部分・合計と、有料部分の読む時間。数え方は `structure.md` の 1）

```bash
node -e '
const t = require("fs").readFileSync(process.argv[1], "utf8");
const parts = t.split(/^.*【有料ライン】.*$/m);
const count = s => {
  let skip = false, text = "";
  for (const l of s.split("\n")) {
    if (/^#{1,3}\s/.test(l)) skip = /^#{1,3}\s*参考文献/.test(l);
    if (skip || /^# /.test(l)) continue;
    text += l.replace(/^#{2,3}\s+|^>\s?|^\s*(?:[-*]|\d+\.)\s+/g, "")
             .replace(/\[([^\]]*)\]\([^)]*\)/g, "$1")
             .replace(/\*\*/g, "").replace(/https?:\/\/\S+/g, "")
             .replace(/【(?:本人が書く|要確認)[：:][^】]*】/g, "");
  }
  return [...text.replace(/\s/g, "")].length;
};
const free = count(parts[0]), paid = parts[1] ? count(parts[1]) : 0;
console.log(`有料ライン ${parts.length - 1} 行／無料 ${free}字／有料 ${paid}字（読む時間の目安 ${Math.ceil(paid / 500)}分）／合計 ${free + paid}字`);
' note/<slug>/paid/article.md
```
