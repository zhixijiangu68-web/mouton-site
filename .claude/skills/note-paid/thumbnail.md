# 見出し画像（サムネイル）

見出し画像は、note の一覧と X のカードで、題より先に目に入る。画像の言葉は「止める一行」にする。何の記事か（主題の言葉）は、一覧では画像と並ぶ題が、X ではリプライの文（題を入れる）が補う。作り方は自作だけ（`scripts/note-thumb`。文字と色だけで描く）。

強さの印は `structure.md` の冒頭と同じ。根拠の全体は `analysis.md`（とくに 10）。末尾の「→ 10-5」などは `analysis.md` の節の番号。

---

## 1. 先に知っておくこと

- **売れている・反応の多い記事の見出し画像の傾向は、1件も確かめられていない**（検索で画像が見えず、note のページも開けなかった）【未調査】。「顔を入れると」「文字を入れると」何%、のような話は書かない。YouTube のサムネイルなどの研究も調べていない【未調査】。埋める手順は `analysis.md` 12-8（オーナーの画面の写しで、傾向は記録できる）（→ 10-4）
- note のヘルプは「見出し画像の有無で、PV やスキ数に数十パーセントの差」「見出し画像のある記事は読まれやすい傾向」と書いている【公式・未確認】。比べているのは「ある・ない」で、どんな画像が効くかは分からない（→ 10-3）
- 推奨の大きさは 1280×670px（約 1.91:1。16:9 ではない【計算】）。推奨と違うと切られ、ブラウザとアプリで見え方が違う【公式・未確認】。別のヘルプは「2:1 がおすすめ」【公式・未確認】。一覧・アプリで何 px に縮み、どこが切れるかは書かれていない【未調査】（→ 10-1）
- 2025-11-04 から、見出し画像のない記事は本文1枚目の画像が自動でサムネイルになるが、SNS でシェアしたときの画像には使われない【公式・未確認】（→ 10-2）
- X のリンクカードには題が出ないことがある（2023-10 に題が外されたという報道と、2024-01 にウェブで戻ったという報道がある。そのあとと 2026年の見え方は分からない）【報道・未確認】。だから X の告知では、リプライの文に題を入れる（`SKILL.md` の手順7）（→ 10-2）
- note の一覧（タイムライン・検索）で、見出し画像と題がどう並ぶかは、この調査では確かめていない【未調査】。オーナーが公開のあとに見る（下の 4）
- X は画像を覚えていて、差し替えてもすぐには変わらない【公式・未確認】（→ 10-2）

## 2. 決まり

1. **毎回付ける**。仕様が違っていても損がない（付けなければ、X で画像が出ないかもしれない）【公式・未確認】（→ 10-8 の 1）
2. **1280×670 で作り、言葉は真ん中に寄せる**。`scripts/note-thumb` は、文字をすべて上下 52px・左右 120px の枠の中に入れ、見出しとサブを真ん中に置く。この枠で守れるのは、中央を残して **2:1 と 16:9 に切られたときだけ**。3:2・4:3・正方形に中央で切られると、横に長い見出しの端は欠ける【計算・切り方は仮定】（note がそう切るかは未確認）。だから作るたびに、出力の「中央で切ったとき」と `--preview` の見本で、どこまで残るかを見る。正方形でも残したいなら1行の幅を 670px より狭くする（見出し 103px なら1行6字まで、120px なら5字まで。字が少ないと make.mjs は字を大きくするので、出力で確かめる）。欠けるのを受け入れるなら、その理由（例：止まる一行を守るため）を `paid/04-review.md` に書く（→ 10-5・10-8 の 2〜3）
3. **止める一行を先に**。画像の見出しは、読んでいる一人が止まる一行（問い・場面・事実の数字・常識の反対）。主題の言葉（哲学者名・書名）は、題（一覧で画像と並ぶ）とリプライの文（X）で補えるなら、画像に入れなくてよい。入れるなら、止まる力を弱めない形で（見出しに入るならそこへ。サブ（最大 44px）は幅 160px で約 5.5px になり読めないので、幅 343px 以上で読めればよい言葉だけを置く）。【決まり】CLAUDE.md「見出し・1行目は『読む人が止まるか』でだけ決める」（→ 10-2・10-8 の 4）
4. **見出しは 10〜15字・2行・文節で改行・103px 以上**。【決まり】note-titler（10〜15文字）。一覧の小さな表示でも読める大きさから逆算した目安：1280 幅の画像が幅 160px で出ると文字は 1/8 になり、12.8px（サイトの本文の下限 0.8rem）で見せるには 103px 以上要る【計算・表示幅は仮定】（→ 10-5）。`scripts/note-thumb` は見出しを 64〜148px に収め、103px 未満なら「注意」を出し、64px で入らなければ画像を作らずに止まる（→ 10-5・10-8 の 5）
5. **題と画像で役割を分ける**。題は「主題の言葉＋止まる言葉」（`titles.md` の 2 の 1）、画像は「止める一行」。同じ文を繰り返さない。ムートンの下書きは「画像が問い、題が答え」の組み合わせを試している（`note/good-habits/03-titles.md`「毎日の朝食は「良い習慣」か」13字。未公開で反応のデータはない）（→ 10-6・10-8 の 6）
6. **画像の言葉にも、題と同じ決まり**：命令・約束・あおり・最上級・強い語を書かない。**値段・期限・割引・「残り○部」・「有料」も入れない**（値段は変わり、X は古い画像を覚えている【公式・未確認】。偽りの限定・根拠のない No.1 は不当表示になる、という note の説明【公式・未確認】）。小さな画像では文脈が抜けるので、脅しに見える語（「死亡」など）を入れない（`note/good-habits/03-titles.md` の判断）。**有料部分の引用・読み方・結論も入れない**（無料部分の言葉と目次の言葉まで）（→ 10-8 の 9〜11・11-2）
7. **内容に合った画像だけ**。釣りの言葉にしない（無関係な画像で PV を稼ぐのはすすめない、という note の考え方【公式・未確認】）。哲学者のたとえを縮めて画像にするときは、縮めたことで意味がずれていないか（例：「どれだけ食べたかを見せない」を「草を見せない」と縮めると、量の話が抜ける）を見る（→ 10-3）
8. **色は紙・墨・藍**（`variant` の paper・ink・ai。`renewal.css` と同じ色）。朱（#C8361B）は判定の「×」だけの色なので使わない【決まり】CLAUDE.md。連載は同じ `variant`・同じ `label` にそろえる（連載は統一感を、という note の考え方【公式・未確認】）。一覧で文字が読めない大きさでも、色と形でムートンの記事だと分かる（→ 10-6・10-8 の 8）
9. **権利の確かな画像だけ**：自分で作った画像（`scripts/note-thumb`）。他人の写真・イラスト・本の表紙・ロゴ・肖像を使わない。翻訳書の文をそのまま載せない（現代の翻訳には訳者の権利がある【一般的な注意・法令は未確認】）。哲学者の言葉を載せるなら、照らした本文から自分で訳した短い句だけにし（照らしていない句は載せない。`SKILL.md` の手順2）、出典は本文に書く。みんなのフォトギャラリー・写真素材・AI の画像の利用条件は確かめていない【未調査】ので使わない（→ 10-7）
10. **健康の記事**：「治る」「効く」に見える言葉、前と後を比べる見せ方を使わない。【決まり】CLAUDE.md「文章のルール」（→ 11-2）

## 3. thumb.json と作り方

部長が、03-titles.md で推した文言から `note/<slug>/thumb.json` を書く。

```json
{
  "title": "〔見出し 1行目〕\n〔2行目〕",
  "sub": "〔小さな一行。なくてよい〕",
  "label": "哲学",
  "variant": "paper"
}
```

| 項目 | 中身 | 決まり |
|---|---|---|
| `title` | 大きな文言。`\n` で改行 | 10〜15字・2行。文節で切る。止める一行（2 の 3・5） |
| `sub` | 小さな一行（2行まで）。なくてよい | 幅 343px 以上で読めればよい言葉（主題の言葉など）。値段・期限は入れない |
| `label` | 上の小さな札（1行）。なくてよい | 分野か連載の名前を短く（例：「哲学」）。「有料」「新作」は入れない |
| `variant` | `paper`（紙の地・墨の字。既定）／`ink`（墨の地）／`ai`（藍の地） | 迷ったら `paper`（サイトと同じ紙・墨）。連載では変えない |

作る（リポジトリの直下で。初回だけ `(cd scripts/note-thumb && npm ci)`：書体 Noto Sans JP と Playwright が `package-lock.json` の版で入る）：

```bash
node scripts/note-thumb/make.mjs note/<slug>/thumb.json --preview
```

→ `note/<slug>/thumbnail.png`（1280×670）ができる。Chromium が見つからないときは、表示される案内に従う（`CHROME_PATH` か `npx playwright install chromium`）。`node scripts/note-thumb/make.mjs --help` で使い方が出る。

- 出力の「見出し ◯px・◯行」「縮んだときの大きさ」「中央で切ったとき」「注意」を読む。見出しが 103px 未満、3行以上、「注意」が出たら、文言を短くするか `\n` の位置を変えて作り直す。「止めました」と出たら画像はできていない（文言が長すぎる）
- 「中央で切ったとき」は、2:1・16:9・3:2・4:3・正方形に中央を残して切られたときに、見出しとサブがすべて残るか（○）、端が欠けるか（×）。2:1・16:9 が × なら作り直す。3:2 から先は 2 の 2
- `--preview` の見本（上の段：幅 343・160・100px に縮めた見え方、下の段：中央で切った見え方）は、OS の一時フォルダ（`<一時フォルダ>/note-thumb/<slug>-thumbnail-preview.png`）にでき、場所が出力に出る。リポジトリには残らないので、消さなくてよい。Read で開いて、どの幅で読めるかと、どこが欠けるかを見る
- `thumbnail.png` も Read で開いて目で見る（文字の切れ・改行の位置・色）
- 文言を変えたら、03-titles.md と thumb.json の両方を直してから作り直す
