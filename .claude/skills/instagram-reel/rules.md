# 運用ルール（art.gagaga）

このファイルは、ユーザーから聞いた条件をまとめた「ルール」です。条件が変わったら、ここを書き換えれば全担当に反映されます。
最終更新：2026-10-06

## アカウントと目的

- アカウント：Instagram `@art.gagaga`（表示名 bee）。2026-10-06 時点で投稿0・フォロワー0
- 発信内容：ムートンのサイト（https://… ※独自ドメイン決定後に記入）の記事の内容
- 目的（優先順）
  1. ムートンのサイトへの訪問を増やす
  2. 需要を満たして、初収益を上げる（サイトのアフィリエイト・メールマガジン・広告へつなげる）
- 届けたい感情：**モチベーションを掻き立てる**（見た人のやる気に火をつける）

## 参考にする型（2026-10-02 にユーザーが共有したリール）

- 黒背景、白い線で描いた横顔の頭。頭の中に白い楕円の「心の窓」があり、そこに鉛筆画と短い言葉が次々に切り替わる
- 流れ：落ち込みの連続（Depressed / Hated / Alone / Tired）→ 転換（DISCIPLINE / ~~PROVE~~ IMPROVE）→ 決意（It's you vs you）
- 長さ15〜20秒。顔出しなし、ナレーションなし、1画面の言葉は1〜3語、BGMのみ
- 「型」だけを参考にする。参考リールの絵・素材・文言の引き写しはしない

## 形式

- リール（縦 1080×1920、15〜20秒、30fps）。最初の1秒で止める（フック）
- 顔出しなし
- 声：基本は字幕のみ＋BGM。語りが合うテーマのときだけ AI 音声（CapCut などの読み上げ機能で人が入れる）
- 字幕・画面の言葉は日本語。1画面12字以内、明朝体、白黒
- 絵：鉛筆・線画のタッチ（アイコンの手描きの目と統一）。自前で用意する（手描き、コードでの描画、または権利の確かな生成画像）
- 最後の画面とキャプションで、プロフィールのリンクから記事へ案内する
- プロフィールのリンクはサイトの `links.html`（リールで紹介した記事・最近の記事・テーマの入口）。ドメインが決まったら `https://<ドメイン>/links.html?utm_source=instagram&utm_medium=social` を設定し、サイトへの流入を GA4 で数えられるようにする

## 題材

- ムートンの記事が元ネタ。特に「哲学・生き方」（恐怖、セルフイメージ、自由、システム、ゴギンズなど）
- 1本のリールは、記事の「問い → 落ち込み → 気づき → 決意」を圧縮したもの
- 記事に書いていないことは言わない（リールで新しい主張を作らない）

## 使ってはいけない表現・企画のNG

1. 健康効果を言い切る表現（「治る」「〇〇だけで痩せる」など。薬機法）
2. 自傷・自殺を連想させる具体的な描写や言葉（落ち込みの気持ちの表現はOK）
3. 実在の人物の写真・他人の作品・参考リールの素材の無断使用
4. 出典のない数字（「9割の人が〜」は記事に出典があるときだけ）
5. 政治・宗教・特定の人への批判
6. 根拠のない成功の断言（「努力すれば誰でも成功する」など）
7. 休むことを否定する表現（サイトの「何もしない時間は無駄なのか」と矛盾するため）
8. 広告・アフィリエイトを含む投稿で「PR」表示を省くこと（ステマ規制）

## 毎週確認する指標（優先順）

1. プロフィールのリンクのクリック数（最重要）
2. 保存数・シェア数
3. フォロワー増加数
4. リールの視聴維持率（最後まで見られた割合）
5. サイト側：Instagram 経由の訪問数、アフィリエイトのクリック数（アクセス解析の導入後）

数字の目標は未設定。ユーザーから届いたらここに書く。

## 人の承認が必要なこと

- 企画（テーマ）の決定：週の企画案をユーザーが選ぶ
- 完成した動画の公開：投稿はユーザーが Instagram アプリで行う（AI社員は投稿しない）
- 新しい表現ルールや、アカウントの見た目（名前・アイコン・プロフィール）の変更

## AI社員にできないこと（人がやる）

- Instagram への投稿・予約投稿（アプリから人が行う。将来 Instagram Graph API を使う場合は別途設定）
- インサイト（数値）の取得：ユーザーがスクリーンショットか CSV を渡す
- BGM の選択・追加（Instagram アプリ内の音源を使う。権利のため動画には入れない）
- AI 音声の追加（CapCut などで人が入れる）
