## 2026-10-28 の決まり：X は集客口、指針を渡す（下の 2026-10-18 の決まりより優先）

- **役割**（2026-10-28、オーナー「xは集客口であり、顧客に生きる指針を与える場所にする」「ただ哲学を書けばいいというものでもない」）：X はフォロワーを集め、サイトの決定版の記事へ連れていく入口。投稿は、読んだ人がその日の行動に使える**指針**を渡す
- **締め**：指針（「〜しろ」「〜でいい」）か、認識を変える一言の言い切りで終える。**問いで終わるのは必須ではない**（2026-10-18 の「答えを出さず、問いで終わる」を置き換える）。根拠：伸びた投稿26件の締めは、指針11・言い切り10・本当の問い0（`promo/x-research/2026-10-28-buzz.md`）
- **命令・あおりは使ってよい**（2026-10-28、オーナー「命令・あおりは必要だと思う。受け取る側の問題だよ」）。使わないのは、炎上と信頼の損失につながる次のものだけ：出典のない数字、「〜するだけで」の誇張、結果の約束（「人生が変わる」「必ず」）、見下し・病気や属性をからかう言葉、嘘の緊急性（「今買わないと損」）。`scripts/x-check.mjs` がこれを見る。サイト・note の言い方（BRAND.md）は、オーナーが決めるまで変えない
- **型**（実例31件から。重なりあり）：①逆説「AではなくBだった」②対象を名指しして救う（「三日坊主の自分を責めるな」）③○×のリストで指針を渡す ④立場の前置き（「出典まで遡って調べる者として」）⑤短く言い切る
- **指針の中身**：サイトの記事の判定表（○ 支持・× 否定・△ 弱い）から取る。数字は判定表の根拠にあるものだけ。記事が「議論が続く」「観察研究」と書いているものは、その一言を残す。哲学は名前を出さず自分の言葉で（下の「哲学の呟き」）
- **仕組み**（X の公開コード、2026-10-28 に確認。`promo/x-research/2026-10-28-funnel.md`）：外部リンクに固定の減点は見当たらないが、リンクつきの投稿はもともと反応が少ない。知識の投稿は140字で読み切れる形にし、リンクはリプ欄か、週に数本の要約投稿の本文に置く。同じ作者の2本目以降は点数が下がるので、1日3本は時間を空ける。フォロワー5万以下・投稿から2時間以内・表示200回未満の元投稿には、新しい作者の枠がある。フォローしていない人へのリプライは For You に出にくい
- **見る数字**：プロフィールの閲覧 → サイトへの流入（`x / social`）→ 記事を最後まで読んだ人。フォロワー数は最後
- **プロフィールと固定ポスト**：`promo/x-profile.md` の 2026-10-28 版（差し替えはオーナー）

## 2026-10-18 の決まり（10/8 の記述より優先）

- **コピー第一**（2026-10-18、オーナー「全てコピーライティングを第一優先に。美しさなんて二の次。完全な両立は不可能」）：1行目は「読む人が止まるか」だけで決める。いちばん強い一文（自分のことだと思う場面・常識の反対・意外な数字）を1行目に置き、まだ何も起きていない場面（「朝、いつもの電車に乗って、いつもの席に着く」）で始めない。最後の一文は、記事を開く理由か、問い。きれいな言い回しと伝わる言い回しが同時に手に入らないときは、伝わるほう。余韻のための改行・詩的な一文・雰囲気のための一文は削る。点検は コピー → 事実 → 言い方 → 字数と utm の順（`docs/content-quality.md` の 0）
- **流れ**：X → 無料の入門記事・3つの姿勢の記事・ムートンについて → （販売が始まったら）悩みから選ぶ有料の3本。「選び方 → Amazon・楽天」は終わり
- **材料**：残す記事（`src/_data/currentArticles.js`）と「ムートンについて」（start.html）だけ。投稿の事実・数字・哲学者の言葉は、その記事に出典つきで書いてあるものだけ使う。アーカイブの記事からは作らない
- **枠**：1日3本はそのまま。**朝＝悩みの場面から入って入門記事へ**（キルケゴール・ニーチェ・スピノザ）、**昼＝哲学者の言葉（出典つき）から連載へ**（ストア派・カミュ・サルトルも）、**夜＝3つの姿勢・ムートンが試していること・問いで終わる**。順番表の「種類」欄は 入門／連載／姿勢／案内
- **型**：○×クイズ・投票・穴埋め・「今日やること」・手順の箇条書きは使わない（2026-10-17、オーナー）。1行目で止めるのは変わらないが、クイズではなく「場面」「常識の反対の一文」「意外な一文（研究の数字）」で始める。リプリンクが基本、本文リンクは1日1本まで（新しい記事の告知など）
- **X だけで回す。他の人の投稿へのリプライはやめる**（2026-10-18、オーナー）：ツイートを探す時間がないため、「毎日10件」の義務はなくす（下の 10/8 の節は休止）。Threads など別の場所にも広げない。まずは X の1日3本をルーティンにする。代わりに (1) 返信が来たものにだけ返す（Issue #230 に本文を貼れば ⑤ が返信案を書く）、(2) 夜の投稿に、翌朝「もうひとつの問い」を自分の投稿への返信として1行足す（文は X担当が「今日の3本」のコメントに入れる。答えではなく問い。リンクは付けない）。時間があるときだけ、テーマの近い20人の X のリストから2〜3件返してもよい（義務にしない）
- **答えを出さず、問いで終わる**（2026-10-18、オーナー。**2026-10-28 から上の「締め」に置き換え**。問いは使ってよいが必須ではない）：ツイートは短いので、結論や「だから僕は〜している」で締めない。読んだ人の思考を動かす問いで終える（答えは記事にある。ツイートはスパイス）。読者が身近に感じる場面・言葉で書き、暑苦しい自分語りはしない
- **言い方**：`docs/content-quality.md` の物差し。約束・見下しを使わない（命令・あおりは 2026-10-28 から X では使ってよい）。ムートンの経験と提案として書き、「あなたは〜だろうか」と問いで終わる投稿を夜に置く
- **有料のこと**：販売が始まるまで、値段・購入・PDF の案内は書かない。販売が始まったら、販売ページへの案内を順番表に足す（`utm_campaign=paid-<slug>`）
- **熱を**（2026-10-28、オーナー「xのツイートをもっと熱を」）：「と思う」「かもしれない」「気がする」を外し、ムートン自身のことは言い切る（「もう、やめた」「僕のものだ」）。1行目は断言、短い文で畳みかける。最後の問いも鋭く（「最初に言ったのは誰だ？」「本当に外見か？」）。熱は言い切りと短さから出す。見下し・誇張・結果の約束は使わない（命令・あおりは 2026-10-28 から使ってよい：上の「2026-10-28 の決まり」）
- **哲学の呟きは、名前を出さず自分の言葉で**（2026-10-28、オーナー「哲学者の名前を出したくない。自分の言葉で言いたい」）：哲学から考えを借りる投稿でも、本文に哲学者の名前・書名・用語を出さない。読者の場面とムートンの言葉に置き換え、元にした考えは `promo/x-posts.md` の「根拠」欄にだけ書く。引用（「」でくくった言葉）も使わない
- **長さ**（2026-10-22、オーナー「xがポストできるぎりぎりだ」）：本文は140字以内（URL を除く）のまま、ぎりぎりまで使う。目安は120〜140字。続きは note（2,000〜4,000字）とサイトの記事（決定版、本文1万〜2万字）にある
- **点検**：下書きは `node scripts/x-check.mjs promo/x-posts.md --section "<節の見出し>"` で字数・重み・utm・禁じている言い回しを確かめてから順番表に入れる
- **数字**：見る順は 実購入 → `paid_buy_click`（販売開始後）→ GA4 の `x / social`（campaign＝記事、content＝reply/body/pinned）→ 投稿ごとのリンクのクリック → フォロワー。`affiliate_click` と Amazon・楽天のレポートは見ない

## 投稿の決まり

- 1日3本（朝 7〜8時ごろ・昼 12〜13時ごろ・夜 21〜22時ごろが目安）。朝・夜は、10月は「選び方」記事が7割、その他の記事が3割。昼は哲学（`promo/x-posts.md` の「哲学投稿のフォーム」の5つの条件を満たしたものだけ）
- 順番は `promo/x-posts.md` の順番表に従う。差し替えるときは順番表も直す
- **ふだんはインプレッションを増やすため、有益な情報を発信する**。本文は、記事の要点（数字・見るところ・意外な事実）をリンクなしで読み切れる形にする
- 投稿の型（2026-10-07 から）
  - **リプリンク**（基本）：本文にリンクを入れず、自分の投稿へのリプライに1行でリンクを置く
  - **本文リンク**：本文の最後にリンクを入れる。**1日1本まで**。新しい選び方記事の告知などに使う
  - どちらの型かは、順番表の「メモ」欄に書く。インプレッションとリンクのクリック数を型ごとに比べる
- 本文は140字以内（URL を除く。2026-10-22 から、ぎりぎりまで使う：目安は120〜140字）。本文リンクにしても、X の重み付きの文字数（日本語1字＝2、URL＝23）で280以内
- リンクには必ず `?utm_source=x&utm_medium=social&utm_campaign=<記事のファイル名>&utm_content=<reply か body>` を付ける（リプライに置くなら `reply`、本文に入れるなら `body`）
- **1行目で止める**（つい読んでしまう投稿でないと見てもらえない）。1行目は次のどれか
  - ○×クイズ（例：「エキストラバージンは国が決めた上の等級。○か×か」）
  - 意外な数字（例：「プロテインを足して増える筋肉、平均約0.3kg」）
  - 常識の否定（例：「口臭の多くは、胃じゃない」）
  - 比較（例：「ホエイとソイ、筋肉が増えやすいのは？」）
- 答えは本文の最後か、翌朝の答え合わせで明かす（続きが気になる形）
- **投票クイズは週2本ほど**。X の投票機能を使い、選択肢（25字以内）と期間（1日）を決める。投票にはリンクを付けない。翌朝、投票を引用して答え合わせを投稿する（この投稿にリンクを付ける）
- 嘘・誇張・あおり（「〇〇な人は損してる」「知らないとヤバい」など）は使わない
- 同じ文面を2回使わない。同じ記事の案は3日以上あける（投票と翌朝の答え合わせは1組として数える）

## 文章のルール

- 日本語。一人称は「僕」
- 記事に書いていないことや数字は書かない。数字は元記事で照合してから使う
- 「効く」「治る」と言い切らない（研究の結果は「〜だった」「〜という結果」と書く）
- 商品や本を名指しで推す投稿には、先頭に「【PR】」を入れる（ステマ規制）
- 他人や他の発信者を批判しない。政治・宗教の話題に乗らない
- 話題のニュースに乗るときも、つなげる先はムートンの記事。記事がない話題には乗らない

## 毎日・毎週見る指標（優先順）

1. 売上：Amazon アソシエイト・楽天のレポートの注文（最重要。売れた日と記事を照らし合わせる）
2. GA4 の `affiliate_click` イベント（Amazon・楽天のリンクのクリック。`article` で記事、`shop` で店が分かる）
3. GA4 の X からの訪問：ソース / メディアが `x / social`、キャンペーンが記事のファイル名
4. X の投稿ごとの「リンクのクリック数」
5. X のインプレッション、リプライ数、ブックマーク数、フォロワー増加数

数字の目標は未設定。オーナーから届いたらここに書く。
