## 2026-10-18 の決まり（10/8 の記述より優先）

- **流れ**：X → 無料の入門記事・3つの姿勢の記事・ムートンについて → （販売が始まったら）悩みから選ぶ有料の3本。「選び方 → Amazon・楽天」は終わり
- **材料**：残す記事（`src/_data/currentArticles.js`）と「ムートンについて」（start.html）だけ。投稿の事実・数字・哲学者の言葉は、その記事に出典つきで書いてあるものだけ使う。アーカイブの記事からは作らない
- **枠**：1日3本はそのまま。**朝＝悩みの場面から入って入門記事へ**（キルケゴール・ニーチェ・スピノザ）、**昼＝哲学者の言葉（出典つき）から連載へ**（ストア派・カミュ・サルトルも）、**夜＝3つの姿勢・ムートンが試していること・問いで終わる**。順番表の「種類」欄は 入門／連載／姿勢／案内
- **型**：○×クイズ・投票・穴埋め・「今日やること」・手順の箇条書きは使わない（2026-10-17、オーナー）。1行目で止めるのは変わらないが、クイズではなく「場面」「常識の反対の一文」「意外な一文（研究の数字）」で始める。リプリンクが基本、本文リンクは1日1本まで（新しい記事の告知など）
- **答えを出さず、問いで終わる**（2026-10-18、オーナー）：ツイートは短いので、結論や「だから僕は〜している」で締めない。読んだ人の思考を動かす問いで終える（答えは記事にある。ツイートはスパイス）。読者が身近に感じる場面・言葉で書き、暑苦しい自分語りはしない
- **言い方**：`docs/content-quality.md` の物差し。命令・断定・約束・あおり・見下しを使わない。ムートンの経験と提案として書き、「あなたは〜だろうか」と問いで終わる投稿を夜に置く
- **有料のこと**：販売が始まるまで、値段・購入・PDF の案内は書かない。販売が始まったら、販売ページへの案内を順番表に足す（`utm_campaign=paid-<slug>`）
- **点検**：下書きは `node scripts/x-check.mjs promo/x-posts.md --section "<節の見出し>"` で字数・重み・utm・禁じている言い回しを確かめてから順番表に入れる
- **数字**：見る順は 実購入 → `paid_buy_click`（販売開始後）→ GA4 の `x / social`（campaign＝記事、content＝reply/body/pinned）→ 投稿ごとのリンクのクリック → フォロワー。`affiliate_click` と Amazon・楽天のレポートは見ない

## 投稿の決まり

- 1日3本（朝 7〜8時ごろ・昼 12〜13時ごろ・夜 21〜22時ごろが目安）。朝・夜は、10月は「選び方」記事が7割、その他の記事が3割。昼は哲学（`promo/x-posts.md` の「哲学投稿のフォーム」の5つの条件を満たしたものだけ）
- 順番は `promo/x-posts.md` の順番表に従う。差し替えるときは順番表も直す
- **ふだんはインプレッションを増やすため、有益な情報を発信する**。本文は、記事の要点（数字・見るところ・意外な事実）をリンクなしで読み切れる形にする
- 投稿の型（2026-10-07 から）
  - **リプリンク**（基本）：本文にリンクを入れず、自分の投稿へのリプライに1行でリンクを置く
  - **本文リンク**：本文の最後にリンクを入れる。**1日1本まで**。新しい選び方記事の告知などに使う
  - どちらの型かは、順番表の「メモ」欄に書く。インプレッションとリンクのクリック数を型ごとに比べる
- 本文は140字以内（URL を除く）。本文リンクにしても、X の重み付きの文字数（日本語1字＝2、URL＝23）で280以内
- リンクには必ず `?utm_source=x&utm_medium=social&utm_campaign=<記事のファイル名>&utm_content=<reply か body>` を付ける（リプライに置くなら `reply`、本文に入れるなら `body`）
- **1行目で止める**（つい読んでしまう投稿でないと見てもらえない）。1行目は次のどれか
  - ○×クイズ（例：「エキストラバージンは国が決めた上の等級。○か×か」）
  - 意外な数字（例：「プロテインを足して増える筋肉、平均約0.3kg」）
  - 常識の否定（例：「口臭の多くは、胃じゃない」）
  - 比較（例：「ホエイとソイ、筋肉が増えやすいのは？」）
- 答えは本文の最後か、翌朝の答え合わせで明かす（続きが気になる形）
- **投票クイズは週2本ほど**。X の投票機能を使い、選択肢（25字以内）と期間（1日）を決める。投票にはリンクを付けない。翌朝、投票を引用して答え合わせを投稿する（この投稿にリンクを付ける）
- 嘘・誇張・あおり（「〇〇な人は損してる」「知らないとヤバい」など）は使わない
- 同じ文面を2回使わない。同じ記事の案は3日以上あける（投票と翌朝の答え合わせは1組として数える）

## 他の人の投稿へのリプライ（2026-10-08 から）

- 毎日10件。オーナーが行う。型と使える一言は `promo/x-replies-out.md`
- 相手：テーマが重なる人（自己啓発、筋トレ、清潔感・メンズ美容、お金の考え方）。自分のフォロワー数の5〜20倍くらいの人を中心に、同じくらいの人を数件、大きい人を1〜2件
- 投稿されてすぐ（目安1時間以内）の投稿へ
- リンクは貼らない。相手を否定しない（「付け足す」言い方にする）。数字は記事で確かめたものだけ
- 根拠：`promo/x-research/2026-10-08.md`

## 文章のルール

- 日本語。一人称は「僕」
- 記事に書いていないことや数字は書かない。数字は元記事で照合してから使う
- 「効く」「治る」と言い切らない（研究の結果は「〜だった」「〜という結果」と書く）
- 商品や本を名指しで推す投稿には、先頭に「【PR】」を入れる（ステマ規制）
- 他人や他の発信者を批判しない。政治・宗教の話題に乗らない
- 話題のニュースに乗るときも、つなげる先はムートンの記事。記事がない話題には乗らない

## 毎日・毎週見る指標（優先順）

1. 売上：Amazon アソシエイト・楽天のレポートの注文（最重要。売れた日と記事を照らし合わせる）
2. GA4 の `affiliate_click` イベント（Amazon・楽天のリンクのクリック。`article` で記事、`shop` で店が分かる）
3. GA4 の X からの訪問：ソース / メディアが `x / social`、キャンペーンが記事のファイル名
4. X の投稿ごとの「リンクのクリック数」
5. X のインプレッション、リプライ数、ブックマーク数、フォロワー増加数

数字の目標は未設定。オーナーから届いたらここに書く。
