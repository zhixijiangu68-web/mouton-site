習慣を変えたいときに読む本。研究から選んだ6冊と、読むときの注意

約6分で読めます（目安）

PR｜この記事には広告（アフィリエイトリンク）が含まれます。詳しく

「今度こそ続ける」と決めて、三日で終わる。そんなとき、やる気を足すより先に、仕組みを知る本を開いてみる。

このサイトでは「システムのないゴールは、動かない」や「セルフイメージは、長期の行動を変える」で、習慣と自己像について書いてきた。その途中で読んだり、参照したりした本から、6冊を選んだ。

ただし、自己啓発の名著の中には、出版後の研究で「思ったより効果が小さい」と分かってきた考え方もある。この記事では、本の紹介と一緒に、その後の研究で分かった注意点も書いておく。

1. 小さな習慣を設計する

ジェームズ・クリアー / 牛原眞弓 訳 / パンローリング

『ジェームズ・クリアー式 複利で伸びる1つの習慣』は、習慣を「きっかけ・欲求・反応・報酬」の流れとして捉え、それぞれを小さく設計し直す本だ。目標より先に「どんな人間になりたいか」を決めるという考え方は、このサイトの「あなたはどんな人間になりたいですか？」とも重なる。

「いつ・どこで・何をするか」を先に決めておく方法は、心理学では実行意図として研究されていて、94の研究を集めた分析で、目標の達成に中程度から大きい効果が示されている [1]。

注意：習慣が自動化するまでの期間は人と行動によって大きく違い、研究では18日から254日まで幅があった [2]。「21日で身につく」のような数字は、目安にしないほうがいい。

2. 意志力の使い方を知る

ケリー・マクゴニガル / 神崎朗子 訳 / 大和書房

『スタンフォードの自分を変える教室』は、スタンフォード大学の講義をもとに、誘惑や先延ばしとの付き合い方を、実験の紹介と小さなワークで進めていく本。自分が誘惑に負ける場面を観察するところから始めるので、読みながら試しやすい。

注意：本の中では「意志力は使うと減る」という研究（自我消耗）が紹介されている。ただ、その後に23の研究室で行われた大規模な追試では、効果はほとんど確認されなかった [3]。「意志力は有限だから温存する」という考え方は、言い切らずに読みたい。

3. 長く続ける力を考える

アンジェラ・ダックワース / 神崎朗子 訳 / ダイヤモンド社

『やり抜く力 GRIT』は、長期的な目標への情熱と粘り強さを「グリット」と呼び、才能よりも続ける力が成果に関わると論じる本。興味を育て、意図的な練習を重ねるという流れは、「システムのないゴールは、動かない」の考え方とも近い。

注意：88の研究をまとめた分析では、グリットと成果の関係は中程度より弱く、性格の「誠実性」とかなり重なっていた [4]。グリットは成功を決める唯一の力ではなく、続ける工夫の一つとして読むのがいい。

4. 能力についての思い込みを見直す

キャロル・S・ドゥエック / 今西康子 訳 / 草思社

『マインドセット「やればできる!」の研究』は、能力は固定されていると考える「硬直マインドセット」と、伸ばせると考える「しなやかマインドセット」の違いを描く本。「自分は続かない人間だ」という決めつけを見直したいときに読みたい。

注意：学業成績との関係を調べた2つのメタ分析では、マインドセットと成績の関係も、マインドセットを変える介入の効果も、全体としては小さかった [5]。考え方を変えるだけでなく、行動を変えることと組み合わせて使いたい。

5. 習慣を脳の仕組みから知る

ラッセル・A・ポルドラック / 神谷之康 監訳・児島修 訳 / みすず書房

『習慣と脳の科学』は、習慣が生まれる仕組みを脳神経科学と心理学から説明し、行動を変えるための研究を紹介する本。すぐ使えるコツより、「なぜ変えるのが難しいのか」を知りたい人に向いている。詳しくはこの本をすすめる理由に書いた。

6. やめられない理由を知る

デイヴィッド・J・リンデン / 岩坂彰 訳 / 河出文庫

『快感回路』は、食べ物、お酒、ギャンブル、寄付まで、人が「気持ちいい」と感じる脳の仕組みを解き明かす本。やめたい習慣を、意志の弱さではなく仕組みから見直す入口になる。詳しくはこの本をすすめる理由に書いた。

本を読んだあとに

本を読むと、変わった気がする。でも、変わるのは行動を繰り返したあとだ。

読み終えたら、気になった方法を一つだけ選び、「いつ・どこで・何をするか」を書いて、今日1回だけやってみる。続かなかった日は、やめるのではなく、次の日に戻ればいい。
