生き方を考えたいときに読む本。哲学と心理学の古典4冊

約3分で読めます（目安）

記事を書いていると、短い文章では答えの出ない問いに何度もぶつかる。生きる意味はどこにあるのか。自由とは何か。他人の目から、どうすれば離れられるのか。

そういう問いを、もう少し深く考えたいときに開いてきた本から、4冊を選んだ。どれも答えをくれる本ではない。でも、考える足場をくれる。

1. 意味が与えられない世界で

フリードリヒ・ニーチェ / 丘沢静也 訳 / 光文社古典新訳文庫（上・下）

『ツァラトゥストラ』は、「神は死んだ」の後の世界で、人はどう生きるのかを、預言者ツァラトゥストラの語りとして描いた本。哲学書というより、詩や物語に近い。

このサイトの「神は死んだ。それでも、なぜ生きるのか。」で考えた問いを、ニーチェ自身がどう語ったのかに触れられる。最初から全部を理解しようとせず、引っかかった言葉に線を引きながら読むのがいいと思う。新しい訳は読みやすい。

2. どんな状況でも、意味は見つけられるのか

ヴィクトール・E・フランクル / 池田香代子 訳 / みすず書房

『夜と霧』は、精神科医のフランクルが、ナチスの強制収容所での体験を記録した本。極限の状況の中で、人が何によって生き延び、何によって崩れていったのかを、心理学者の目で書いている。

ニーチェが「意味は与えられない」と言ったのに対して、フランクルは、どんな状況でも人は意味を見いだしうると考えた。2冊を続けて読むと、問いの両側が見える。

3. 自由は、なぜ重たいのか

エーリッヒ・フロム / 日高六郎 訳 / 東京創元社

『自由からの逃走』は、人は自由を求める一方で、自由に伴う孤独や不安に耐えられず、自分から自由を手放してしまうことがある、と論じた本。1941年に書かれ、なぜ人々が権威に従ったのかを考えている。

「愛ではなく、自由を求める」で、僕は自由を「基準を自分の中に置くこと」と書いた。この本は、その自由がなぜ重たいのかを教えてくれる。

4. 他人の評価から、どう離れるか

岸見一郎・古賀史健 / ダイヤモンド社

『嫌われる勇気』は、心理学者アドラーの考え方を、哲学者と青年の対話の形で紹介した本。「課題の分離」という言い方で、他人がどう評価するかは自分の課題ではない、という整理を示している。

「嫌われることを『気にしなくなる』のではない。優先順位が下がるだけだ」では、この本の考え方を、心理学の研究と合わせて見直した。本を読む前でも後でも、あわせて読むと、言い切りすぎない読み方ができると思う。
