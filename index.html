公開日の新しい順。

  • HTTP は、前の要求を覚えていない。だから、Cookie を見せた相手を本人として扱う

    HTTP は一つの要求に一つの応答を返し、要求どうしを覚えていない。前の要求とのつながりは Cookie が運ぶので、Cookie の属性と HTTPS が守りの土台になる。アクセスログの一行から読めることと、SIEM で見る観点もまとめた。

    守る・約12分・2026年11月7日

  • 経路を乗っ取っても、本物の鍵がなければ本物にはなれない。TLS が守る三つのこと

    TLS は暗号化・完全性・相手の確認の三つを受け持つ。TLS 1.3 は鍵を決めてから証明書で相手を確かめ、証明書は名前と期限と取り消しまで見る。不正な発行は CT の公開の記録で見つけ、CAA で発行できる認証局をしぼる。

    守る・約12分・2026年11月7日

  • DNS の答えは、先に届いた偽物が勝つ。キャッシュポイズニングと、DNSSEC・DoH の役目の違い

    DNS は、届いた応答の正しさを確かめずに、条件の合う最初の応答を受け取る。2008年のキャッシュポイズニングの対策、署名で確かめる DNSSEC、通信路を暗号化する DoT・DoH はそれぞれ守るものが違う。持ち主の側の乗っ取りとログでの見つけ方もまとめた。

    守る・約12分・2026年11月7日

  • 経路が生きていても、名前が引けなければ通信は始まらない。DNS が example.com をアドレスに変える仕組み

    名前は右から読む木で、親のゾーンが子のゾーンの担当サーバーを示してつながる。リゾルバーはルート・TLD・権威サーバーの順にたどり、答えを TTL の間だけ覚える。頼む先のリゾルバーに届かなければ、経路が生きていても名前は引けない。

    守る・約12分・2026年11月7日

  • ファイアウォールは、通すものだけを書いて残りを止める。穴は、ルールの順番と範囲の書き違いから開く

    ファイアウォールは、アドレスとポートとプロトコルで通すか止めるかを決める。行きの通信を覚えて戻りだけを通す方式、上から読んで最初に合ったルールで決まる作り、既定で拒否、出ていく通信とログを、IP アドレスと TCP・UDP の記事の続きとしてまとめた。

    守る・約12分・2026年11月7日

  • 外から入れないのは、NAT が守っているからではない。変換の表と CGN とログの読み方

    家庭のルーターは、プライベートアドレスの機器の通信を、一つの外のアドレスとポート番号に書き換えて外へ出す。変換の表、タイムアウト、事業者の CGN、NAT がファイアウォールではない理由、ログで利用者をたどるのに要る情報を、IP アドレスの記事の続きとしてまとめた。

    守る・約12分・2026年11月7日

  • ICMP を全部止めると、大きな通信だけが止まる。エラーと診断の知らせの読み方

    ICMP は IP の失敗と診断の知らせ。Time Exceeded で途中のルーターが、Packet Too Big で経路の MTU が分かる。全部止めると Path MTU Discovery が壊れ、ping は通るのに大きな通信だけが止まる。

    守る・約12分・2026年11月7日

  • 開いているポートの数だけ、外からの入口がある。TCP と UDP とポートの読み方

    IP アドレスが機器を、ポート番号がその中のプログラムを指す。TCP は SYN・SYN-ACK・ACK で接続を作って順番と再送を受け持ち、UDP は接続を作らずに送る。開いているポートは入口になるので、不要なものは閉じ、スキャンと SYN フラッドの見え方を知っておく。

    守る・約12分・2026年11月7日

  • つないだ機器は、答えたサーバーを確かめずに設定を受け取る。DHCP の仕組みと、偽の DHCP サーバーの防ぎ方

    DHCP は四つのメッセージでアドレスと設定を貸し、期限の半分で延長を頼む。もらえなければ 169.254 の中から自分で決める。返事の送り主は確かめないので、偽のサーバーはスイッチで止め、リースの記録でアドレスと機器を結びつける。

    守る・約12分・2026年11月7日

  • ARP は、答えた相手を確かめない。同じネットワークの中で、通信が横取りされる仕組み

    宛先が自分の範囲の中なら相手の、外ならゲートウェイの MAC アドレスへ送る。その MAC アドレスを引く ARP は答えを確かめないので、同じネットワークの者が偽の答えで通信を横取りできる。見つけ方と防ぎ方までまとめた。

    守る・約12分・2026年11月7日

  • /24 と /16 の違いは、許す相手の数で256倍になる。IP アドレスとプレフィックスの読み方

    /24 は先頭24ビットが同じ256個の範囲。1ビット短くなるごとに範囲は倍になる。プライベートアドレスなどの特別な範囲と、許可リストやログでの読み違いを、ルーティングの記事の続きとしてまとめた。

    守る・約11分・2026年11月7日

  • ルーティングは、いちばん細かい経路を信じる。その決まりが、経路の乗っ取りに使われる

    ルーターは宛先ごとに次の行き先だけを決め、重なる経路ではいちばん細かいものを選ぶ。BGP は届いた申告を確かめずに使う設計だったため、乗っ取りと漏えいが起きてきた。RPKI は、申告した AS が正しいかを確かめる。

    守る・約11分・2026年11月6日

  • SIEM の検知ルールは、入れた日から調整が始まる

    同じ「失敗のあとの成功」でも、時間の幅は15秒から数分、失敗の数は8回から25回まで開いていた。ルールは、置かれる環境に合わせて調整する前提で作られている。

    守る・約11分・2026年11月4日

  • SIEM と XDR は、置き換わる関係ではない。まわりの道具と、ラボでの学び方

    似た名前の道具は、取って代わる関係より、ログを渡し合い、機能が重なる関係として説明されていた。SIEM は、無料の版と公開のデータで、自分のラボで学べる。

    守る・約11分・2026年11月4日

  • SIEM は攻撃を止めない。ログをつなげて、人に知らせる仕組みだ

    SIEM がするのは、集める・そろえる・つなげる・知らせる・残すまで。止めるのは SOAR などの別の仕組みと人。どのログを入れるかで、見えるものが決まる。

    守る・約12分・2026年11月4日
