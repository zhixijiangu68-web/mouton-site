## 運用ルール

実作業は GitHub Issues と PR に紐づけ、状態と次のアクションを明記する。

新しい資料を作成するときは、日付／状態（案・確認中・確定）／関連 Issue・PR／更新者または判断者を明記します。資料の存在だけで開発・公開・テスト完了とはみなしません。
