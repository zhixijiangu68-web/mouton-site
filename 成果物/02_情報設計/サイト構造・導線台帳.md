## 2. サイトのコンテンツ分類

[src/_data/topics.js](../../src/_data/topics.js) の4分類を編集上の正本とし、トップの3テーマとは区別する。

| 内部分類 | 表示名 | トップからの直接導線 |
| --- | --- | --- |
| philosophy | 哲学・生き方 | あり |
| body | 身体 | あり |
| work | 仕事・働き方 | トップの3カードにはない（別導線で案内） |
| food | 食事・化学 | あり |

記事の分類と公開URL・編集方針が一致しているかを新規記事の受け入れ条件にする。

## 3. 主要ユーザーフロー（テスト可能な形）

| ID | 開始点 | 操作 | 到達点 | 成功条件 |
| --- | --- | --- | --- | --- |
| UF-01 | 初回トップ | 3テーマのいずれかを選ぶ | 該当テーマの記事一覧 | 迷わず戻れて横スクロールがない |
| UF-02 | 記事一覧 | 検索／カテゴリー → 記事を開く | 記事本文 | 想定キーワードで適切な記事が出る |
| UF-03 | 入口／メニュー | 「はじめての方へ」→「制作」 | KIOKU・DIARY・MOUTON | 制作の現在地、詳細URLがわかる |
| UF-04 | 記事／商品導線 | LP → 無料Web／PDFサンプル | サンプル | 販売前であると明示し、サンプルが開く |
| UF-05 | 昔の共有リンク | index.html#journal に直接アクセス | journal.html | 既存の共有リンクの意図を保つ |
| UF-06 | 英語記事 | 言語の切替・関連記事を見る | 対応言語／記事 | 訳がない場合の行き先に破綻なし |

## 4. 各ページの情報優先度（提案）

### トップ
1. ブランドの雰囲気と3テーマの選択。
2. 記事を探す／はじめての方へ／英語の補助導線。
3. Day/Nightの選択。Reduced motionを尊重する。

### 記事ページ
1. 見出し・更新情報・何が分かるか。
2. 本文と根拠・一次資料。
3. 関連記事と制作・商品への控えめな導線。
4. PR・医療に関わる注記が必要な場合に目立つ表示。

### 商品LP
1. 誰の何を助けるか、商品仕様と価格。
2. 根拠・目次・サンプル。
3. 購入可能性の正確な表示（現在は発売準備中）。
4. 購入できるようになった場合の販売者表示・返金条件・納品方法。

## 6. 情報設計の監査項目

- [ ] トップから3テーマそれぞれに到達できる
- [ ] 仕事・働き方の記事もサイト内から見つかる
- [ ] 記事一覧で検索・絞り込みができる
- [ ] 既存のアンカー／ブックマークが致命的な404にならない
- [ ] 制作のステータスが projects.json の現状と一致する
- [ ] 商品が発売準備中でもサンプルは利用できる
- [ ] 英語版・問い合わせ・プライバシーへの導線が残る
- [ ] PCとiPhone幅で操作の支障がない
