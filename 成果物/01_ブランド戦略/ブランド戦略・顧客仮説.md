## 1. アイデンティティ

| 項目 | 現行方針 |
| --- | --- |
| 呼称 | ムートン／MOUTON |
| 中心の一文 | 作る。記録する。残していく。 |
| 約束 | 問い、学び、制作物とその過程を一か所に積み重ねる |
| 核となる価値 | 興味を持ったことを自分で確かめ、言葉と作品として保存する |
| 発信領域 | 哲学・生き方、身体、仕事・働き方、食事・化学、制作の記録 |
| 世界観 | わかりやすい入口と深い余韻の両立。余白・静けさ・映画的な印象 |
| 禁止事項 | 根拠のない効果保証、架空の実績／購入者の声、読者への不要な煽り |

MOUTONは「商品販売専用のブランド」ではなく、作品・文章・問いを含む個人のアーカイブ。短期的な収益は信頼の上に成り立つ。

## 2. 対象読者（仮説）

| ID | 読者の状況（検証前） | 求める価値 | 最初の接点 | 確認したい行動 |
| --- | --- | --- | --- | --- |
| SEG-A | 生活習慣・外見・清潔感を改善したい | 断定ではなく出典と実践手順 | 身体・食と科学、無料サンプル | サンプル閲覧、内容についての質問 |
| SEG-B | 生き方・哲学を考えたい | 問いを深められる文章 | 哲学記事、連載、読書案内 | 関連記事回遊、再訪 |
| SEG-C | 個人制作やアプリづくりに関心 | きれいな完成形だけでなく経緯 | 制作一覧、KIOKU、DIARY | 制作記録の閲覧、フィードバック |

- 生活改善層の年齢設定（20〜35歳前後）は既存要件の仮説にすぎず、訪問者を制限しない。
- SEG-A/B/Cは排他的ではない。実測やヒアリングで切り直す。
- ブランド指名検索は一般語「ムートン」だけだとノイズが多い。moutonarchive.com等も併用して判断する。

## 3. メッセージ構造

| 階層 | 伝える内容 | 使用場所 |
| --- | --- | --- |
| ブランド | 「作る。記録する。残していく。」 | 運営者紹介・制作記録・プロフィール |
| 読者への入口 | 「考える。」「身体で、確かめる。」「食べることを、科学で。」 | トップ3テーマ |
| 信頼の理由 | 体験と研究の距離を明示し、出典と限界を示す | 記事・無料サンプル |
| 制作の証拠 | KIOKU・DIARY・MOUTONの進捗、できる／できないこと | making.htmlと個別ページ |
| 商品 | 「清潔感の科学。」75ページ、税込2,980円、発売準備中 | LP。納品の準備が完了するまで購入受付不可 |

## 4. 表現・コピーの判断表

| 観点 | 採用する表現 | 避ける表現 |
| --- | --- | --- |
| 哲学 | 問いと複数の見方、作品や思想家の文脈 | 特定の主張を唯一の答えと断定 |
| 科学 | 対象・方法・結果・限界を並べる | 1研究から全員への効果を断言 |
| 制作 | 「試作中」「未実装」と現状を記す | 計画だけの機能を完成済みと表示 |
| 販売 | 価格・商品内容・決済の状態・条件を明記 | テスト用決済リンクで販売開始を装う |
| 広告 | PR表記と利害関係を視認できる形に | 広告を第三者の独立レビューに見せかける |

コピーの例（提案文・未承認）：
- トップ補助：興味を、確かめる。考えを、残す。
- 制作一覧補助：完成までの道のりも、作品の一部として。
- 科学記事の説明：数字と体験のあいだを、丁寧に読む。

## 5. タッチポイントの一貫性

| 場所 | 役割 | 最低限満たすべきこと |
| --- | --- | --- |
| トップ | 世界観と3テーマの選択 | コピー・視覚・導線が統一される |
| はじめての方へ | 誰が何を残すか説明 | ブランド説明と制作・記事へのリンク |
| 記事 | 読む価値を渡す | 出典、公開・更新情報、関連記事 |
| 制作 | 人となりと制作力を伝える | ステータスと次の一歩を偽らない |
| 商品LP | 商品と販売条件を伝える | 商品仕様・現状・法務情報と整合 |
| X・SNS | 記事への入口 | サムネ・紹介文・遷移先が一致 |

## 6. ブランド検証

1. 初見ユーザー5人程度に「何のサイトか」「どこを押すか」を尋ねる（人数は調査案）。
2. トップ→記事、記事→関連ページ、制作一覧→詳細の各導線を観察する。
3. ブランド名の想起・再訪意向は定性の声と定量の再訪・指名検索を分ける。
4. 商品購入意向を聞く際は「無料なら欲しい」と有料2,980円での購入を区別する。
5. 発見は日時・方法・引用の匿名化状態・改善案・関連Issueを記録する。

## 7. 改善判断のチェック

- ブランドの目的に沿うか
- 読者の理解が早くなるか
- 科学・販売の事実を歪めないか
- モバイルでも情報に到達できるか
- 運用を続けられるか
- 指標で後から検証できるか

目標値・ポジショニングの勝ち筋・市場規模・差別化優位の実証は**未確認**。検証前に「確立済み」と書かない。
