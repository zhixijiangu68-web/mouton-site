Body

その不調、どこから整えるか。

流行りの健康法や気合いで、続かなかったことはありませんか。

身体を、気分ではなく、確かめられることから。

生き方が変われば、行動が変わり、やがて外見や日常にも表れる。身体は、その変化がいちばん最後に表れる場所だと僕は思う。だからここでは、研究で確かめられることから、ひとつずつ整える。

1 / 3

人にどう見られているか、清潔感が気になる。

清潔感は、顔立ちの話ではない。肌、睡眠、ひげ、歯、服、匂いという、自分で整えられる要素に分けられる。

  1. 清潔感を分解する約9分
  2. 第一印象は0.1秒で決まる。そして、寝不足は顔に出る約5分
  3. 匂いは、人の印象をどこまで決めているのか約8分
  4. 匂いケアは「脇と足の裏」から。原因が違えば、対策も違う約8分
  5. 口臭の多くは「胃」ではなく、口の中から生まれる約13分
この悩みの続き清潔感の科学（PDF）何をどの順で整えるかを、研究から決める一冊。

2 / 3

寝ても疲れがとれない。体力がない。

何時間寝たかより、毎日同じ時間に寝起きしているかのほうが、からだと強く結びついていた。体力も、限界の高さより、一日を終えたあとに残る余力で考えられる。

  1. 「何時間寝たか」より「毎日同じ時間か」約7分
  2. 休日の「寝だめ」で、睡眠不足は取り返せるのか約5分
  3. 朝型と夜型は、変えられるのか約4分
  4. 昼寝は、何分がいいのか約3分
  5. 筋トレを減らしたら、なぜか「体力」がついた約3分

3 / 3

やる気が出ない。気分に振り回される。

「我慢すると意志力が減る」という説は、大規模な追試ではほぼ確かめられなかった。やる気が出ないのは、意志が弱いからとは限らない。

  1. 「意志力は使うと減る」は本当か約6分
  2. ドーパミンから、習慣へ約5分
  3. 扁桃体とは何か約6分
  4. 「前頭前野の炎症」とは何か約6分
  5. 反省するほど、動けなくなるのはなぜだろう。約5分
この悩みの続き・有料スピノザ「続かないのは、意志が弱いからではない。」感情の仕組みから、気分に左右されずに続ける形をつくる。
