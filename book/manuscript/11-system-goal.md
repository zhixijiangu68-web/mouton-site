# システムのないゴールは、動かない

「今年こそ痩せる」「もっと稼ぐ」「事業をつくる」。

目標を立てるのは簡単だ。問題は、**その目標を達成するために、日常的に何をするのかまで決まっているか**だ。

ここでいう「システム」とは、習慣やルーティンのことを指す。

毎日何をするのか。\
毎週何をするのか。\
その行動を続けることで、何が蓄積され、どんな結果につながるのか。

ゴールだけでは行動は決まらない。ゴールを日常の行動まで分解して初めて、目標は動き始める。

## ゴールは必要。ただし、それだけでは足りない

ゴールそのものには意味がある。目標設定理論の研究では、「頑張る」のような曖昧な目標より、具体的で挑戦的な目標のほうが高い成果につながりやすいことが示されている（Locke & Latham, 2002）。

しかし、ゴールが決めるのは「どこへ行くか」までだ。「どうやって行くか」は決めてくれない。そこで必要になるのがシステムだ。

ゴール → システム → 行動 → 結果 → 振り返り → システム（改善）

重要なのは、この中で自分が直接操作できる領域を理解することだ。

売上100万円、体脂肪率10％、フォロワー1万人。これらは目標にはできるが、直接操作することはできない。結果は管理するものではなく、行動の結果として観測するものだ。

一方で、「週に1本動画を公開する」「週3回トレーニングする」「毎日1時間、顧客について調べる」といった行動は自分で操作できる。

だから日常で管理するのは、結果ではなく入力となる行動だ。ゴールを決めたら、次に決めるべきは**「その結果を生み出すために、何を繰り返すのか」**になる。

## 良いシステムと悪いシステムの違い

習慣にすれば何でもいいわけではない。重要なのは、その行動が結果につながっているかどうかだ。

-   **YouTubeを成長させる**\
    悪いシステム：毎日再生数を確認する\
    良いシステム：週1本公開／毎週10本の伸びた動画を分析／毎日30分企画
-   **体を変える**\
    悪いシステム：毎日体重計に乗って一喜一憂する\
    良いシステム：週3回トレーニング／重量と回数を記録／睡眠を確保
-   **事業を伸ばす**\
    悪いシステム：とにかく毎日忙しくする\
    良いシステム：毎日1時間調査／毎週1つ施策を実行／毎週数字を振り返る

悪いシステムは、「結果を確認する行動」や「努力した感覚」で終わる。良いシステムは、「行動 → 蓄積 → 結果」の関係を説明できる。

たとえば、毎週動画を制作するなら、因果は次のようにつながる。

制作本数が増える\
↓\
視聴データが増える\
↓\
何が見られるのか分かってくる\
↓\
企画や編集を改善できる\
↓\
良い動画を作れる確率が上がる

重要なのは「毎日何かをすること」ではない。**その行動を繰り返した先に、どんな成果が生まれるのかを考えることだ。**

## 続かない日の設計

「毎日やる」と決めるだけでは、システムとしては弱い。行動する条件まで決めておく。

心理学では、こうした考え方は「実行意図（implementation intentions）」として研究されている。たとえば、「記事を書く」だけではなく、**「夕食後、デスクに座ったら、記事を500文字書く」**と決める。

つまり、いつ・どこで・何をするかまで具体化する。Gollwitzer & Sheeran（2006）は、94件の研究を統合したメタ分析で、実行意図が目標達成を促進する効果を報告している。行動を気分に任せず、始まる条件を先に決めておけば、「今日はやるか、やらないか」を毎回判断する必要が減る。

## 1日抜けても、システムを捨てない

習慣はすぐには自動化されない。Lallyら（2010）の研究では、自動性が高まるまでの期間に大きな個人差があり、その幅は18〜254日だった。モデル上では約66日で自動性が高い水準に近づいた。また、1回行動できなかったことが、習慣形成に大きな影響を与えるわけではなかった。

ここから分かるのは、システムに必要なのは完璧さではなく、復帰できることだ。1日できなかったからといってやめるのではなく、翌日に戻る。失敗しない仕組みよりも、失敗しても戻れる仕組みのほうが現実的だ。

## システムは結果を見て更新する

システムを作ったからといって、それが正しいとは限らない。定期的な振り返りが必要になる。

行動 → 結果 → 振り返り → 改善

-   3時間勉強しているのに点数が上がらない → 「もっと勉強する」ではなく、勉強方法を見直す
-   毎日SNSを投稿しているのに読まれない → 投稿数だけでなく、内容を分析する
-   毎週トレーニングしているのに成果が出ない → トレーニング内容、食事、睡眠を確認する

努力量を増やす前に、現在の行動が本当に目的の結果につながっているのかを確認する。システムとは、同じ行動を永久に繰り返すことではなく、結果を確認しながら行動を修正していく仕組みでもある。

## 今日のワーク

達成したいゴールを1つ書く。次に、3つの質問に答える。

1.  毎日・毎週、何をする？
2.  その行動を続けると、なぜ結果につながる？
3.  何を見て、そのシステムが機能しているか判断する？

**ゴール**

事業を成長させる

**システム**

毎日1時間、顧客・商品・競合を調べる／毎週1つ、新しい施策を実行する／毎週日曜に数字を振り返る

**なぜ結果につながる**

顧客理解と試行回数が増え、成果につながる施策を発見できる確率が上がる

**判断の指標**

実行した施策数、反応率、売上を確認し、翌週の行動を修正する

2つ目に答えられない場合、その習慣は目的とつながっていない可能性がある。3つ目に答えられなければ、システムを改善するための情報がない。

そして最後に、**今日、そのシステムを1回だけ実行する。**

## まとめ

ゴールは必要だ。しかし、ゴールだけでは何も実行されない。

ゴールが「どこへ行くか」を決めるなら、システムは「日常的に何をするか」を決める。結果を生み出すのは、目標を書いた回数ではなく、実際に繰り返された行動だ。

ゴール → システム → 行動 → 結果 → 振り返り → 改善

このループを作る。欲しい未来を決めたら、未来だけを見ない。その未来を生み出す「普通の一日」を設計する。

ゴールは未来にある。システムは今日にある。

**システムのないゴールは、願望のまま動かない。**
