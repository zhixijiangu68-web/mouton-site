IDS 3/4：商用・クラウドの製品と、第三者の評価の読み方

約7分更新日 2026年11月4日

いまの通信の多くは暗号化されている。中身が見えなければ、中身と照らす IDS は働かない。商用とクラウドの製品を並べると、この暗号化された通信をどう扱うかで、はっきり分かれていた。

この3本目では、商用とクラウドの製品の違いと、第三者の評価の読み方を書く。ここに書く性能の数字は、すべてメーカーの発表で、第三者が確かめたものではない。特定の製品を勧めるものでもない。

IDS について、4本に分けて書いている。1 IDS とは何か、なぜ大事か／2 無料の道具／3 商用とクラウドの製品／4 選ぶとき・運用するとき。

よく言われることの判定

確かさは、資料の確かさの目安。事実は公式の資料を検索で確かめたもので、原典を開いて確かめ直している途中なので、「中」より上にしていない。

よく言われること判定確かさ主な根拠
暗号化された通信でも、IDS は中身まで見られる× 否定中復号しない限り中身は見えない。Cloud IDS は暗号化された中身を復号できないと明記している。TLS 1.3 では証明書も暗号化される [1][2]
第三者の試験で推奨された製品なら、どの版でも同じように守れる× 否定中2025年の比較試験では、回避の手口で抜けられた2製品が、直した版で再試験して評価が上がった。結果は版に結びついている [3][4]
Gartner の Leader は、検知の性能が高い製品のことだ× 否定中Magic Quadrant は、実行能力とビジョンの2軸でベンダーを置くもので、検知率を測る試験ではない [5]

商用の多くは次世代ファイアウォールの機能で、NDR は内側の通信の振る舞いを見る

商用の製品は、大きく3つに分かれた。次世代ファイアウォール（NGFW）の中の IPS、専用の IPS、NDR（ネットワークの検知と対応）だ。

次世代ファイアウォールの IPS は、境目に置く機器の機能の一つ

  • Cisco Secure Firewall：Snort 3 のエンジンを使う。復号せずに通信の特徴から脅威を見分ける、Encrypted Visibility Engine も持つ[6]
  • Palo Alto Networks Advanced Threat Prevention：シグネチャに、通り道での深層学習を足した追加のサブスクリプション。メーカーの発表では、従来の IPS より60%多く、ゼロデイ（直し方がまだ出ていない弱点）を狙うインジェクション攻撃を防ぐ[7]
  • Fortinet FortiGate：通信を復号するディープインスペクションで、中身を IPS に見せる。証明書だけを見る方式では、中身が要る IPS は働かないと説明している[8][9]
  • Check Point：HTTPS Inspection で復号してから検査する[10]

インジェクション攻撃は、入力に命令を混ぜて相手に実行させる攻撃だ。

専用の IPS は、仮想パッチが中心

Trend Micro の TippingPoint は、Digital Vaccine と呼ぶフィルターを配る。脆弱性を狙う通信を止める「仮想パッチ」が中心だ[11]。仮想パッチは、脆弱性を直す前に、それを狙う通信を通り道で止めることだ。

NDR は、通信のコピーから内側の振る舞いを見る

NDR は、通信のコピーを受け取り、内側の通信の振る舞いを見る。コピーの取り出し口は、ミラーポート（スイッチが通信のコピーを出す口）やタップ（回線から通信のコピーを取り出す機器）だ。

  • Darktrace：組織ごとの「ふだん」を学び、そこからのずれを見つけると説明している[12]
  • Vectra AI：通信のメタデータ（宛先・時刻・量など、中身以外の情報）と、Active Directory などの ID の動きから、攻撃者の振る舞いを見る[13]
  • ExtraHop RevealX：TLS 1.3 を含めて通信を復号できる、とメーカーは説明している[14]
  • Corelight：オープンソースの Zeek と Suricata を土台にした NDR[15]

暗号化された通信は、復号する・特徴で見る・見えない、の3通りだった

並べてみると、暗号化された通信の扱いは3通りに分かれた。

  • 復号して中身を見る：NGFW の検査、ExtraHop
  • 復号せずに通信の特徴で見る：Cisco の Encrypted Visibility Engine、Corelight、Vectra、Darktrace
  • 中身は見えない：Google Cloud IDS[1]

TLS 1.3 では証明書も暗号化されるので、復号しなければ、相手の証明書の情報も見えなくなる[2]。

復号するには、検査する機器の証明書を端末に信頼させる手間がかかる。処理も重くなる[8][16]。復号しない方式は、その手間がない代わりに、見えるのは通信の特徴までだ。どちらを取るかは、守りたいものと、誰がどこまで中身を見てよいかで決まる。

クラウドでは、止められるものと、知らせるだけのものがあった

クラウドの主な3つは、置き方が違った。

クラウドの IDS/IPS（2026年11月4日時点。公式の資料を検索で確認）
サービス止めるか検知のもと暗号化料金の形
AWS Network Firewall止められる（警告だけにもできる）Suricata 互換のルールと、AWS が管理するルールTLS インスペクションで復号できる時間＋処理した量
Google Cloud IDS止めない（検知と警告）Palo Alto Networks の脅威のシグネチャ復号しない時間＋検査した量
Azure Firewall Premium止められる（シグネチャごとに選ぶ）Microsoft が管理するシグネチャTLS インスペクションで復号できる時間＋処理した量

AWS Network Firewall は、Suricata 互換のルールで止められる。TLS インスペクションでは、証明書を AWS Certificate Manager で用意する[17]。公式の料金のページでは、米国東部で、1時間あたり0.395ドルと、処理した1GBあたり0.065ドルだった。TLS インスペクションを使うと、時間あたりの料金が加わる[18]。

Google Cloud IDS は、通信のコピーを調べて知らせるだけだ[19]。料金のページでは、1時間あたり1.50ドルと、検査した1GBあたり0.07ドルだった[20]。

Azure Firewall Premium は、シグネチャごとに「無効」「警告」「警告して拒否」を選べる[16]。

値段は変わりやすく、地域でも違うので、使う前に料金のページで確かめてほしい。

第三者の評価は版によって変わり、Gartner の Leader は性能の試験ではなかった

製品を比べるとき、第三者の評価は役に立つ。ただ、読み方には注意が要る。

CyberRatings.org は、2025年にエンタープライズ向けファイアウォールの比較試験を行った。7製品のうち3つが「Recommended」だった[3]。Fortinet と Palo Alto Networks の2製品は、IP や TCP の回避の手口で抜けられて「Caution」だった。そのあと、直した版で再試験し、「Recommended」に上がった[4]。試験の結果は、試した版に結びついている。そして、回避の手口に弱いと、シグネチャがあっても抜けられる。

Gartner の Magic Quadrant は、ベンダーを「実行能力」と「ビジョンの完全性」の2軸に置くものだ。検知率を測る試験ではない。2025年の Hybrid Mesh Firewall の Leaders は、Check Point・Fortinet・Palo Alto Networks だった[5]。初めての NDR の Leaders は、Vectra AI・Darktrace・ExtraHop・Corelight だった[21]。どちらも、名前が挙がったことを、そのまま検知の強さと読まないほうがいい。

商用とクラウドは、暗号化の扱いと置き方から比べる

まとめると、商用は次世代ファイアウォールの IPS・専用の IPS・NDR に分かれた。暗号化された通信は、復号する・特徴で見る・見えない、の3通りだった。クラウドでは、止められるものと、知らせるだけのものがあった。第三者の評価は、版と年をつけて読む。

日本で使えるかどうか（地域や販売）は、ほとんどの製品で確かめられていない。同じ条件で検知の強さを比べた公開の試験も、ファイアウォールの試験しか見つけられなかった。

この記事の事実は、公式の資料を検索で確かめたもので、原典のページを一つずつ開いて確かめ直している途中だ。下書きと資料の照らし合わせには AI を使い、公開の前にムートンが全文を読む決まりにしている。特定の製品を勧めるものではない。

自分の環境の暗号化された通信は、誰が、どこまで見てよいものだろうか。

次に読む

  • 侵入に自分で気づけた組織は52%だった。IDSは、見つけて知らせる道具だった。

    侵入に自分で気づけたのは52%。IDS は止める箱ではなく、見つけて知らせる道具だった。

  • 無料のIDSは、Suricata・Snort 3・Zeekが中心で、Snort 2はもう終わっていた。

    Snort 2 は2026年10月に終わった。無料の IDS は、知らせる道具と記録する道具で役目が違った。
