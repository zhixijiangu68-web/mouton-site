お金について最初に読む本。考える順番別に4冊

約{{ readMinutes }}分で読めます（目安）

お金の本は多すぎて、どれから読めばいいか分からない。だから、考える順番を先に決めて、その順に1冊ずつ読む。

{% quiz "アマチュアのテニスの試合で、勝ち負けを決めているのは何か。「いいショット」か「ミス」か？", "ミス。", "プロの試合では、いいショットで点を取ったほうが勝つ。アマチュアの試合では、相手のミスで点が入ることのほうが多い。投資の本『敗者のゲーム』の題名は、この話から来ている。" %}

僕がこの記事を書いたのは、外見と同じくらい、お金も「整えておくと、ほかのことに集中できるもの」だと思っているからだ。仕事や遊びに力を使うために、まずお金のことで迷う時間を減らしたい。

ここでは、お金について考える順番を4つに分けて、それぞれで最初に読みたい本を1冊ずつ選んだ。

考える順番読む本
1. お金の全体像をつかむ本当の自由を手に入れる お金の大学
2. 増やし方の考え方を知る敗者のゲーム
3. お金と心の関係を知るサイコロジー・オブ・マネー
4. 何に使うかを決めるDIE WITH ZERO

1. お金の全体像をつかむ

『本当の自由を手に入れる お金の大学 改訂版』（両@リベ大学長、朝日新聞出版）は、お金の力を「貯める」「稼ぐ」「増やす」「守る」「使う」の5つに分けて、家計の見直しから税金、投資までを図解で説明する入門書。改訂版は新しいNISAの制度に合わせて書き直されている。

何から手をつければいいか分からないときに、まず地図を手に入れるための1冊。細かいところは、ほかの本や公的機関の情報で確かめればいい。

2. 増やし方の考え方を知る

『敗者のゲーム〈原著第8版〉』（チャールズ・エリス、鹿毛雄二・鹿毛房子 訳、日本経済新聞出版）は、プロでも市場の平均に勝ち続けるのは難しい、という前提から、長い目で見た資産運用の考え方を説く本。冒頭のクイズのテニスの話は、この本の題名のもとになっている。

「どの銘柄が上がるか」を当てようとする前に、「大きなミスをしない」ことの意味を考えるのに向いている。

3. お金と心の関係を知る

『サイコロジー・オブ・マネー』（モーガン・ハウセル、児島修 訳、ダイヤモンド社）は、お金でうまくいくかどうかは、知識の量より、ふるまい方で決まる、という視点から書かれたエッセイ集。

短い章が続くので、どこからでも読める。数字の本を読んでも続かなかった人に向いている。

{% amazonLink "4478114137", "Amazonでこの本を見る", "book-buy" %}

4. 何に使うかを決める

『DIE WITH ZERO』（ビル・パーキンス、児島修 訳、ダイヤモンド社）は、お金を貯めること自体を目的にせず、人生の時期ごとに「そのときにしかできない経験」に使っていこう、と提案する本。やりたいことを年代ごとの箱に入れる「タイムバケット」という考え方が出てくる。

1〜3の本で守りと増やし方を知ったあとに読むと、「何のために整えるのか」がはっきりする。

{% amazonLink "4478109680", "Amazonでこの本を見る", "book-buy" %}

本を読んだあとに

4冊を全部読む必要はない。いまいちばん迷っている順番の1冊から読めばいい。

読み終えたら、毎月の「入るお金」と「出ていくお金」を、それぞれ3行で書き出してみる。お金のことを考える時間は、そこから短くなっていく。
