# 顔写真（リンク画像・記事の表紙用）

- 使ってよいのは、商用利用ができて出典表示の要らない無料素材（Unsplash / Pexels）か、オーナー本人の写真だけ
- 写っている人が商品をすすめているように見せない（商品と並べない、セリフを付けない）
- ファイルを置いたら、下の表に出典を書く
- 記事の front matter に `face: "images/faces/<ファイル名>.jpg"` を書き、`cd scripts/og && node make.mjs` でリンク画像を作り直す
