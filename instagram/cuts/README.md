# 早送りカット型のリール（「The life I want.」型）

2026-10-06 にユーザーが共有した参考リール（quotientacademy「The life I want.」）の**型だけ**を使う。
暗い机・作業中の画面・夜の街・本とノートなどの映像を約0.5秒ずつ切り替え、真ん中に一言を出し続け、最後に「続きはプロフィールのリンクから」の画面を2.5秒出す。全体は約15.5秒。

## 素材のルール

- 使ってよいのは、**自分で撮った映像**か、**商用利用でき、出典の表示が要らないフリー素材**（Pexels、Mixkit など）だけ。参考リールや他人の投稿の映像は使わない
- 人の顔がはっきり映る素材や、ロゴ・商標が目立つ素材は避ける
- 素材ごとに、どこから取ったか（URL・ライセンス名）を、各フォルダの `assets.md` に書く（#16 素材収集）
- 1本に 8〜15 個の素材があると、同じ映像の繰り返しが目立たない

## 作り方

1. `NN-<記事>/clips/` に素材（mp4・mov・jpg・png）を入れる。ファイル名の順に使われる
2. 書き出す：
   ```sh
   cd .claude/skills/instagram-reel/render
   node cuts.mjs ../../../../instagram/cuts/NN-<記事>/cuts.json
   ```
3. `reel.mp4` と `cover.png` ができる。BGM はアプリで入れる

## cuts.json

| 項目 | 意味 |
|---|---|
| `text` | ずっと出しておく一言。`\n` で改行。1行12字以内 |
| `size` | 文字の大きさ（px、既定 50） |
| `clips` | 素材のフォルダ（または、ファイルの一覧） |
| `cut` | 1カットの秒数（既定 0.5） |
| `length` | カット部分の長さ（秒、既定 14） |
| `brightness` / `saturation` | 映像を少し暗く・落ち着いた色にする（既定 -0.06 / 0.85） |
| `end` | 最後の画面。`text`、`sub`（記事名）、`duration`（秒） |
